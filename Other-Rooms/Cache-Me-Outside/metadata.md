# Cache Me Outside

## Room Information
- **URL**: https://tryhackme.com/room/cachemeoutside
- **Difficulty**: Medium
- **Category**: OSINT
- **Estimated Time**: ~60 minutes

## Description
Years after walking away from the scene, a retired hacker has left pieces of his identity scattered across the open internet. At first glance, it looks like nothing more than a leaked conversation screenshot — but buried in that image is the first thread of a much larger trail. Public profiles, forgotten details, and small mistakes begin to connect into something more deliberate. Someone wanted this person found.

## Objectives
- Identify a retired hacker through OSINT techniques
- Extract exposed email addresses from Git commit metadata
- Discover phone numbers via automated email responses (active OSINT)
- Geolocate a city from social media imagery
- Pinpoint a tram station using transit route reconstruction

## Tools Used
- Komoot (fitness profile analysis)
- GitHub / GitHub API (commit metadata extraction)
- Threads / Instagram (social media OSINT)
- Google Lens / Google Maps (image geolocation)
- Email client (auto-reply trigger — active OSINT)
- Sherlock / username enumeration (optional)

## Concepts
- Username reuse across platforms
- Git commit metadata exposure
- Active vs passive OSINT
- Image geolocation (Google Lens)
- Transit route reconstruction
- Public profile correlation
