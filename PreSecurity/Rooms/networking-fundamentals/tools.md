# Tools: Networking Fundamentals

## Primary Tools

| Tool | Category | Purpose |
|------|----------|---------|
| ping | Diagnostics | Test network connectivity to a host |
| ip | Configuration | View and configure network interfaces |

## Related Tools

| Tool | Purpose |
|------|---------|
| traceroute | Trace the path packets take to a destination |
| ifconfig | Legacy network interface configuration |
| netstat | Display network connections and listening ports |
| Wireshark | Capture and analyze network packets |
