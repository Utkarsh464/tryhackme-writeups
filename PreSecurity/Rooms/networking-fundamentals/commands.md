# Commands: Networking Fundamentals

## Network Diagnostics

| Command | Description |
|---------|-------------|
| `ping -c 4 8.8.8.8` | Test connectivity to a remote host |
| `ip a` | Display all network interfaces and their IP addresses (modern Linux) |
| `ifconfig` | Display network interface configuration (legacy) |
| `ip route` | Show the routing table |
