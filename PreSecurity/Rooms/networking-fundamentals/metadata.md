# Networking Fundamentals

## Room Information
- **Room URL:** https://tryhackme.com/room/networking-fundamentals
- **Module:** Network Fundamentals
- **Difficulty:** Very Easy
- **Estimated Time:** 20-30 min
- **Access:** Free

## Description
This room introduces the basics of computer networking. Students learn what a network is, the different types of networks (LAN, WAN, MAN), common network topologies (star, bus, ring, mesh), and the fundamentals of data transmission.

Networking is the foundation of all cybersecurity knowledge. Understanding how devices communicate, how data travels across networks, and how networks are structured is essential before diving into security concepts like firewalls, VPNs, and network attacks.

## Learning Objectives
- Define what a network is and why networks exist
- Differentiate between LAN, WAN, and MAN
- Identify common network topologies and their trade-offs
- Understand basic data transmission concepts

## Key Tools and Technologies
- Network cables (copper, fiber)
- Routers
- Switches
- Hubs

## Prerequisites
- None

## Expected Outcomes
Students will understand the fundamental concepts of computer networking, including network types, topologies, and how data moves between devices.
