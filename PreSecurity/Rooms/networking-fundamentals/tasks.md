# Tasks: Networking Fundamentals

## Task 1: What is a Network?
**Purpose:** Understand the basic definition and purpose of a network.

**Skills:** Networking fundamentals.

**Theory:** A network connects two or more devices so they can communicate and share resources. Networks can be as small as two computers connected directly or as large as the global internet connecting billions of devices.

## Task 2: Network Types (LAN, WAN, MAN)
**Purpose:** Learn the differences between LAN, WAN, and MAN.

**Skills:** Network classification.

**Theory:** LAN (Local Area Network) covers a small area like a home or office. WAN (Wide Area Network) spans large geographic areas, with the internet being the largest WAN. MAN (Metropolitan Area Network) covers a city-sized area, larger than a LAN but smaller than a WAN.

## Task 3: Network Topologies
**Purpose:** Identify network topology types.

**Skills:** Network design fundamentals.

**Theory:** Star topology connects all devices to a central switch; if the switch fails, the whole network goes down. Bus topology uses a single backbone cable; easy to set up but a single break can disable the network. Ring topology passes data in one direction; a break affects all downstream devices. Mesh topology has every device connected to every other device, offering redundancy at high cost.

## Task 4: Data Transmission
**Purpose:** Understand how data moves across networks.

**Skills:** Data transmission concepts.

**Theory:** Data is broken into smaller pieces called packets for transmission. These packets travel across the network independently and are reassembled at the destination. The network infrastructure (switches, routers) handles packet forwarding based on addressing information.
