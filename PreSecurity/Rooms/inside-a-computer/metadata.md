# Inside a Computer

## Room Information
- **Room URL:** https://tryhackme.com/room/inside-a-computer
- **Module:** Computer Fundamentals
- **Difficulty:** Very Easy
- **Estimated Time:** 20-30 min
- **Access:** Free

## Description
This room introduces the core hardware components that make up a modern computer system. Students explore the CPU, RAM, storage, motherboard, and GPU, understanding how each component contributes to overall system performance.

Understanding computer hardware is foundational for cybersecurity professionals who need to assess system requirements, configure secure hardware, and troubleshoot physical and virtual systems. This knowledge directly applies to forensics, system administration, and secure configuration.

## Learning Objectives
- Identify and describe the major internal components of a computer
- Understand how CPUs, RAM, storage, and GPUs function and interact
- Differentiate between hardware types and their performance characteristics

## Key Tools and Technologies
- CPU (x86, ARM)
- RAM (DDR3/4/5)
- SSD (SATA, NVMe)
- GPU (CUDA)
- Motherboard (chipset, PCIe)

## Prerequisites
- None

## Expected Outcomes
Recognise all major internal computer components and explain their roles in system operation and security.
