# Commands: Inside a Computer

## System Information

| Command | Description |
|---------|-------------|
| `lscpu` | Display CPU architecture info |
| `cat /proc/cpuinfo` | Detailed per-core CPU information |
| `free -h` | Show RAM usage in human-readable format |
| `cat /proc/meminfo` | Detailed memory statistics |
| `lsblk` | List block storage devices |
| `df -h` | Show disk usage and mount points |
| `sudo fdisk -l` | List and manage partition tables |
| `lspci` | List PCI devices |
| `nvidia-smi` | NVIDIA GPU monitoring and management |
| `sudo lshw` | Comprehensive hardware listing |

## Windows

| Command | Description |
|---------|-------------|
| `wmic cpu get name` | Show CPU name and model |
| `wmic memorychip get capacity` | Show installed RAM module capacities |
| `systeminfo` | Detailed hardware and OS configuration |
| `msinfo32` | System Information GUI tool |
