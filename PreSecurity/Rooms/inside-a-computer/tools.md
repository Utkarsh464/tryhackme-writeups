# Tools: Inside a Computer

## Primary Tools

| Tool | Category | Purpose |
|------|----------|---------|
| `lscpu` | System Utility | Display CPU architecture, cores, threads, cache sizes |
| `free` | System Utility | Monitor RAM usage and swap utilisation |
| `lsblk` | Storage Utility | List block devices and partition layout |
| `fdisk` | Disk Utility | View and modify partition tables |
| `lspci` | Hardware Utility | Enumerate PCIe-connected devices |
| `nvidia-smi` | GPU Monitor | Query NVIDIA GPU status, memory, and processes |
| `lshw` | Hardware Lister | Comprehensive hardware configuration report |
| `dmidecode` | BIOS/DMI | Decode system BIOS and hardware DMI tables |
| `hwinfo` | Hardware Probe | Detailed hardware probing and diagnostics |
