# Tools: Computer Types

## Primary Tools

| Tool | Category | Purpose |
|------|----------|---------|
| `dmidecode` | Hardware | DMI/BIOS table decoder for system, memory, BIOS info |
| `ipmitool` | Server Management | Manage IPMI-enabled devices for remote server control |
| `lspci` | Hardware Listing | Enumerate all PCIe devices in the system |
| `pinout` | GPIO Utility | Display Raspberry Pi GPIO header and functions |
| `nvidia-smi` | GPU Monitor | Query and manage NVIDIA GPUs and their processes |
| `systemctl` | Service Manager | Control services including IPMI/KVM management tools |
| `OpenIPMI` | Server Management | Open-source IPMI kernel interface and tools |
