# Computer Types

## Room Information
- **Room URL:** https://tryhackme.com/room/computer-types
- **Module:** Computer Fundamentals
- **Difficulty:** Very Easy
- **Estimated Time:** 20-30 min
- **Access:** Free

## Description
This room categorises the different types of computing systems, from personal desktops and laptops to servers, workstations, embedded systems, and supercomputers. Each type is examined through its purpose, design philosophy, and hardware characteristics.

Understanding computer types is essential for security professionals who must select appropriate platforms, assess attack surfaces, and harden systems across diverse environments ranging from IoT devices to enterprise data centres.

## Learning Objectives
- Classify computing systems by form factor, use case, and architecture
- Understand the hardware and design trade-offs for each computer type
- Recognise the security implications unique to each platform

## Key Tools and Technologies
- Desktop components, laptop SoCs
- Rack server chassis, IPMI
- Embedded platforms (Raspberry Pi, Arduino)
- Mainframe and HPC architecture

## Prerequisites
- None

## Expected Outcomes
- Distinguish between computer types by their hardware design, performance goals, and deployment environment.
