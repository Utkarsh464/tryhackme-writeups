# Tools: Windows CLI Basics

## Primary Tools

| Tool | Category | Purpose |
|------|----------|---------|
| `ipconfig` | Network | Display TCP/IP configuration |
| `netstat` | Network | Show active connections, ports, and routing table |
| `ping` | Network | Test network reachability and latency |
| `tracert` | Network | Trace packet route to destination |
| `nslookup` | Network | Query DNS name resolution |
| `systeminfo` | System | Display detailed OS and hardware configuration |
| `tasklist` | Process | List running processes with details |
| `taskkill` | Process | Terminate a process by PID or name |
| `wmic` | WMI | WMI command-line queries for system data |
| `Get-Command` | PowerShell | Enumerate available PowerShell cmdlets |
| `Get-Process` | PowerShell | List and filter running processes |
| `Get-Service` | PowerShell | List and filter Windows services |
| `Where-Object` | PowerShell | Filter pipeline objects by criteria |
| `Select-Object` | PowerShell | Select or limit output properties and rows |
| `Export-CSV` | PowerShell | Export pipeline output to CSV file |
