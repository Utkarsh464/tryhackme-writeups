# Windows CLI Basics

## Room Information
- **Room URL:** https://tryhackme.com/room/windows-cli-basics
- **Module:** Operating Systems Basics
- **Difficulty:** Very Easy
- **Estimated Time:** 20-30 min
- **Access:** Free

## Description
This room covers the Windows command line interface, including both the traditional Command Prompt (CMD) and modern PowerShell. Students learn essential commands for file management, network diagnostics, system information, and process management.

Windows CLI skills are critical for system administration, incident response, and penetration testing on Windows targets. Many administrative tasks require CLI commands, and PowerShell has become a key tool for both legitimate automation and adversarial tradecraft.

## Learning Objectives
- Navigate and manage files using CMD and PowerShell
- Perform network diagnostics with CMD and PowerShell commands
- Gather system information and manage processes from the CLI

## Key Tools and Technologies
- CMD (dir, ipconfig, netstat)
- PowerShell (cmdlets, pipeline)
- WMIC, systeminfo

## Prerequisites
- None

## Expected Outcomes
- Use CMD and PowerShell to navigate directories, manage files and processes, perform network diagnostics, and gather system information.
