## Description
Python Basics introduces the Python programming language, focusing on fundamental concepts needed for cyber security tasks. Topics include variables, data types, conditionals, loops, functions, and file I/O.

Python is widely used in security for scripting, automation, exploit development, and analysis. Mastering these basics enables you to write custom tools and understand existing security scripts.

## Learning Objectives
- Declare variables and use common data types
- Write conditional statements and loops
- Define and call functions with parameters
- Read and write files using Python
- Use list comprehensions for concise data processing

## Key Tools and Technologies
- Python 3, IDLE, Jupyter Notebook

## Prerequisites
- None

## Expected Outcomes
Ability to write basic Python scripts for data processing, automation, and security-related tasks.
