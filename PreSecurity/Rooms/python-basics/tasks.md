# Tasks: Python Basics

## Task 1: Variables and Data Types
**Purpose:** Understand how to store and type data in Python.

**Skills:** Variables, int, float, str, bool.

**Theory:** Variables in Python are dynamically typed and assigned with `=`. Common built-in types include integers, floats, strings, booleans, lists, and dictionaries. Type can be checked with `type()`.

**Commands:** `name = "Alice"`, `type(name)`

---

## Task 2: Conditionals
**Purpose:** Control program flow with conditional statements.

**Skills:** if, elif, else.

**Theory:** Conditionals execute code based on boolean conditions. Python uses indentation to define blocks. Comparison operators include `==`, `!=`, `<`, `>`, `<=`, `>=`. Logical operators `and`, `or`, `not` combine conditions.

**Commands:** `if x > 0: print("positive")`

---

## Task 3: Loops
**Purpose:** Repeat actions using for and while loops.

**Skills:** for, while, range.

**Theory:** `for` loops iterate over sequences (lists, strings, ranges). `while` loops continue while a condition is true. `break` exits a loop early; `continue` skips to the next iteration.

**Commands:** `for i in range(5): print(i)`

---

## Task 4: Functions
**Purpose:** Define reusable blocks of code.

**Skills:** def, return, parameters.

**Theory:** Functions are defined with `def`, can take parameters, and return values using `return`. Default parameter values and keyword arguments provide flexibility. Functions are first-class objects in Python.

**Commands:** `def add(a, b): return a + b`

---

## Task 5: File I/O and Libraries
**Purpose:** Read and write files; import useful libraries.

**Skills:** open, with statement, import.

**Theory:** `open()` returns a file object. The `with` statement ensures proper resource cleanup. Common security-related libraries include `os`, `sys`, `socket`, `requests`, `hashlib`, and `subprocess`.

**Commands:** `with open("file.txt") as f: content = f.read()`
