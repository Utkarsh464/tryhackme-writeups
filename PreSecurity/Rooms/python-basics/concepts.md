# Concepts: Python Basics

## 1. Variables
Named references to values in memory. Python is dynamically typed so variables can change type during execution.

## 2. Data Types
int (integers), float (decimal numbers), str (text), bool (True/False), list (ordered mutable sequence), dict (key-value pairs).

## 3. Conditionals (if/elif/else)
Control structures that execute different code blocks based on boolean conditions. Python uses indentation (4 spaces) to define code blocks.

## 4. Loops (for/while)
`for` iterates over sequences; `while` repeats until a condition becomes false. `range()` generates numeric sequences for iteration.

## 5. Functions
Named blocks of reusable code defined with `def`. Functions can accept parameters and return values. They enable modular, testable code.

## 6. List Comprehension
A concise syntax for creating lists: `[x**2 for x in range(10) if x % 2 == 0]`. More readable and faster than manual for-loop construction.

## 7. File I/O
Reading and writing files using `open()` and the `with` statement. Modes include `r` (read), `w` (write), `a` (append), `rb` (binary read).

## 8. Common Security Libraries
`requests` (HTTP), `socket` (networking), `hashlib` (hashing), `os` (system), `sys` (interpreter), `subprocess` (shell commands), `re` (regex).
