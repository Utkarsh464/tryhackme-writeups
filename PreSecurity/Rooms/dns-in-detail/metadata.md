# DNS in Detail

## Room Information
- **Room URL:** https://tryhackme.com/room/dns-in-detail
- **Module:** How The Web Works
- **Difficulty:** Very Easy
- **Estimated Time:** 20-30 min
- **Access:** Free

## Description
This room provides a detailed look at the Domain Name System (DNS), the phonebook of the internet. Students learn about the DNS hierarchy (root servers, TLDs, SLDs, subdomains), record types (A, AAAA, CNAME, MX, TXT, NS), and the resolution process for recursive and authoritative queries.

DNS is fundamental to how the internet operates and is a frequent target for attacks. Understanding DNS structure helps security professionals recognize threats like DNS spoofing, DNS tunnelling, and domain generation algorithms used by malware.

## Learning Objectives
- Describe the DNS hierarchy (root → TLD → SLD → subdomain)
- Identify common DNS record types and their purposes
- Explain the DNS resolution process (recursive vs authoritative)
- Recognize common DNS attacks

## Key Tools and Technologies
- dig
- nslookup
- DNS server software (BIND)

## Prerequisites
- Networking Fundamentals

## Expected Outcomes
Students will understand how DNS translates domain names to IP addresses, the structure of the DNS hierarchy, and common DNS record types.
