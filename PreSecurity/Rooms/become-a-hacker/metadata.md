# Become a Hacker

## Room Information
- **Room URL:** https://tryhackme.com/room/become-a-hacker
- **Module:** Attacks and Defenses
- **Difficulty:** Very Easy
- **Estimated Time:** 30-45 min
- **Access:** Free

## Description
Become a Hacker introduces the attacker mindset using industry-standard frameworks like the Cyber Kill Chain and MITRE ATT&CK. You will learn the stages of a cyber attack and practice command injection exploitation and defence.

Understanding how attackers think and operate is essential for both offensive and defensive security roles. The practical component demonstrates how unsanitised user input leads to command injection vulnerabilities.

## Learning Objectives
- Describe the seven phases of the Cyber Kill Chain
- Navigate the MITRE ATT&CK framework
- Exploit command injection vulnerabilities
- Implement input validation defences

## Key Tools and Technologies
- Linux command line, MITRE ATT&CK website

## Prerequisites
- None

## Expected Outcomes
Ability to analyse attacks using structured frameworks and identify command injection vulnerabilities in web applications.
