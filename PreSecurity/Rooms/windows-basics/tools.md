# Tools: Windows Basics

## Primary Tools

| Tool | Category | Purpose |
|------|----------|---------|
| `icacls` | Permission Tool | View and modify NTFS file/folder permissions |
| `cipher` | Encryption Tool | Manage EFS encryption on files and folders |
| `tasklist` | Process Tool | Display running processes and their details |
| `sc` | Service Tool | Configure and query Windows services |
| `wevtutil` | Log Tool | Query and manage Windows event logs |
| `reg` | Registry Tool | Query, add, and export Registry entries |
| `services.msc` | GUI Console | Graphical service management |
| `secpol.msc` | GUI Console | Local Security Policy configuration |
| `eventvwr.msc` | GUI Console | Event Viewer for system/security logs |
| `regedit` | GUI Console | Registry Editor for system configuration |
| `perfmon.msc` | GUI Console | Performance Monitor for resource tracking |
