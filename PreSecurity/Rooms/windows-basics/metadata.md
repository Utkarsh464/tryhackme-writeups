## Description
This room explores the Windows operating system, focusing on its architecture, file system (NTFS), security controls, and built-in administrative tools. Students learn about the NT kernel, NTFS permissions, User Account Control, and management consoles like Event Viewer, Task Manager, and Services.

Windows is the most widely deployed desktop OS and a primary target in enterprise environments. Security professionals must understand how to configure Windows securely, audit events, and navigate its administrative interface to defend against Windows-specific threats.

## Learning Objectives
- Describe Windows NT architecture and NTFS features
- Configure and understand UAC, permissions, and local security policy
- Navigate key Windows administrative tools (Task Manager, Event Viewer, Services, Registry)

## Key Tools and Technologies
- Windows NT kernel, NTFS
- UAC, secpol.msc
- Task Manager, Event Viewer
- Services.msc, regedit

## Prerequisites
- None

## Expected Outcomes
- Navigate Windows administrative tools, configure NTFS permissions and UAC, and understand Windows security architecture.
