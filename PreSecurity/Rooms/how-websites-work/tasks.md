# Tasks: How Websites Work

## Task 1: HTML
**Purpose:** Learn HTML structure and common elements.

**Skills:** Web markup language.

**Theory:** HTML uses tags like `<h1>` (headings), `<p>` (paragraphs), `<a>` (links), `<img>` (images), and `<div>` (containers). Attributes like `href`, `src`, `class`, and `id` add configuration. HTML comments (`<!-- -->`) can accidentally leak sensitive information when left in production code.

## Task 2: CSS
**Purpose:** Learn CSS for styling web pages.

**Skills:** Web styling.

**Theory:** CSS uses selectors (element, class, ID) to target HTML elements and apply properties like `color`, `font-size`, `margin`, and `display`. Styles can be inline, internal (`<style>`), or external (`.css` files). The cascade determines which styles take precedence when conflicts occur.

**Commands:** N/A

---

## Task 3: JavaScript
**Purpose:** Understand JavaScript for interactivity.

**Skills:** Client-side programming.

**Theory:** JavaScript runs in the browser and can manipulate the DOM (Document Object Model) to dynamically change page content, handle events (clicks, form submissions), make HTTP requests via `fetch()`, and store data in cookies or localStorage. It is single-threaded and event-driven.

**Commands:** N/A

---

## Task 4: Security Considerations
**Purpose:** Recognize common web security issues.

**Skills:** Web security awareness.

**Theory:** HTML comments in production code can reveal credentials or internal paths. XSS (Cross-Site Scripting) occurs when user input is rendered unsanitized, allowing attackers to inject malicious scripts. DevTools can expose JavaScript logic, API endpoints, and authentication tokens.
