# Tools: How Websites Work

## Primary Tools

| Tool | Category | Purpose |
|------|----------|---------|
| Browser DevTools | Development | Inspect HTML, CSS, network requests, and debug JavaScript |
| Browser | Rendering | Renders HTML/CSS/JavaScript |

## Related Tools

| Tool | Purpose |
|------|---------|
| curl | Fetch and inspect raw HTML from the command line |
| Burp Suite | Intercept and modify web traffic |
| Wappalyzer | Identify technologies used by a website |
| HTML Validator | Validate HTML syntax and structure |
| JSBeautifier | Format and beautify minified JavaScript |
