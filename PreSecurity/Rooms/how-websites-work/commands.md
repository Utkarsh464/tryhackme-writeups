# Commands: How Websites Work

## Browser DevTools

| Command / Action | Description |
|---------|-------------|
| `F12` or `Ctrl+Shift+I` | Open browser Developer Tools |
| `Ctrl+Shift+C` | Inspect element mode |
| `Ctrl+Shift+J` | Open Console tab in Chrome |

## JavaScript Console

| Command | Description |
|---------|-------------|
| `console.log("message")` | Print a message to the console |
| `document.querySelector("p")` | Select the first `<p>` element in the DOM |
| `document.getElementById("main")` | Select an element by ID |
| `fetch('http://example.com/api').then(r => r.json())` | Make an HTTP request from the console |
| `localStorage.getItem("key")` | Read a value from localStorage |
