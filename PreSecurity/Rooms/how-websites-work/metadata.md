# How Websites Work

## Room Information
- **Room URL:** https://tryhackme.com/room/how-websites-work
- **Module:** How The Web Works
- **Difficulty:** Very Easy
- **Estimated Time:** 20-30 min
- **Access:** Free

## Description
This room explains the three core technologies that power websites: HTML (structure), CSS (presentation), and JavaScript (interactivity). Students learn how browsers render web pages, how the Document Object Model (DOM) works, and how to use browser Developer Tools for debugging and exploration.

Understanding web technologies is essential for web security. Many vulnerabilities — including XSS (Cross-Site Scripting), HTML injection, and insecure client-side logic — stem from how HTML, CSS, and JavaScript interact. The room also highlights security pitfalls like exposed comments in HTML source.

## Learning Objectives
- Identify HTML elements, attributes, and comments
- Understand CSS selectors and how they style elements
- Explain JavaScript's role in the DOM and event handling
- Use browser DevTools to inspect and debug web pages
- Recognize common web security issues (hidden comments, XSS)

## Key Tools and Technologies
- Browser DevTools
- HTML
- CSS
- JavaScript

## Prerequisites

## Expected Outcomes
Students will understand how HTML, CSS, and JavaScript work together to create websites and be able to use DevTools to inspect and analyze web pages.
