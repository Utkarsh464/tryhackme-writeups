# Tasks: Data Representation

## Task 1: Binary and Bits
**Purpose:** Learn how computers represent data using binary digits (bits).

**Skills:** Binary number system, bits and bytes.

**Theory:** Computers use binary (base-2) with digits 0 and 1. A single binary digit is a bit; 8 bits form a byte. Binary is the lowest-level representation of all data in a computer.

**Commands:** None

---

## Task 2: Number Systems
**Purpose:** Understand different number systems used in computing.

**Skills:** Binary (base-2), octal (base-8), decimal (base-10), hexadecimal (base-16).

**Theory:** Decimal uses digits 0-9, binary uses 0-1, octal uses 0-7, and hexadecimal uses 0-9 and A-F. Each system has different applications: binary for hardware, octal for file permissions, hex for memory addresses and colours.

**Commands:** None

---

## Task 3: Conversions
**Purpose:** Convert numbers between binary, octal, decimal, and hexadecimal.

**Skills:** Base conversion techniques.

**Theory:** To convert from another base to decimal, multiply each digit by the base raised to its positional power. To convert from decimal to another base, repeatedly divide by the base and collect remainders from last to first.

**Commands:** None

---

## Task 4: Data Sizes
**Purpose:** Understand units of digital data storage.

**Skills:** Bit, byte, kilobyte, megabyte, gigabyte, terabyte.

**Theory:** 1 byte = 8 bits. 1 KB = 1024 bytes, 1 MB = 1024 KB, 1 GB = 1024 MB, 1 TB = 1024 GB. These units are used to measure storage capacity and file sizes.

**Commands:** None

---

## Task 5: Boolean Logic
**Purpose:** Apply basic Boolean logic operations.

**Skills:** AND, OR, NOT, XOR.

**Theory:** AND returns true only if both inputs are true. OR returns true if at least one input is true. NOT inverts the input. XOR returns true if inputs differ. These operations are fundamental to digital circuits and programming logic.

**Commands:** None
