# Concepts: Data Representation

## 1. Bit
The smallest unit of data in computing, representing a single binary value of 0 or 1.

## 2. Byte
A group of 8 bits, used as the fundamental unit of data storage. One byte can represent 256 distinct values.

## 3. Binary (Base-2)
A number system using only digits 0 and 1. Each position represents a power of 2.

## 4. Hexadecimal (Base-16)
A number system using digits 0-9 and letters A-F. Each hex digit represents 4 bits, making it compact for representing binary data.

## 5. Octal (Base-8)
A number system using digits 0-7. Historically used in Unix file permissions.

## 6. Base Conversion
Converting a number from one base to another by understanding positional value. Common conversions include decimal-to-binary and binary-to-hex.

## 7. Boolean Logic
A branch of algebra where values are true/false (1/0). Operations include AND, OR, NOT, and XOR, which form the basis of digital circuits.

## 8. Data Size Units
Hierarchical units: bit → byte → kilobyte → megabyte → gigabyte → terabyte. Each step multiplies by 1024 (2^10).
