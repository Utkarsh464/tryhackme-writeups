# Data Representation

## Room Information
- **Room URL:** https://tryhackme.com/room/data-representation
- **Module:** Software Basics
- **Difficulty:** Very Easy
- **Estimated Time:** 20-30 min
- **Access:** Free

## Description
Data representation explores how computers store and process information using binary. This room covers number systems including binary, octal, decimal, and hexadecimal, along with conversions between them.

You will learn about data size units from bits and bytes up to terabytes. Boolean logic operations such as AND, OR, NOT, and XOR are also introduced as fundamental building blocks of computation.

## Learning Objectives
- Understand binary, octal, decimal, and hexadecimal number systems
- Convert numbers between different bases
- Distinguish between bits, bytes, and larger data size units
- Apply Boolean logic operations (AND, OR, NOT, XOR)

## Key Tools and Technologies
- Number system conversion methods

## Prerequisites
- None

## Expected Outcomes
Ability to convert between number systems and understand how data is represented at the hardware level.
