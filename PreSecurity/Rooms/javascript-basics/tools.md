# Tools: JavaScript Basics

## Primary Tools

| Tool | Category | Purpose |
|------|----------|---------|
| Browser DevTools | Debugger | Inspect DOM, debug JS, view network requests |
| Node.js | Runtime | Server-side JavaScript execution environment |
| npm | Package Manager | Install JavaScript libraries and tools |
| ESLint | Linter | Analyse JavaScript code for errors and style issues |
| jsbin/codepen | Playground | Online JavaScript testing and sharing |
