# JavaScript Basics

- **Access:** Free

## Description
JavaScript Basics covers the fundamentals of client-side web programming. You will learn variables, functions, DOM manipulation, asynchronous programming with fetch and promises, and common web security issues.

JavaScript is essential for understanding how web applications work and identifying client-side vulnerabilities. Many web attacks such as XSS exploit JavaScript's interaction with the DOM.

## Learning Objectives
- Declare variables using let and const
- Write functions using declarations and arrow syntax
- Manipulate the DOM with getElementById and querySelector
- Make asynchronous HTTP requests with fetch
- Understand common JavaScript security pitfalls

## Key Tools and Technologies
- Browser Developer Tools, Node.js

## Prerequisites
- None

## Expected Outcomes
Ability to read and write client-side JavaScript for web security assessments and understand common vulnerabilities.
