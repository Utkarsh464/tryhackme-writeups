# Tools: Putting It All Together

## Primary Tools

| Tool | Category | Purpose |
|------|----------|---------|
| Browser DevTools | Debugging | Monitor full request lifecycle, network timing, and rendering |
| curl | HTTP Client | Test HTTP requests and inspect response details |
| Wireshark | Packet Analysis | Capture and analyze every packet in the request lifecycle |

## Related Tools

| Tool | Purpose |
|------|---------|
| dig | Inspect DNS resolution in detail |
| OpenSSL | Examine TLS certificates and test TLS connections |
| tcpdump | Command-line packet capture |
| traceroute | Map network path between client and server |
| Postman | GUI tool for testing and debugging HTTP requests |
