# Concepts: Careers in Cyber

## 1. Penetration Tester
Penetration testers simulate real-world attacks to identify vulnerabilities in systems and applications. They follow structured methodologies, produce detailed reports, and recommend remediation steps. Strong technical skills and creativity are essential.

## 2. SOC Analyst
SOC analysts monitor security alerts, triage incidents, and escalate threats. Tier 1 handles initial alerts. Tier 2 performs deeper investigations. Tier 3 involves advanced threat hunting and malware analysis.

## 3. Security Engineer
Security engineers design, implement, and maintain security systems like firewalls, IDS/IPS, and VPNs. They work on security architecture, automate security controls, and ensure systems are hardened against attacks.

## 4. Digital Forensic Analyst
Forensic analysts investigate security incidents by collecting and analyzing digital evidence. They recover deleted files, examine system artifacts, track attacker activity, and present findings in legal proceedings.

## 5. Chief Information Security Officer (CISO)
The CISO is a senior executive responsible for an organization's overall security strategy. They manage security teams, develop policies, ensure regulatory compliance, and report security risks to the board.

## 6. CompTIA Security+
An entry-level certification covering network security, compliance, threats, vulnerabilities, and cryptography. It is widely recognized as a baseline certification for security professionals and is required for many government roles.

## 7. OSCP
The Offensive Security Certified Professional certification requires passing a 24-hour practical exam. It tests real-world penetration testing skills with minimal guidance and is highly respected for offensive security roles.

## 8. Building a Career Roadmap
A structured approach to entering cybersecurity: learn fundamentals (networking, Linux, security concepts), practice hands-on skills (CTFs, labs), earn certifications (Security+), gain experience (internships, SOC roles), and specialize in a chosen area.
