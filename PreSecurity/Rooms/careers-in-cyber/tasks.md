# Tasks: Careers in Cyber

## Task 1: Security Roles Overview
**Purpose:** Learn about the major roles in cybersecurity.

**Skills:** Career awareness.

**Theory:** Cybersecurity offers diverse roles including penetration tester (finding vulnerabilities), SOC analyst (monitoring threats), security engineer (building defenses), forensic analyst (investigating incidents), and CISO (strategic leadership). Each role requires different skills and experience levels.

## Task 2: Certifications
**Purpose:** Understand industry-recognized certifications.

**Skills:** Certification planning.

**Theory:** CompTIA Security+ is an entry-level certification covering core security concepts. CEH (Certified Ethical Hacker) focuses on offensive techniques. OSCP (Offensive Security Certified Professional) is a hands-on penetration testing certification requiring practical exam performance.

**Commands:** N/A

---

## Task 3: Building a Portfolio
**Purpose:** Learn how to demonstrate skills to employers.

**Skills:** Personal branding.

**Theory:** A strong cybersecurity portfolio includes a well-documented GitHub with writeups, a LinkedIn profile highlighting certifications and projects, a personal blog or website, and participation in CTF competitions or bug bounty programs.

**Commands:** N/A

---

## Task 4: Getting Started
**Purpose:** Create a roadmap for entering cybersecurity.

**Skills:** Career planning.

**Theory:** Start with foundational knowledge (networking, OS concepts, security basics), practice on platforms like TryHackMe and HackTheBox, pursue entry-level certifications (Security+), network with professionals, and apply for SOC analyst or junior pen tester roles.
