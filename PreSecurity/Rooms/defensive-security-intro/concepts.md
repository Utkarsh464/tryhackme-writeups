# Concepts: Defensive Security Intro

## 1. Defensive Security
Defensive security encompasses all measures taken to protect systems and networks from attacks. This includes prevention (firewalls, patching), detection (monitoring, alerts), and response (incident handling, recovery).

## 2. Security Operations Center (SOC)
A centralized unit responsible for monitoring, detecting, analyzing, and responding to cybersecurity incidents. SOCs use SIEM platforms to aggregate and correlate logs from across the organization.

## 3. SIEM (Security Information and Event Management)
A platform that collects and analyzes log data from various sources to identify suspicious activity. SIEM tools use correlation rules, threat intelligence, and machine learning to generate alerts for SOC analysts.

## 4. IDS and IPS
Intrusion Detection Systems (IDS) monitor network traffic and alert on suspicious patterns. Intrusion Prevention Systems (IPS) go further by actively blocking detected threats in real time.

## 5. Digital Forensics
The practice of collecting, preserving, and analyzing digital evidence in a forensically sound manner. Key principles include maintaining chain of custody and ensuring data integrity throughout investigations.

## 6. Incident Response Process
A structured approach to handling security incidents: Preparation (tools/plans), Identification (detecting anomalies), Containment (isolating threats), Eradication (removing threats), Recovery (restoring operations), and Lessons Learned (improving future response).

## 7. The CIA Triad
Confidentiality ensures data is only accessible to authorized users. Integrity guarantees data is accurate and hasn't been tampered with. Availability ensures systems and data are accessible when needed by authorized users.

## 8. Blue Team
The defensive security team responsible for maintaining an organization's security posture. Blue team activities include monitoring, threat hunting, patch management, security architecture review, and incident response.
