# Tasks: Defensive Security Intro

## Task 1: What is Defensive Security?
**Purpose:** Define defensive security and contrast it with offensive security.

**Skills:** Understanding security disciplines.

**Theory:** Defensive security focuses on preventing intrusions, detecting ongoing attacks, and responding to security incidents. It involves monitoring networks, analyzing logs, managing firewalls, and ensuring systems are patched and configured securely.

## Task 2: Security Operations Center (SOC)
**Purpose:** Understand the role and structure of a SOC.

**Skills:** SOC operations awareness.

**Theory:** A SOC is a team of security professionals who monitor and analyze an organization's security posture 24/7. SOC analysts work in tiers (Tier 1 triage, Tier 2 investigation, Tier 3 advanced threat hunting) to detect and respond to threats using SIEM tools.

## Task 3: Digital Forensics and Incident Response (DFIR)
**Purpose:** Learn the basics of DFIR.

**Skills:** Understanding incident handling.

**Theory:** DFIR combines digital forensics (collecting and analyzing evidence) with incident response (containing and remediating breaches). The process includes preparation, identification, containment, eradication, recovery, and lessons learned.

## Task 4: The CIA Triad
**Purpose:** Understand the three core principles of security.

**Skills:** Security fundamentals.

**Theory:** The CIA triad stands for Confidentiality (data accessible only to authorized parties), Integrity (data is accurate and unaltered), and Availability (systems and data are accessible when needed). Every security control maps to at least one CIA principle.
