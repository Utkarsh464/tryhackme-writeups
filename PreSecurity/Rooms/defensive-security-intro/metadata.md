# Defensive Security Intro

## Room Information
- **Room URL:** https://tryhackme.com/room/defensive-security-intro
- **Module:** Introduction to Cyber Security
- **Difficulty:** Very Easy
- **Estimated Time:** 20-30 min
- **Access:** Free

## Description
This room introduces defensive security — the practice of protecting networks, systems, and data from attacks. Students learn about Security Operations Centers (SOCs), incident detection and response, and the fundamentals of digital forensics.

Defensive security is the counterpart to offensive security and forms the backbone of enterprise cybersecurity. Understanding how to detect, respond to, and prevent attacks is critical for any security professional, whether they work on a blue team or pursue a broader security role.

## Learning Objectives
- Define defensive security and its importance
- Explain the role of a Security Operations Center (SOC)
- Understand basic incident detection and response procedures
- Recognize the role of digital forensics in investigations
- Describe the CIA triad

## Key Tools and Technologies
- SIEM (Security Information and Event Management)
- IDS/IPS
- Wireshark
- Splunk

## Prerequisites
- None

## Expected Outcomes
Students will understand the defensive side of cybersecurity, including how SOCs operate, how incidents are detected and handled, and the principles that guide security defense.
