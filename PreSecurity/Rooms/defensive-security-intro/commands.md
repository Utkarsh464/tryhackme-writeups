# Commands: Defensive Security Intro

## System Monitoring

| Command | Description |
|---------|-------------|
| `sudo tcpdump -i eth0` | Capture network packets for analysis |
| `tail -f /var/log/syslog` | Monitor system logs in real time |

## File Analysis

| Command | Description |
|---------|-------------|
| `file filename` | Determine file type |
| `strings filename` | Extract readable strings from a binary |
