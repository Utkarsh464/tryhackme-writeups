# Commands: Offensive Security Intro

## Web Enumeration

| Command | Description |
|---------|-------------|
| `gobuster dir -u http://target.com -w /usr/share/wordlists/dirb/common.txt` | Directory busting to find hidden paths |
| `curl http://target.com/` | Fetch a web page from the terminal |

## System Interaction

| Command | Description |
|---------|-------------|
| `whoami` | Display current user |
| `ls -la` | List all files including hidden ones |
| `cat filename` | Display file contents |
