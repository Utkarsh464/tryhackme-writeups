# Tasks: Offensive Security Intro

## Task 1: What is Offensive Security?
**Purpose:** Define offensive security and contrast it with defensive security.

**Skills:** Understanding security disciplines.

**Theory:** Offensive security involves actively breaking into systems to find vulnerabilities. Unlike defensive security (which protects), offensive security takes the attacker's perspective to proactively discover weaknesses before they are exploited in the wild.

**Purpose:** Apply offensive security concepts by exploiting a vulnerable website.

**Skills:** Basic web enumeration, command execution, flag capture.

## Task 3: Penetration Testing Methodology
**Purpose:** Learn the structured phases of a penetration test.

**Skills:** Understanding pen test workflow.

**Theory:** A penetration test follows five phases: reconnaissance (gathering intel), scanning (identifying open ports/services), exploitation (gaining access), privilege escalation (elevating permissions), and reporting (documenting findings). Each phase builds on the previous one.

## Task 4: Careers in Offensive Security
**Purpose:** Explore career paths that use offensive security skills.

**Skills:** Career awareness.

**Theory:** Offensive security roles include penetration tester, red team member, and security researcher. These roles require continuous learning, hands-on practice, and often industry certifications like OSCP, CEH, or GPEN.
