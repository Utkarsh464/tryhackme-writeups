# Offensive Security Intro

## Room Information
- **Room URL:** https://tryhackme.com/room/offensive-security-intro
- **Module:** Introduction to Cyber Security
- **Difficulty:** Very Easy
- **Estimated Time:** 20-30 min
- **Access:** Free

## Description
This room introduces the concept of offensive security — the proactive approach to cybersecurity where ethical hackers simulate real-world attacks to find vulnerabilities before malicious actors do. Students learn the core methodology behind penetration testing and ethical hacking.

Understanding offensive security is essential because it teaches how attackers think and operate. By adopting the attacker mindset, security professionals can better defend systems and identify weaknesses that would otherwise go unnoticed.

## Learning Objectives
- Define offensive security and its role in cybersecurity
- Understand the penetration testing methodology (reconnaissance, scanning, exploitation, reporting)
- Differentiate between ethical hacking and malicious hacking
- Apply basic offensive techniques in a controlled environment

## Key Tools and Technologies
- Kali Linux
- Metasploit
- Nmap
- Gobuster
- Burp Suite

## Prerequisites
- None

## Expected Outcomes
Students will grasp the fundamentals of offensive security and understand the phases of a typical penetration test, preparing them for further study in ethical hacking.
