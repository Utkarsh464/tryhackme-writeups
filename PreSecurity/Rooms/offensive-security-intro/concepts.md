# Concepts: Offensive Security Intro

## 1. Offensive Security
Offensive security is the practice of actively breaking into computer systems to discover vulnerabilities. It is a proactive approach that simulates the actions of real attackers to identify security gaps before they can be exploited maliciously.

## 2. Ethical Hacking
Ethical hacking involves authorized attempts to bypass system security. Unlike malicious hackers, ethical hackers have permission to test systems and report findings to the organization so they can be fixed.

## 3. Penetration Testing Methodology
A structured approach to security testing consisting of five phases: reconnaissance (intelligence gathering), scanning (identifying attack surface), exploitation (gaining entry), privilege escalation (expanding access), and reporting (communicating results).

## 4. Reconnaissance
The first phase where the tester gathers information about the target using passive techniques (OSINT, DNS lookups) and active techniques (port scanning, directory enumeration) without causing damage.

## 5. Exploitation
The phase where identified vulnerabilities are leveraged to gain unauthorized access to a system. This includes techniques like SQL injection, command injection, and buffer overflow attacks.

## 6. Reporting
The final and most important phase where findings are documented with clear remediation steps. A good report includes the scope, methodology, findings (with risk ratings), and actionable recommendations.

## 7. Red Team vs Blue Team
Red team simulates adversarial attacks to test defenses. Blue team defends against attacks and monitors for intrusions. Purple team integrates both perspectives for improved security posture.

## 8. Rules of Engagement
Legal and contractual boundaries that define what a penetration tester can and cannot do. Includes scope (targets), limitations (no DoS), timelines, and data handling requirements.
