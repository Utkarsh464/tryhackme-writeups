## Description
This room introduces cloud computing service models and deployment strategies. Students learn about IaaS, PaaS, and SaaS, how they differ, and when to use each. Public, private, hybrid, and multi-cloud models are explored along with the shared responsibility model for security.

Cloud security is one of the fastest-growing domains in cybersecurity. Understanding misconfigured S3 buckets, IAM privilege escalation, and the shared responsibility model is critical for defending cloud-hosted assets and conducting cloud penetration testing.

## Learning Objectives
- Differentiate between IaaS, PaaS, and SaaS service models
- Describe public, private, hybrid, and multi-cloud deployment models
- Explain the shared responsibility model and key cloud security concepts

## Key Tools and Technologies
- AWS S3, EC2, IAM
- Azure VMs, Active Directory
- GCP Compute Engine, Cloud Storage
- Terraform, CloudFormation

## Prerequisites
- None

## Expected Outcomes
- Distinguish cloud service and deployment models, and explain the shared responsibility security model.
