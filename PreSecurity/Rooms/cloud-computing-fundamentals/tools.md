# Tools: Cloud Computing Fundamentals

## Primary Tools

| Tool | Category | Purpose |
|------|----------|---------|
| `aws-cli` | Cloud CLI | Command-line management of AWS services |
| `az-cli` | Cloud CLI | Command-line management of Azure resources |
| `gcloud` | Cloud CLI | Command-line management of Google Cloud Platform |
| `terraform` | IaC Tool | Infrastructure as Code for provisioning cloud resources |
| `cloudsploit` | Security Scanner | Audits cloud infrastructure for misconfigurations |
| `scoutsuite` | Security Scanner | Multi-cloud security auditing framework |
| `s3-inspector` | Security Tool | Check AWS S3 bucket permissions and configurations |
| `pacbot` | Compliance Tool | Cloud compliance and policy enforcement engine |
