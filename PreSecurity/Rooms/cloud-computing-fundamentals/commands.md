# Commands: Cloud Computing Fundamentals

## AWS CLI

| Command | Description |
|---------|-------------|
| `aws ec2 run-instances` | Launch a new EC2 instance |
| `aws s3 ls` | List S3 buckets |
| `aws s3api put-bucket-public-access` | Block public access to a bucket |
| `aws iam list-users` | List IAM users |
| `aws iam list-roles` | List IAM roles |
| `aws configure` | Configure AWS CLI credentials |

## Azure CLI

| Command | Description |
|---------|-------------|
| `az vm create` | Create a virtual machine |
| `az webapp create` | Create a web app (PaaS) |
| `az role assignment list` | List role assignments |
| `az login` | Authenticate Azure CLI |

## GCP CLI (gcloud)

| Command | Description |
|---------|-------------|
| `gcloud compute instances create` | Create a compute instance |
| `gcloud app deploy` | Deploy an app to App Engine |
| `gcloud iam roles list` | List IAM roles |
| `gcloud auth login` | Authenticate gcloud CLI |

## General

| Command | Description |
|---------|-------------|
| `terraform init` | Initialise Terraform working directory |
| `terraform plan` | Preview infrastructure changes |
| `terraform apply` | Apply infrastructure changes to cloud |
