# Tools: Operating System Security

## Primary Tools

| Tool | Category | Purpose |
|------|----------|---------|
| `net` | User Management | Windows CLI for managing users, groups, accounts |
| `useradd` / `usermod` | User Management | Linux CLI for adding and modifying users |
| `passwd` | User Management | Change user passwords |
| `chage` | User Management | Set user password expiry and age policies |
| `secpol.msc` | GUI Console | Windows Local Security Policy editor |
| `eventvwr.msc` | GUI Console | Windows Event Viewer for log analysis |
| `wevtutil` | Logging | Windows CLI event log query tool |
| `auditctl` | Logging | Linux audit system control — define audit rules |
| `journalctl` | Logging | View and query systemd journal logs |
| `iptables` | Firewall | Linux packet filtering and NAT rules |
| `ufw` | Firewall | Uncomplicated Firewall for iptables |
| `netsh` | Firewall | Windows network shell for firewall config |
| `apt` | Patching | Debian/Ubuntu package management |
| `yum` / `dnf` | Patching | RHEL/CentOS/Fedora package management |
| `pam-auth-update` | Patching | Configure PAM authentication modules |
