## Description
This room covers the fundamental security principles and practices for hardening operating systems. Students learn about user account management, least privilege, authentication methods, password policies, patch management, logging, firewalls, and the principle of reducing attack surface by disabling unnecessary services.

OS security is the foundation of all cybersecurity. Exploits at the OS level can compromise every application running on the system. Understanding how to configure accounts, apply patches, monitor logs, and harden the OS is essential for every security professional.

## Learning Objectives
- Implement user account security and least privilege
- Configure password policies and authentication mechanisms
- Manage patches, logging, firewalls, and service configurations

## Key Tools and Technologies
- Windows Firewall, iptables/nftables
- Event Viewer, syslog, auditd
- WSUS, apt, yum
- secpol.msc, gpedit.msc

## Prerequisites
- None

## Expected Outcomes
- Harden an OS by configuring user accounts, authentication policies, patching, logging, firewalls, and reducing unnecessary services.
