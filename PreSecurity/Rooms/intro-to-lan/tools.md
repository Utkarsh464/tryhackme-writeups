# Tools: Intro to LAN

## Primary Tools

| Tool | Category | Purpose |
|------|----------|---------|
| arp | Networking | View and manipulate the ARP cache |
| ip | Networking | Modern tool for network interface and route configuration |

## Related Tools

| Tool | Purpose |
|------|---------|
| ifconfig | Legacy tool for network interface configuration |
| Wireshark | Capture and analyze ARP packets |
| nmap | Network discovery and ARP scanning |
| macchanger | Change MAC address of a network interface |
