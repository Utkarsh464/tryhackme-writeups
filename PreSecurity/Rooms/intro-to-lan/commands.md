# Commands: Intro to LAN

## MAC and ARP Tools

| Command | Description |
|---------|-------------|
| `ip link show` | Show MAC addresses of all network interfaces |
| `arp -a` | Display the ARP cache (IP-to-MAC mappings) |
| `ip neigh` | Show neighbour table (ARP cache on modern Linux) |

## Interface Configuration

| Command | Description |
|---------|-------------|
| `ifconfig` | Display and configure network interfaces |
| `ip addr` | Show IP addresses and MAC addresses |
