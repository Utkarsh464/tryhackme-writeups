# Intro to LAN

## Room Information
- **Room URL:** https://tryhackme.com/room/intro-to-lan
- **Module:** Network Fundamentals
- **Difficulty:** Very Easy
- **Estimated Time:** 20-30 min
- **Access:** Free

## Description
This room dives into Local Area Networks in greater detail. Students learn about Ethernet technology, MAC addresses, the ARP protocol, how switches operate, and the concepts of collision and broadcast domains. Wireless LAN basics are also introduced.

Understanding LAN internals is critical for network security. Concepts like ARP spoofing, MAC address filtering, and switch security all stem from the fundamentals covered in this room. It provides the groundwork for understanding how devices discover and communicate with each other on local networks.

## Learning Objectives
- Understand Ethernet and its role in LANs
- Explain MAC addresses and their format
- Describe the ARP protocol and how it resolves IP-to-MAC mappings
- Differentiate between collision and broadcast domains
- Understand basic switch operations

## Key Tools and Technologies
- Ethernet
- Switches
- ARP
- Wi-Fi

## Prerequisites
- Networking Fundamentals

## Expected Outcomes
Students will understand how LANs operate at the data link layer, including how switches forward frames, how ARP resolves addresses, and the difference between collision and broadcast domains.
