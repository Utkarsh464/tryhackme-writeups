# Extending Your Network

## Room Information
- **Room URL:** https://tryhackme.com/room/extending-your-network
- **Module:** Network Fundamentals
- **Difficulty:** Very Easy
- **Estimated Time:** 30-40 min
- **Access:** Free

## Description
This room covers technologies that extend and manage networks beyond simple LANs. Students learn about Network Address Translation (NAT), Port Address Translation (PAT), the DHCP protocol and DORA process, VPNs, subnetting, routing, default gateways, and firewalls.

These technologies are fundamental to how modern networks operate at scale. NAT allows many devices to share a single public IP. DHCP automates IP address assignment. VPNs create secure tunnels over public networks. Understanding these concepts is essential for both network administration and security.

## Learning Objectives
- Explain NAT and PAT and why they are used
- Describe the DHCP DORA process
- Understand VPNs and their use cases
- Perform basic subnetting calculations
- Explain routing and the role of a default gateway
- Differentiate between network firewalls and host firewalls

## Key Tools and Technologies
- Cisco Packet Tracer
- OpenVPN
- iptables
- iproute2

## Prerequisites
- Intro to LAN
- OSI Model

## Expected Outcomes
Students will understand how networks are extended through NAT, DHCP, VPNs, subnetting, and routing, and how firewalls provide perimeter security.
