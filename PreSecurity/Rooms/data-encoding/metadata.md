# Data Encoding

## Room Information
- **Room URL:** https://tryhackme.com/room/data-encoding
- **Module:** Software Basics
- **Difficulty:** Very Easy
- **Estimated Time:** 30-45 min
- **Access:** Free

## Description
Data encoding covers how text and binary data are represented in formats suitable for transmission and storage. This room explores ASCII, Unicode, base64, URL encoding, and hex encoding.

Understanding encoding is essential for handling data across different systems, web applications, and network protocols. Misinterpretation of encoding can lead to security vulnerabilities and data corruption.

## Learning Objectives
- Understand ASCII and its 7-bit character set
- Distinguish between Unicode encoding schemes (UTF-8, UTF-16)
- Encode and decode base64 data
- Apply URL encoding for web requests
- Use hex encoding for binary data representation

## Key Tools and Technologies
- Python (encode/decode), base64, xxd, CyberChef

## Prerequisites
- None

## Expected Outcomes
Ability to identify and work with different encoding schemes used in computing and security challenges.
