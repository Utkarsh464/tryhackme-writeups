# Tools: Data Encoding

## Primary Tools

| Tool | Category | Purpose |
|------|----------|---------|
| base64 | CLI | Encode/decode base64 data from the command line |
| xxd | CLI | Make hex dumps or convert hex to binary |
| od | CLI | Octal/hex dump of files |
| Python | Language | Built-in encode/decode methods, base64, and urllib.parse modules |
| CyberChef | Web App | Browser-based encoding/decoding and data analysis Swiss-army knife |
