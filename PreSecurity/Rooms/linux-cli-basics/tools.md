# Tools: Linux CLI Basics

## Primary Tools

| Tool | Category | Purpose |
|------|----------|---------|
| `ls` | Filesystem | List directory contents |
| `cp` | Filesystem | Copy files and directories |
| `mv` | Filesystem | Move or rename files |
| `rm` | Filesystem | Remove files and directories |
| `mkdir` | Filesystem | Create directories |
| `chmod` | Permission | Change file permissions (rwx) |
| `chown` | Permission | Change file owner and group |
| `ps` | Process | Snapshot of current processes |
| `top` | Process | Real-time process monitoring |
| `htop` | Process | Enhanced interactive process viewer |
| `kill` | Process | Send signals to terminate/control processes |
| `grep` | Text | Pattern search within files and output |
| `sed` | Text | Stream editor for text transformations |
| `awk` | Text | Pattern scanning and processing language |
| `find` | Filesystem | Locate files by criteria across filesystem |
| `cat` | Text | Concatenate and display file contents |
