# Linux CLI Basics

## Room Information
- **Room URL:** https://tryhackme.com/room/linux-cli-basics
- **Module:** Operating Systems Basics
- **Difficulty:** Very Easy
- **Estimated Time:** 20-30 min
- **Access:** Free

## Description
This room teaches the foundational Linux command-line skills needed for system navigation, file manipulation, permission management, process control, and text processing. Students learn the Linux filesystem hierarchy, essential commands, and the chmod permission model.

The Linux CLI is the primary interface for most servers, cloud instances, and security testing platforms. Every cybersecurity professional must be comfortable navigating the terminal, managing files and permissions, and analysing system output using text-processing utilities.

## Learning Objectives
- Navigate the Linux filesystem and perform basic file operations
- Understand and configure Linux file permissions
- Manage processes and use text processing commands effectively

## Key Tools and Technologies
- Bash, coreutils (touch, cp, mv, rm)
- chmod, chown, user/group management
- ps, top, htop
- grep, sed, awk, find

## Prerequisites
- None

## Expected Outcomes
- Confidently navigate the Linux CLI, manage files and processes, and use text processing commands to analyse outputs.
