# Database SQL Basics

## Room Information
- **Room URL:** https://tryhackme.com/room/database-sql-basics
- **Module:** Software Basics
- **Difficulty:** Very Easy
- **Estimated Time:** 30-45 min
- **Access:** Free

## Description
Database SQL Basics introduces structured query language for interacting with relational databases. You will learn CRUD operations (SELECT, INSERT, UPDATE, DELETE), JOINs for combining tables, aggregate functions, and SQL injection vulnerabilities.

SQL is fundamental for web application security testing. Understanding how databases work enables you to exploit SQL injection flaws and implement secure database access patterns.

## Learning Objectives
- Query data with SELECT and WHERE clauses
- Insert, update, and delete records
- Join tables using INNER JOIN
- Use aggregate functions (COUNT, SUM, AVG, MIN, MAX)
- Identify and prevent SQL injection vulnerabilities

## Key Tools and Technologies
- SQLite, MySQL, sqlmap

## Prerequisites
- None

## Expected Outcomes
Ability to write SQL queries for common operations and understand how SQL injection attacks exploit query construction.
