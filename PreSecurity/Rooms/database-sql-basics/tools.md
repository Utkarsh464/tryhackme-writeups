# Tools: Database SQL Basics

## Primary Tools

| Tool | Category | Purpose |
|------|----------|---------|
| SQLite | DBMS | Lightweight embedded database, great for learning SQL |
| MySQL | DBMS | Popular open-source relational database |
| sqlmap | Security Tool | Automated SQL injection detection and exploitation |
| sqlite3 CLI | CLI | Command-line interface for SQLite databases |
| MySQL CLI | CLI | Command-line interface for MySQL databases |
| DB Browser for SQLite | GUI | Visual database browser and editor |
