# Tools: Cryptography Concepts

## Primary Tools

| Tool | Category | Purpose |
|------|----------|---------|
| OpenSSL | CLI | Comprehensive cryptography library for encryption, signing, certificates |
| GPG | CLI | GNU Privacy Guard for encryption and signing |
| Hashcat | Security Tool | Password recovery and hash cracking |
| CyberChef | Web App | Browser-based cryptography and encoding operations |
| certbot | CLI | Automated SSL/TLS certificate management via Let's Encrypt |
