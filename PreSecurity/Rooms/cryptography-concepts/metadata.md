## Description
Cryptography Concepts covers the fundamental building blocks of secure communication. This room explores symmetric and asymmetric encryption, hashing, digital signatures, and Public Key Infrastructure (PKI).

Cryptography is the backbone of modern security — protecting data in transit, verifying identities, and ensuring integrity. Understanding these concepts is essential for anyone working in cyber security.

## Learning Objectives
- Distinguish between symmetric and asymmetric encryption
- Understand hashing and its role in password storage
- Explain how digital signatures provide non-repudiation
- Describe the components of PKI and certificate trust chains

## Key Tools and Technologies
- OpenSSL, GPG, Hashcat

## Prerequisites
- None

## Expected Outcomes
Ability to select appropriate cryptographic primitives for common security requirements and understand their strengths and limitations.
