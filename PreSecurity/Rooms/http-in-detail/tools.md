# Tools: HTTP in Detail

## Primary Tools

| Tool | Category | Purpose |
|------|----------|---------|
| curl | HTTP Client | Command-line tool for HTTP requests |
| Browser DevTools | Debugging | Inspect network requests, headers, and responses |

## Related Tools

| Tool | Purpose |
|------|---------|
| Burp Suite | Web proxy for intercepting and modifying HTTP traffic |
| netcat | Manual TCP connections for raw HTTP requests |
| Postman | GUI tool for testing HTTP APIs |
| Python requests | Python library for programmatic HTTP requests |
| Wget | Command-line file downloader with HTTP support |
