# HTTP in Detail

## Room Information
- **Room URL:** https://tryhackme.com/room/http-in-detail
- **Module:** How The Web Works
- **Difficulty:** Very Easy
- **Estimated Time:** 20-30 min
- **Access:** Free

## Description
This room examines the Hypertext Transfer Protocol (HTTP) in depth. Students learn about HTTP methods (GET, POST, PUT, PATCH, DELETE), status codes (1xx Informational through 5xx Server Error), headers (Request and Response), and the differences between HTTP and HTTPS.

HTTP is the foundation of web communication and a primary attack surface in web security. Understanding HTTP methods, status codes, and headers is essential for web application security testing, API work, and understanding how browsers and servers communicate.

## Learning Objectives
- Identify and describe HTTP methods (GET, POST, PUT, PATCH, DELETE)
- Interpret HTTP status codes (1xx-5xx)
- Understand common HTTP headers (Host, User-Agent, Content-Type, Authorization, Cookie, Set-Cookie)
- Explain HTTP vs HTTPS and the role of TLS
- Use curl to make HTTP requests

## Key Tools and Technologies
- curl
- Burp Suite
- Browser DevTools
- netcat

## Prerequisites
- Networking Fundamentals
- OSI Model

## Expected Outcomes
Students will understand HTTP request/response structure, methods, status codes, headers, and be able to interact with web servers using curl.
