# Tools: Become a Defender

## Primary Tools

| Tool | Category | Purpose |
|------|----------|---------|
| Splunk | SIEM | Enterprise log aggregation, search, and alerting platform |
| ELK Stack | SIEM | Open-source log analysis (Elasticsearch, Logstash, Kibana) |
| Crowdstrike Falcon | EDR | Cloud-based endpoint protection with threat intelligence |
| SentinelOne | EDR | Autonomous endpoint detection and response platform |
| Wireshark | Network | Packet capture and network traffic analysis |
| tcpdump | CLI | Command-line packet capture tool |
| VirusTotal | Threat Intel | Online file and URL scanning service |
| YARA | Analysis | Pattern-matching tool for malware identification |
