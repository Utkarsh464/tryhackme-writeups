# Become a Defender

## Room Information
- **Room URL:** https://tryhackme.com/room/become-a-defender
- **Module:** Attacks and Defenses
- **Difficulty:** Very Easy
- **Estimated Time:** 30-45 min
- **Access:** Free

## Description
Become a Defender introduces defensive security operations, covering the SOC team structure, SIEM and EDR tools, incident response phases, and IoC analysis. You will learn how organisations detect, analyse, and respond to cyber threats.

Defensive security is about building and operating systems that protect networks and data. This room provides a foundation for anyone interested in a blue team role.

## Learning Objectives
- Describe the SOC analyst tier structure
- Understand the roles of SIEM and EDR
- Follow the incident response process
- Analyse indicators of compromise (IoCs)
- Apply defence in depth principles

## Key Tools and Technologies
- Splunk, ELK Stack, Crowdstrike, SentinelOne

## Prerequisites
- None

## Expected Outcomes
Ability to describe how a Security Operations Centre functions and identify the key tools and processes used in incident response.
