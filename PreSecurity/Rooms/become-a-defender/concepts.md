# Concepts: Become a Defender

## 1. SOC (Security Operations Centre)
A team responsible for monitoring, detecting, analysing, and responding to security incidents. Operates 24/7 in large organisations.

## 2. SOC Analyst Tiers
Tier 1: Triage — monitor alerts, validate incidents. Tier 2: Investigation — deep analysis, containment. Tier 3: Threat Hunting — proactive searching, forensics, advanced malware analysis.

## 3. SIEM (Security Information and Event Management)
A platform that collects, normalises, and analyses log data from across the organisation. Provides real-time alerting, dashboards, and compliance reporting. Examples: Splunk, ELK Stack (Elasticsearch, Logstash, Kibana).

## 4. EDR (Endpoint Detection and Response)
A security solution that monitors endpoint activity for threats. Provides telemetry, behavioural analysis, and automated response. Examples: Crowdstrike Falcon, SentinelOne, Microsoft Defender for Endpoint.

## 5. Incident Response
A structured approach to handling security incidents. The six phases are Preparation, Detection & Analysis, Containment, Eradication & Recovery, Post-Incident Activity (Lessons Learned).

## 6. IoC (Indicator of Compromise)
Artifacts that suggest a system has been compromised. Common IoCs include IP addresses, domain names, file hashes, registry keys, and process names. Used to detect ongoing or past intrusions.

## 7. Defence in Depth
A security strategy using multiple, overlapping layers of defence. Ensures resilience if any single control is bypassed. Layers include network, endpoint, application, data, and administrative controls.

## 8. Security Controls
Preventive (block attacks), Detective (identify attacks), Corrective (fix damage), and Deterrent (discourage attackers). A balanced security posture uses all four types.
