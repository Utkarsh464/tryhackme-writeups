# Client-Server Basics

## Room Information
- **Room URL:** https://tryhackme.com/room/client-server-basics
- **Module:** Computer Fundamentals
- **Difficulty:** Very Easy
- **Estimated Time:** 20-30 min
- **Access:** Free

## Description
This room introduces the client-server network architecture that underpins most modern internet and enterprise services. Students learn the request-response communication pattern, common server types, and how clients initiate connections to servers.

Understanding the client-server model is fundamental to cybersecurity. It underpins web applications, email, file sharing, and databases — each of which presents unique attack surfaces and security considerations that professionals must assess and protect.

## Learning Objectives
- Define the client-server model and its request-response pattern
- Identify and describe common server types and their protocols
- Distinguish the client-server model from peer-to-peer architecture

## Key Tools and Technologies
- Web servers (Apache, Nginx)
- File servers (SMB, NFS)
- Database servers (MySQL, PostgreSQL)
- Mail servers (SMTP, IMAP)
- Netcat, cURL

## Prerequisites
- None

## Expected Outcomes
- Explain the client-server architecture, describe common server types and their protocols, and recognise the security implications of each model.
