# Tools: Client-Server Basics

## Primary Tools

| Tool | Category | Purpose |
|------|----------|---------|
| `curl` | HTTP Client | Transfer data to/from servers using various protocols |
| `telnet` | Network Utility | Raw TCP connection for protocol testing |
| `netstat` | Network Stat | View network connections, routing tables, interface stats |
| `ss` | Socket Stat | Modern equivalent of netstat for socket dumps |
| `smbclient` | SMB Client | Access SMB/CIFS file shares from the command line |
| `showmount` | NFS Utility | Display NFS export information |
| `mysql` | Database CLI | MySQL/MariaDB interactive SQL client |
| `psql` | Database CLI | PostgreSQL interactive SQL client |
| `openssl` | Crypto Tool | Test encrypted connections and generate certificates |
| `nginx` | Web Server | High-performance HTTP and reverse proxy server |
| `ufw` | Firewall | Uncomplicated Firewall front-end for iptables |
