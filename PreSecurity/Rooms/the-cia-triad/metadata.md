## Description
The CIA Triad is the foundational model for information security, defining three core principles: Confidentiality, Integrity, and Availability. This room explains each principle with real-world examples and explores the trade-offs between them.

Understanding the CIA Triad is essential for any security professional. It provides a framework for analysing security requirements, evaluating risks, and designing protective controls across all domains of cyber security.

## Learning Objectives
- Define confidentiality, integrity, and availability
- Identify controls that support each CIA principle
- Understand real-world scenarios where CIA trade-offs occur
- Apply the CIA Triad to security analysis
