# Tools: The CIA Triad

## Primary Tools

| Tool | Category | Purpose |
|------|----------|---------|
| sha256sum | CLI | Generate and verify SHA-256 hashes for integrity |
| md5sum | CLI | Generate MD5 hashes (fast but less secure) |
| chmod | CLI | Modify file permissions for access control |
| chown | CLI | Change file ownership for access control |
| openssl | CLI | Encryption and certificate operations |
| gpg | CLI | File encryption and signing |
