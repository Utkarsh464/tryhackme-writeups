# Virtualisation Basics

## Room Information

- **Difficulty:** Very Easy
- **Estimated Time:** 20-30 min
- **Access:** Free

## Description
This room explains how virtualisation enables multiple virtual machines (VMs) to run on a single physical host by abstracting hardware resources. Topics include hypervisor types, virtual machine components, and resource allocation strategies.

Virtualisation is foundational to cloud computing, DevOps, and cybersecurity lab environments. Understanding hypervisors, snapshots, and isolation helps professionals design resilient infrastructure and safely conduct malware analysis.

## Learning Objectives
- Define virtualisation and describe hypervisor types (Type 1 and Type 2)
- Identify virtual machine components (vCPU, vRAM, vDisk, vNIC)
- Understand resource allocation, oversubscription, and VM isolation

## Key Tools and Technologies
- VMware ESXi, Hyper-V, KVM
- VirtualBox, VMware Workstation
- Vagrant, Docker

## Prerequisites
- None

## Expected Outcomes
- Explain how hypervisors virtualise hardware, differentiate Type 1 and Type 2 hypervisors, and describe key VM components and management concepts.
