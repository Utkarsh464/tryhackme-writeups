# Tools: Virtualisation Basics

## Primary Tools

| Tool | Category | Purpose |
|------|----------|---------|
| `virsh` | VM Management | Command-line interface for managing KVM/libvirt VMs |
| `virt-manager` | GUI VM Manager | Graphical interface for creating and managing VMs |
| `VBoxManage` | VM Management | VirtualBox command-line VM management tool |
| `VBoxHeadless` | VirtualBox | Run VirtualBox VMs in headless (background) mode |
| `kvm-ok` | Utility | Check if CPU supports hardware virtualisation extensions |
| `qemu-img` | Disk Utility | Create and manage QEMU disk image formats |
| `vagrant` | Provisioning | Tool for building and managing portable VM environments |
| `docker` | Container Runtime | Lightweight containerisation alternative to VMs (uses host kernel) |
