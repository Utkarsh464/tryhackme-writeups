# Tools: Packets and Frames

## Primary Tools

| Tool | Category | Purpose |
|------|----------|---------|
| Wireshark | Packet Analysis | Deep inspection of hundreds of protocols |
| tcpdump | Packet Capture | Command-line packet capture |

## Related Tools

| Tool | Purpose |
|------|---------|
| tshark | CLI version of Wireshark for scripting and analysis |
| Scapy | Python library for crafting and dissecting packets |
| Nmap | Network discovery with custom packet crafting |
| netstat | View active network connections and their states |
