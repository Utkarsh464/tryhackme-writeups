# Packets and Frames

## Room Information
- **Room URL:** https://tryhackme.com/room/packets-and-frames
- **Module:** Network Fundamentals
- **Difficulty:** Very Easy
- **Estimated Time:** 20-30 min
- **Access:** Free

## Description
This room explores the structure of data units used in network communication. Students learn about TCP segments, UDP datagrams, IP packets, and Ethernet frames — their headers, fields, and how they encapsulate data at each layer of the OSI model.

Understanding the exact structure of packets and frames is essential for network analysis, troubleshooting, and security. When analysing network traffic with tools like Wireshark, recognizing header fields helps identify attacks, diagnose performance issues, and understand protocol behavior.

## Learning Objectives
- Describe the structure of a TCP segment and its header fields
- Differentiate between TCP and UDP datagrams
- Identify fields in an IP packet header
- Explain the Ethernet frame structure
- Understand the encapsulation/de-encapsulation process

## Key Tools and Technologies
- Wireshark
- tcpdump
- Scapy

## Prerequisites
- OSI Model
- Intro to LAN

## Expected Outcomes
Students will be able to identify and describe the headers of TCP segments, UDP datagrams, IP packets, and Ethernet frames, and explain how data is encapsulated as it traverses the network stack.
