# Tasks: OSI Model

## Task 1: What is the OSI Model?
**Purpose:** Understand the purpose of the OSI model.

**Skills:** Conceptual framework understanding.

**Theory:** The OSI model is a 7-layer framework that standardizes network communication. Each layer handles a specific aspect of data transmission, from physical electrical signals to application data. The model helps vendors create interoperable products and helps professionals troubleshoot network issues.

## Task 2: Layer 1 - Physical
**Purpose:** Learn about the Physical layer.

**Skills:** Layer 1 understanding.

**Theory:** The Physical layer handles the raw transmission of bits over a physical medium (copper wire, fiber optic cable, radio waves). It defines voltage levels, cable types, connector types, and data rates. Devices include hubs, repeaters, and network cables.

**Commands:** N/A

---

## Task 3: Layer 2 - Data Link
**Purpose:** Learn about the Data Link layer.

**Skills:** Layer 2 understanding.

**Theory:** The Data Link layer handles node-to-node communication and error detection. It packages data into frames, adds MAC addresses, and manages access to the physical medium. Switches operate at Layer 2. Protocols include Ethernet and PPP.

**Commands:** N/A

---

## Task 4: Layer 3 - Network
**Purpose:** Learn about the Network layer.

**Skills:** Layer 3 understanding.

**Theory:** The Network layer handles routing and logical addressing (IP addresses). It determines the best path for data to travel from source to destination across multiple networks. Routers operate at Layer 3. The primary protocol is IP (IPv4 and IPv6).

**Commands:** N/A

---

## Task 5: Layer 4 - Transport & Upper Layers
**Purpose:** Learn about the Transport, Session, Presentation, and Application layers.

**Skills:** Layers 4-7 understanding.

**Theory:** The Transport layer (Layer 4) provides reliable (TCP) or unreliable (UDP) data delivery. The Session layer (Layer 5) manages connections. The Presentation layer (Layer 6) translates data formats. The Application layer (Layer 7) is where user-facing protocols like HTTP, FTP, and DNS operate.
