# OSI Model

## Room Information

## Description
This room explains the OSI (Open Systems Interconnection) model, a conceptual framework that standardizes network communication into seven distinct layers. Students learn each layer from Physical to Application, the protocols that operate at each layer, and how data is encapsulated as it travels down the stack.

The OSI model is one of the most important foundational concepts in networking and cybersecurity. Understanding which layer a protocol or attack operates at helps security professionals diagnose issues, design secure networks, and understand how attacks like ARP spoofing (Layer 2) or SQL injection (Layer 7) target specific layers.

## Learning Objectives
- List the 7 layers of the OSI model in order
- Describe the function of each layer
- Identify protocols associated with each layer
- Explain data encapsulation and de-encapsulation

## Key Tools and Technologies
- Wireshark
- TCP/IP stack
- Various Layer 2-7 protocols

## Prerequisites
- Networking Fundamentals
- Intro to LAN

## Expected Outcomes
Students will be able to recite the OSI model layers, describe their functions, and identify which layer a given protocol or device operates at.
