# Tools: OSI Model

## Primary Tools

| Tool | Category | Purpose |
|------|----------|---------|
| Wireshark | Packet Analysis | Capture and inspect packets at all OSI layers |
| tcpdump | Packet Capture | Command-line packet capture tool |

## Related Tools

| Tool | Purpose |
|------|---------|
| Nmap | Network discovery and OSI Layer 3/4 scanning |
| netstat | Display network connections and listening ports |
| traceroute | Map network path between hosts (Layer 3) |
| ping | Test IP-level connectivity (Layer 3) |
