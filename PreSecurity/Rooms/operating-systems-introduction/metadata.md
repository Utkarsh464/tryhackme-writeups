# Operating Systems Introduction

## Room Information
- **Room URL:** https://tryhackme.com/room/operating-systems-introduction
- **Module:** Operating Systems Basics
- **Difficulty:** Very Easy
- **Estimated Time:** 20-30 min
- **Access:** Free

## Description
This room introduces the core concepts of operating systems — what they are, how they manage hardware and software resources, and the major kernel architecture types. Students explore process scheduling, memory management, file systems, and the role of the shell/user interface.

Understanding OS fundamentals is essential for every cybersecurity professional. Exploits target kernel vulnerabilities, process memory, file system permissions, and scheduler behaviour. This foundation is required before learning about OS-specific security hardening.

## Learning Objectives
- Define an operating system and describe kernel types (monolithic, microkernel, hybrid)
- Explain process scheduling, memory management, and file system concepts
- Understand the role of device drivers and the user interface (shell/UI)

## Key Tools and Technologies
- Linux kernel, Windows NT kernel
- ext4, NTFS
- Bash, PowerShell
- systemd, process scheduler

## Prerequisites
- None

## Expected Outcomes
- Describe how an OS manages processes, memory, and storage through its kernel and core subsystems.
