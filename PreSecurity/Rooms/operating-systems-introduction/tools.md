# Tools: Operating Systems Introduction

## Primary Tools

| Tool | Category | Purpose |
|------|----------|---------|
| `uname` | System Info | Display kernel and OS information |
| `ps` | Process Info | Snapshot of current running processes |
| `top` | Process Monitor | Real-time interactive process viewer |
| `htop` | Process Monitor | Enhanced interactive process viewer |
| `free` | Memory Monitor | Display RAM and swap usage |
| `vmstat` | System Stats | Report virtual memory, processes, and CPU activity |
| `nice` | Process Control | Run a process with modified scheduling priority |
| `lsblk` | Storage Utility | List block storage devices with file system info |
| `stat` | File Info | Display detailed file metadata and attributes |
| `lsmod` | Kernel Info | List loaded kernel modules |
| `modinfo` | Kernel Info | Show detailed kernel module information |
