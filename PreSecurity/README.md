## Learning Path Overview

The **Pre-Security** path on TryHackMe is an entry-level curriculum designed to take someone with zero technical background and equip them with a solid, practical understanding of how modern technology works and how it can be attacked and defended.

| Status | Detail |
|--------|--------|
| **All Modules** | `COMPLETED` — 7 modules covering fundamentals |
| **Certificate** | `pre_security.pdf` — SEC0 Professional Certification |

Each module contains interactive rooms (virtual machines, challenges, guided exercises) that reinforce the topic through hands-on application. This handbook documents every room with explanations, key takeaways, and reference material.

## Module Breakdown

### Module 01 — Introduction to Cyber Security
First steps into the field. Covers offensive vs defensive security, career pathways, and ethical considerations.
- **Rooms:** Offensive Security Intro, Defensive Security Intro, Careers in Cyber
- **Key Outcomes:** Understand red vs blue team roles, CIA triad, ethical hacking principles

### Module 02 — Network Fundamentals
Build an understanding of how devices communicate across networks.
- **Rooms:** Networking Fundamentals, Intro to LAN, OSI Model, Packets & Frames, Extending Your Network
- **Key Outcomes:** Understand OSI/TCP-IP models, common protocols, ports, subnetting, routing

### Module 03 — How The Web Works
Dissect the full stack of web technology from DNS to browser rendering.
- **Rooms:** DNS in Detail, HTTP in Detail, How Websites Work, Putting It All Together
- **Key Outcomes:** Understand DNS resolution, HTTP methods/status codes, full request lifecycle

### Module 04 — Computer Fundamentals
Explore the physical and logical components of computer systems.
- **Rooms:** Inside a Computer, Computer Types, Client-Server Basics, Virtualisation Basics, Cloud Computing
- **Key Outcomes:** Understand CPU, RAM, storage, cloud deployment models

### Module 05 — Operating Systems Basics
Cover the two dominant OS families: Windows and Linux.
- **Rooms:** OS Introduction, Windows Basics, Linux CLI Basics, Windows CLI Basics, OS Security
- **Key Outcomes:** Navigate CLI, manage files/processes, understand permissions

### Module 06 — Software Basics
Bridge hardware and software — data representation, programming, and databases.
- **Rooms:** Data Representation, Data Encoding, Python Basics, JavaScript Basics, Database SQL Basics
- **Key Outcomes:** Binary/hex, Python/JavaScript syntax, SQL queries

### Module 07 — Attacks and Defenses
Synthesize everything into practical attack and defense scenarios.
- **Rooms:** The CIA Triad, Cryptography Concepts, Become a Hacker, Become a Defender
- **Key Outcomes:** Understand kill chain, MITRE ATT&CK, command injection, incident response
