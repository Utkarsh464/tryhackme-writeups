# Module 07: Attacks and Defenses

## Module Name
Attacks and Defenses

## Description
This module synthesises everything learned in the path into practical security scenarios. It examines how attackers think, the methodologies they employ, and how defenders can detect, respond to, and prevent these techniques. Students learn about the CIA Triad (Confidentiality, Integrity, Availability), fundamental cryptography concepts (encryption, hashing, digital signatures), the Cyber Kill Chain framework, and the MITRE ATT&CK knowledge base. The module includes hands-on experience with command injection attacks and incident response simulations, providing practical context for the theoretical concepts.

## Learning Objectives
- Understand the CIA Triad and its application to security
- Explain basic cryptography concepts (symmetric, asymmetric, hashing)
- Describe the stages of the Cyber Kill Chain
- Understand the MITRE ATT&CK framework structure
- Perform a command injection attack
- Follow an incident response process

## Skills

## Prerequisites
- All previous modules (01-06)

## Expected Outcomes
After completing this module, students will understand how to apply the CIA triad to evaluate security, recognise different cryptographic primitives, describe attack methodologies using Cyber Kill Chain and MITRE ATT&CK, exploit command injection vulnerabilities, and follow a structured incident response process.
