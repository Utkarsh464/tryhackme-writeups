# Module 02: Network Fundamentals

## Module Name
Network Fundamentals

## Description
Networking is the backbone of all modern computing. This module builds an understanding of how devices communicate across local and wide-area networks, the protocols that govern this communication, and the infrastructure that makes it all possible. Students will learn about the OSI and TCP/IP models, IP addressing and subnetting, core networking protocols (TCP, UDP, ICMP, ARP), common ports and services, and networking devices such as switches, routers, and firewalls. The module also covers how networks can be extended through technologies like NAT, DHCP, VLANs, and VPNs. By the end of this module, learners will have a solid grasp of how data travels across networks and the fundamental building blocks of network communication.

## Learning Objectives
- Understand the OSI and TCP/IP networking models
- Identify common protocols at each layer
- Explain IP addressing, subnetting, and CIDR notation
- Differentiate between TCP and UDP
- Understand the role of switches, routers, and firewalls
- Explain NAT, DHCP, DNS, and VPN technologies

## Skills
- Network layer identification
- Protocol analysis fundamentals
- IP addressing and subnet calculation
- Understanding of network devices and their roles
- Basic network troubleshooting concepts

## Technologies
- Ethernet
- TCP/IP protocol suite
- DNS and DHCP
- NAT and VPN technologies

## Tools
- Command-line network utilities (ping, traceroute, nslookup)
- Basic network analysis concepts

## Prerequisites
- Basic computer literacy
- Completion of Module 01 (recommended)

## Expected Outcomes
After completing this module, students will understand how data flows through a network, be able to identify which protocols operate at each OSI layer, understand IP addressing and subnetting fundamentals, and recognise the function of key networking devices and technologies.
