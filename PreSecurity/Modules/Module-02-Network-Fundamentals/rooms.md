# Rooms: Network Fundamentals

## Room 1: Networking Fundamentals

**Room URL:** https://tryhackme.com/room/networkingfundamentals

**Description:** This room provides a comprehensive introduction to computer networking, covering the core concepts that underpin all modern communication. Students learn about network types (LAN, WAN, MAN), network topologies, and the fundamental principles of data transmission. The room establishes the vocabulary and conceptual framework needed for all subsequent networking topics.

**Key Topics:**
- What is a network
- LAN, WAN, MAN definitions
- Network topologies (star, bus, ring, mesh)
- Data transmission basics
- Network performance metrics

---

## Room 2: Intro to LAN

**Room URL:** https://tryhackme.com/room/introtolan

**Description:** This room dives into Local Area Networks (LANs) — the most common type of network found in homes, schools, and businesses. Students learn about LAN components including switches, routers, and access points. The room covers Ethernet operation, MAC addressing, ARP protocol, and how devices discover each other on a local network segment.

**Key Topics:**
- LAN components and architecture
- Ethernet and MAC addresses
- ARP (Address Resolution Protocol)
- Switch operation
- Wireless LAN basics

---

## Room 3: OSI Model

**Room URL:** https://tryhackme.com/room/osi

**Description:** This room teaches the OSI (Open Systems Interconnection) model — the conceptual framework that standardises network communication into seven distinct layers. Students learn the function of each layer, the protocols that operate at each layer, and how data encapsulation works as information travels down and up the stack. The OSI model provides a universal language for describing and troubleshooting network issues.

**Key Topics:**
- Seven OSI layers
- Layer functions and protocols
- Data encapsulation
- Layer interactions
- Troubleshooting with OSI model

---

## Room 4: Packets & Frames

**Room URL:** https://tryhackme.com/room/packetsframes

**Description:** This room explores the fundamental units of network data: packets and frames. Students learn the structure of TCP and UDP segments, IP packets, and Ethernet frames. The room covers header fields, how data is encapsulated at each layer, and how packet-switched networks route data from source to destination. Understanding packet structure is essential for network analysis and security.

**Key Topics:**
- Packet and frame structure
- TCP header fields
- UDP header fields
- IP packet structure
- Ethernet frame structure
- Encapsulation and decapsulation

---

## Room 5: Extending Your Network

**Room URL:** https://tryhackme.com/room/extendingyournetwork

**Description:** This room covers technologies used to extend networks beyond a single LAN segment. Students learn about Network Address Translation (NAT), which allows multiple devices to share a single public IP address, Dynamic Host Configuration Protocol (DHCP) for automatic IP assignment, and Virtual Private Networks (VPNs) for secure remote connectivity. The room also introduces subnetting concepts and routing fundamentals.

**Key Topics:**
- NAT and port forwarding
- DHCP operation
- VPN technologies
- Subnetting and CIDR
- Routing fundamentals
- Firewall basics
