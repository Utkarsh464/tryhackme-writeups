# Module 01: Introduction to Cyber Security

## Module Name
Introduction to Cyber Security

## Description
This module serves as the entry point for beginners starting their cybersecurity education. It introduces the foundational concepts of information security, distinguishing between offensive security (ethical hacking, penetration testing) and defensive security (blue team operations, monitoring, incident response). The module also explores the cybersecurity career landscape, helping learners understand the various roles and pathways available in the industry. By the end of this module, learners will understand the ethical and legal boundaries of security testing, the key responsibilities of different security professionals, and the value that cybersecurity brings to organisations. This module is designed for absolute beginners with no prior security experience.

## Learning Objectives
- Understand the difference between offensive and defensive security
- Identify key responsibilities of red team and blue team professionals
- Recognise common attack types and defence mechanisms
- Understand the penetration testing methodology
- Explore cybersecurity career pathways
- Understand ethical and legal boundaries of security testing

## Prerequisites
- Basic computer literacy
- Ability to browse the web
- No prior cybersecurity experience required

## Expected Outcomes
After completing this module, students will be able to differentiate between offensive and defensive security roles and methodologies. They will understand the ethical framework governing penetration testing and have hands-on experience with basic exploitation and monitoring concepts. This foundational knowledge prepares learners for deeper technical modules in networking, operating systems, and security analysis.
