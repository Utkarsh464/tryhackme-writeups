# Rooms: Introduction to Cyber Security

## Room 1: Offensive Security Intro

**Room URL:** https://tryhackme.com/room/offensivesecurityintro

**Description:** This room introduces the concept of offensive security, commonly known as ethical hacking or penetration testing. Students learn about the hacker mindset, the penetration testing methodology, and get hands-on experience exploiting a vulnerable web application. The room covers key concepts such as reconnaissance, exploitation, and the ethical and legal boundaries of security testing. It provides a realistic but safe environment to understand how attackers think and operate.

**Key Topics:**
- What is offensive security
- Penetration testing methodology
- Ethical hacking principles
- Basic exploitation techniques
- Legal and ethical boundaries

## Room 2: Defensive Security Intro

**Room URL:** https://tryhackme.com/room/defensivesecurityintro

**Description:** This room focuses on the defensive side of cybersecurity, introducing the blue team's role in protecting organisations from cyber threats. Students learn about security operations centres (SOCs), incident detection and response, digital forensics, and security monitoring. The room covers tools and techniques used by defenders to identify, analyse, and mitigate security incidents in real time, including a hands-on incident response simulation.

**Key Topics:**
- What is defensive security
- Security Operations Centre (SOC) roles
- Incident detection and analysis
- Digital forensics fundamentals
- Threat intelligence and monitoring

## Room 3: Careers in Cyber

**Room URL:** https://tryhackme.com/room/careersincyber

**Description:** This room explores the breadth of cybersecurity career opportunities available to aspiring professionals. It covers the various roles within the industry — from penetration tester and SOC analyst to security engineer, forensic analyst, and CISO. The room emphasises that entry-level hiring prioritises practical, hands-on experience over certifications and provides guidance on how to build a portfolio, participate in CTF competitions, and create effective write-ups.

**Key Topics:**
- Cybersecurity career pathways
- Role requirements and responsibilities
- Building a portfolio and home lab
- Certifications and learning paths
- Industry demand and salary expectations
