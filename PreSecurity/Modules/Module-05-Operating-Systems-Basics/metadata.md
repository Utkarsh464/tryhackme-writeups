# Module 05: Operating Systems Basics

## Module Name
Operating Systems Basics

## Description
An operating system (OS) manages hardware resources, provides services to applications, and mediates user interaction. This module covers the two dominant OS families: Windows and Linux. Students learn what an OS is, its core components (kernel, process scheduler, memory manager, file system, device drivers), and how it manages processes, memory, and files. The module provides hands-on experience with both Windows and Linux command-line interfaces, teaching essential commands for file management, process control, and system administration. Security concepts including user accounts, permissions, UAC, and OS security best practices are also covered.

## Learning Objectives
- Understand the role and components of an operating system
- Navigate the Linux filesystem using CLI commands
- Navigate the Windows CLI (Command Prompt and PowerShell)
- Manage files, processes, and permissions
- Understand OS security concepts and best practices

## Skills
- Linux command-line proficiency
- Windows command-line proficiency
- File system navigation
- Process and permission management
- OS security awareness

## Technologies
- Linux (Ubuntu/Debian family)
- Microsoft Windows
- NTFS and ext4 file systems
- Command-line interfaces

## Tools
- Linux CLI tools (ls, cd, cat, cp, mv, rm, chmod, ps, grep, find)
- Windows CLI tools (dir, ipconfig, netstat, tasklist, systeminfo)
- PowerShell

## Prerequisites
- Module 04 (Computer Fundamentals) recommended

## Expected Outcomes
After completing this module, students will be comfortable navigating both Linux and Windows systems using the command line, managing files and processes, understanding the permission model on each OS, and applying basic OS security principles.

## Duration
Approximately 2 hours 20 minutes total

## Difficulty
Very Easy
