# Module 06: Software Basics

## Module Name
Software Basics

## Description
This module bridges the gap between hardware and application software by introducing how computers represent and manipulate data, how programs are structured, and the basics of three widely used programming languages. Students learn about binary representation, number systems (binary, octal, decimal, hexadecimal), and character encoding (ASCII, Unicode). The module provides introductory hands-on experience with Python, JavaScript, and SQL — three languages that are essential for cybersecurity professionals. By the end of this module, learners will understand how computers store and process data and will have written their first programs.

## Learning Objectives
- Understand binary representation and number systems
- Explain character encoding schemes (ASCII, Unicode, base64)
- Write basic Python programs with variables, conditionals, loops, and functions
- Write basic JavaScript programs for web interactivity
- Write SQL queries to interact with databases
- Understand SQL injection as a security vulnerability

## Skills
- Data representation literacy
- Basic Python programming
- Basic JavaScript programming
- SQL query writing
- Security-aware coding mindset

## Technologies
- Python 3
- JavaScript (ES6+)
- SQL (SQLite, MySQL)
- Web browsers (for JavaScript)

## Tools
- Python interpreter
- Node.js / browser console
- SQL database tools

## Prerequisites
- Basic computer literacy

## Expected Outcomes
After completing this module, students will understand how computers represent data, be able to write simple programs in Python and JavaScript, be able to query databases using SQL, and understand how SQL injection attacks work at a conceptual level.
