# Module 03: How The Web Works

## Module Name
How The Web Works

## Description
The web is the primary attack surface in modern cybersecurity. This module dissects the full stack of web technology — from DNS resolution and HTTP protocol mechanics to the client-side technologies that render content in the browser. Students will learn how domain names are resolved to IP addresses through the DNS hierarchy, how HTTP requests and responses are structured and transmitted, and how websites are built using HTML, CSS, and JavaScript. The module culminates by tracing the complete lifecycle of a web request from URL entry to page rendering, providing a holistic understanding of web technology.

## Learning Objectives
- Understand DNS hierarchy and record types
- Explain the DNS resolution process
- Understand HTTP request methods and response status codes
- Identify key HTTP headers and their purposes
- Understand the roles of HTML, CSS, and JavaScript
- Trace the complete web request lifecycle

## Skills
- DNS query and resolution understanding
- HTTP request/response analysis
- Web technology stack comprehension
- Browser rendering process awareness

## Technologies
- DNS
- HTTP/HTTPS
- HTML, CSS, JavaScript
- Web browsers

## Tools
- Command-line DNS tools (nslookup, dig, host)
- curl
- Browser developer tools

## Prerequisites
- Basic computer literacy
- Module 02 (Network Fundamentals) recommended

## Expected Outcomes
After completing this module, students will understand how domain names are resolved, how HTTP communication works, how websites are structured and rendered, and be able to trace the full path of a web request. This knowledge is essential for web security topics including OWASP Top 10, SQL injection, and XSS.
