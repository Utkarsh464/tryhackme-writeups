# Module 04: Computer Fundamentals

## Module Name
Computer Fundamentals

## Description
Before you can secure technology, you must understand how it works. This module explores the physical and logical components that constitute a computer system, from transistors to cloud infrastructure. Students learn about internal hardware architecture including the CPU, RAM, storage devices, motherboard, and GPU. The module also covers different types of computer systems (desktops, laptops, servers, embedded systems), the client-server model, virtualisation technology, and cloud computing. By the end of this module, learners will have a comprehensive understanding of how computers are built, categorised, and deployed in modern environments.

## Learning Objectives
- Identify and explain the function of key internal hardware components
- Differentiate between types of computer systems
- Understand the client-server architectural model
- Explain virtualisation concepts and hypervisors
- Describe cloud computing service and deployment models

## Skills
- Hardware component identification and understanding
- Computer system classification
- Client-server architecture comprehension
- Virtualisation awareness
- Cloud computing literacy

## Technologies
- CPU architectures (x86, ARM)
- Memory technologies (DDR, NAND)
- Storage technologies (HDD, SSD, NVMe)
- Virtualisation platforms
- Cloud computing (IaaS, PaaS, SaaS)

## Tools
- System information utilities
- Virtual machine software concepts

## Prerequisites
- Basic computer literacy

## Expected Outcomes
After completing this module, students will understand how computers are built and categorised, the client-server model that underpins most networked applications, and how virtualisation and cloud computing extend traditional computing capabilities.

## Duration
Approximately 2 hours 10 minutes total
