## Where Pre-Security Fits in Cybersecurity

The Pre-Security path is the first stepping stone into cybersecurity. It provides the foundational knowledge required before specialising in offensive or defensive roles.

```
                      ┌─────────────────────────────────────────┐
                      │         CYBERSECURITY LANDSCAPE          │
                      ├──────────────┬──────────────┬────────────┤
                      │  OFFENSIVE   │   DEFENSIVE   │   GOVERNANCE│
                      │  (Red Team)  │  (Blue Team)  │  (GRC)      │
├─────────────────────┼──────────────┼──────────────┼────────────┤
│ Mod 01: Intro       │  Foundation  │  Foundation  │  Foundation │
│ Mod 02: Networking  │  Foundation  │  Foundation  │  —          │
│ Mod 03: Web         │  Foundation  │  Foundation  │  —          │
│ Mod 04: Computer    │  Foundation  │  Foundation  │  —          │
│ Mod 05: OS Basics   │  Foundation  │  Foundation  │  —          │
│ Mod 06: Software    │  Foundation  │  Foundation  │  —          │
│ Mod 07: Attacks     │  Foundation  │  Foundation  │  Foundation │
└─────────────────────┴──────────────┴──────────────┴────────────┘
```

**Key Insight:** Pre-Security is the **common foundation** for all cybersecurity roles. Every subsequent specialisation builds on this base.

## Next Recommended Paths

After completing Pre-Security, these TryHackMe learning paths are the natural next step:

### 1. Cyber Security 101 (Recommended First)
- **Focus:** Expanded foundations with hands-on tooling
- **Key modules:** Linux, web hacking, network security, Windows, Python, privilege escalation, Metasploit, Burp Suite
- **Estimated time:** 80-100 hours
- **Leverages from Pre-Security:** All modules provide prerequisite knowledge

### 2. SOC Level 1
- **Focus:** Defensive security, SIEM (Splunk, ELK), incident response, threat intelligence
- **Key modules:** Network traffic analysis, endpoint monitoring, phishing analysis
- **Prepares you for:** BTL1 (Blue Team Level 1) certification
- **Estimated time:** 50-70 hours
- **Leverages from Pre-Security:** Mod 02 (Networking), Mod 07 (Attacks & Defenses)

### 3. Jr Penetration Tester
- **Focus:** Web exploitation, network penetration testing, report writing
- **Key modules:** OWASP Top 10, buffer overflows, network exploitation
- **Prepares you for:** eJPT certification
- **Estimated time:** 40-60 hours
- **Leverages from Pre-Security:** Mod 03 (Web), Mod 06 (Software)

### 4. Cyber Defence
- **Focus:** Digital forensics, memory analysis, malware analysis, threat hunting
- **Key modules:** Forensics, memory forensics, YARA, threat intelligence
- **Prepares you for:** GCFA, CHFI certifications
- **Estimated time:** 50-80 hours
