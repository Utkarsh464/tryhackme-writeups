# Module 4: Computer Fundamentals — Quick Reference

## Key Concepts
- **CPU**: Central Processing Unit — executes instructions (fetch-decode-execute cycle)
- **CPU Components**: ALU (arithmetic logic), Control Unit (instruction coordination), Registers (fast internal storage)
- **RAM**: Random Access Memory — volatile, fast, stores active data/processes
- **Storage Types**: HDD (mechanical, slower, cheaper, larger), SSD (flash, fast, durable), NVMe (very fast, direct PCIe)
- **Volatile vs Non-Volatile**: RAM loses data on power loss; storage (SSD/HDD) retains data
- **Cloud Models**: IaaS (infrastructure — VMs, storage), PaaS (platform — database, runtime), SaaS (software — email, Office 365)
- **Cloud Deployment**: Public, Private, Hybrid, Multi-cloud
- **Virtualisation**: Hypervisor creates and runs VMs (Type 1: bare-metal like VMware ESXi, Type 2: hosted like VirtualBox)
- **Containers**: Lightweight, share host OS kernel (Docker, LXC)
- **Binary**: Base-2 number system (0s and 1s) — fundamental to all computing
- **Hex**: Base-16 (0-9, A-F) — compact representation of binary, used for memory addresses, MAC addresses, colors

## Binary/Hex Quick Reference

| 10 | 1010 | A |
| 15 | 1111 | F |

## Key Terms
- **Bit**: Smallest data unit (0 or 1)
- **Byte**: 8 bits
- **Clock Speed**: CPU cycles per second (GHz)
- **Cache**: Small, fast CPU memory (L1, L2, L3)
- **Hypervisor**: Software that creates/manages VMs
- **API**: Application Programming Interface
- **SLA**: Service Level Agreement (cloud uptime guarantees)
