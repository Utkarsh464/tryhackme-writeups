# Programming Basics

## Definition
**Python** is a high-level, interpreted language known for readability and extensive libraries (requests, socket, scapy, pwntools). **JavaScript** is the client-side scripting language for web browsers, essential for DOM manipulation, AJAX, and Node.js server-side. **SQL** (Structured Query Language) manages relational databases through queries (SELECT, INSERT, UPDATE, DELETE, JOIN).

## Why It Matters
Python dominates security tooling, automation, and exploit development. JavaScript is required for understanding XSS, CSRF, and web application attacks. SQL is foundational for database attacks (SQL injection), data extraction, and log analysis.

## Key Points
- Python: dynamic typing, indentation-scoped, comprehensive standard library
- JavaScript: event-driven, prototypal inheritance, runs in browser/server
- SQL: declarative; operations on sets/relations; joins combine tables
- All three are interpreted (no compile step)

## Common Interview Questions
1. What is the difference between Python and Bash scripting?
**Answer:** Python is a full-featured language with complex data structures; Bash is for command orchestration and file operations.
2. What is an SQL join?
**Answer:** A `JOIN` clause combines rows from two or more tables based on a related column.
3. What is XSS in relation to JavaScript?
**Answer:** Cross-Site Scripting — injecting malicious JS into web pages viewed by others.
