# Computer Hardware

## Definition
Core computer hardware includes the **CPU** (Central Processing Unit — executes instructions), **RAM** (Random Access Memory — volatile, fast storage for active data), **Storage** (HDD/SSD — persistent data), **Motherboard** (connects all components via buses and chipset), and **GPU** (Graphics Processing Unit — parallel computation for rendering and specialized workloads).

## Why It Matters
Understanding hardware is essential for resource planning, vulnerability assessment (e.g., Meltdown/Spectre affected CPU architecture), and forensic analysis. Memory forensics, disk imaging, and performance tuning all require hardware knowledge.

## Key Points
- CPU: clock speed, cores, cache levels (L1, L2, L3)
- RAM: volatile; data lost on power-off; measured in GB
- Storage: SSD > HDD speed; NVMe > SATA
- Motherboard: form factor (ATX, mATX), chipset, expansion slots
- GPU: dedicated vs integrated; VRAM

## Common Interview Questions
1. What is the difference between RAM and storage?
**Answer:** RAM is volatile and fast (active data); storage is persistent and slower (files/database).
2. What components handle networking on a motherboard?
**Answer:** The NIC (Network Interface Controller) may be onboard or an expansion card.
