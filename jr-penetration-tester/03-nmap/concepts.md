# Important Concepts — Network Reconnaissance

| Concept | Description |
|---------|-------------|
| Passive Recon | Gathering info without directly interacting with target |
| Active Recon | Directly probing target systems (generates traffic) |
| OSINT | Open Source Intelligence — publicly available information |
| WHOIS | Domain registration records (registrant, registrar, dates) |
| DNS Records | A, AAAA, MX, NS, TXT, SOA, CNAME — each serves different purpose |
| Certificate Transparency | Public logs of SSL/TLS certs (crt.sh) |
| dnsrecon | Automated DNS enumeration and subdomain discovery |
| dig | Detailed DNS query tool |
| nslookup | DNS lookup utility (simpler than dig) |
| crt.sh | Certificate Transparency search tool |
| curl | HTTP request tool for web server probing |
| netcat (nc) | Swiss-army knife for TCP/UDP connections |
| traceroute | Maps network path from source to destination |
| Ping Sweep | ICMP echo requests to find live hosts |
| Banner Grabbing | Connecting to a service to read its version banner |
