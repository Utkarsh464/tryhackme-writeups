# Important Concepts — Start Your Cyber Security Journey

## Core Concepts

| Concept | Description |
|---------|-------------|
| Offensive Security | Proactively identifying and exploiting vulns to improve security |
| Defensive Security | Monitoring, detecting, and responding to threats |
| Ethical Hacking | Authorised testing with defined rules of engagement |
| Red Team | Simulates real-world attacks to test defences |
| Blue Team | Defends against attacks, monitors, and responds |
| Purple Team | Collaboration between red and blue teams |
| SOC | Security Operations Centre — centralised threat monitoring |
| SIEM | Security Information and Event Management — log aggregation and analysis |
| Incident Response | Structured approach to handling security breaches |
| Threat Intelligence | Data-driven understanding of adversary behaviour |
