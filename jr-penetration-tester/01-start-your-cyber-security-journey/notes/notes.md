# Start Your Cyber Security Journey — Study Notes

## Offensive Security Intro

- Offensive security = breaking into systems, finding vulns, simulating attacker behaviour
- Ethical hacking requires explicit permission (rules of engagement)
- Common tools: Metasploit, Burp Suite, Nmap, Gobuster
- Key methodology: recon → enumeration → exploitation → post-exploitation → reporting

## Defensive Security Intro

- Defensive security = protecting systems, monitoring threats, responding to incidents
- Blue team activities: SOC monitoring, SIEM analysis, digital forensics, malware analysis
- Threat intelligence: understanding adversary TTPs (tactics, techniques, procedures)
- Incident response lifecycle: preparation → detection → containment → eradication → recovery

## Careers in Cyber

- **Red Team:** Penetration tester, ethical hacker, red team operator
- **Blue Team:** SOC analyst, incident responder, threat hunter, forensic analyst
- **Purple Team:** Combines red and blue perspectives
- **GRC:** Governance, risk, and compliance roles
- Entry-level certs: Security+, CEH, TryHackMe paths
- Advanced: OSCP, GPEN, CISSP
