# Important Concepts — Penetration Testing Foundations

## Pentesting Concepts

| Concept | Description |
|---------|-------------|
| Rules of Engagement | Legal scope and boundaries for testing |
| Black Box Testing | No prior knowledge of target |
| Grey Box Testing | Limited knowledge of target |
| White Box Testing | Full knowledge of target (source code, credentials) |
| Information Gathering | Passive collection of public data |
| Enumeration | Active discovery of services and systems |
| Exploitation | Using a vulnerability to gain access |
| Privilege Escalation | Gaining higher-level access |
| Post-Exploitation | Actions after initial compromise |
| Reporting | Documenting findings for stakeholders |

## Security Concepts

| Concept | Description |
|---------|-------------|
| Confidentiality | Data accessible only to authorised parties |
| Integrity | Data cannot be tampered with by unauthorised parties |
| Availability | Systems and data accessible when needed |
| PIM | Privileged Identity Management — who has access |
| PAM | Privileged Access Management — what access allows |
| Bell-LaPadula | No read up, no write down (confidentiality focus) |
| Biba | No read down, no write up (integrity focus) |
| STRIDE | Spoofing, Tampering, Repudiation, Info Disclosure, DoS, Elevation |
| Incident Response | Structured approach to handling security events |
