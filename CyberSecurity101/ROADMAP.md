## Skill Progression Map

### Phase 1 — Foundation (Modules 1–2)
| Skill | Level Achieved |
|-------|---------------|
| Operating system navigation | Proficient in Linux CLI |
| Security terminology & concepts | Understand CIA, risk, threat models |
| Career awareness | Know roles, pathways, certifications |

### Phase 2 — Platform Depth (Modules 3–4)
| Skill | Level Achieved |
|-------|---------------|
| Windows system administration | Navigate GUI and CLI, manage users/services |
| Active Directory concepts | Understand domains, OUs, GPOs, authentication |
| Command line mastery | CMD, PowerShell, bash proficiently |

### Phase 3 — Networking & Cryptography (Modules 5–6)
| Skill | Level Achieved |
|-------|---------------|
| Network protocol analysis | Read packet captures, understand TCP/IP, DNS, HTTP |
| Port scanning & enumeration | Proficient with Nmap, understand service detection |
| Cryptography fundamentals | Distinguish symmetric/asymmetric, crack hashes |

### Phase 4 — Exploitation & Web Hacking (Modules 7–8)
| Skill | Level Achieved |
|-------|---------------|
| Vulnerability exploitation | Use Metasploit for scanning, exploitation, pivoting |
| Web application testing | Identify XSS, SQLi, IDOR, use Burp Suite |
| CVE research & application | Understand real-world vulnerability disclosure |

### Phase 5 — Tooling & Defensive (Modules 9–12)
| Skill | Level Achieved |
|-------|---------------|
| Offensive tooling | Hydra, Gobuster, SQLMap, reverse/bind shells |
| SOC operations | Understand SIEM, firewalls, IDS/IPS, vulnerability scanners |
| Digital forensics & IR | Forensics chain of custody, incident response lifecycle |
| Malware analysis tools | CyberChef, CAPA, REMnux, FlareVM |

### Phase 6 — Career & Capstone (Modules 13–14)
| Skill | Level Achieved |
|-------|---------------|
| Security principles | CIA triad, defense in depth, least privilege, risk management |
| Career planning | Understand roles, certification paths, training impact |
| OWASP Top 10 2025 | Identify, exploit, and remediate all 10 categories |
