# Nmap: The Basics — Tools

- **Nmap (Network Mapper):** The primary tool for network discovery and security auditing. Open-source and cross-platform. Supports dozens of scan types, output formats, and scripting capabilities.
- **NSE (Nmap Scripting Engine):** A built-in scripting engine that extends Nmap with custom Lua scripts. Ships with hundreds of pre-installed scripts for discovery, vulnerability detection, exploitation, and brute-forcing.
- **Zenmap:** The official GUI frontend for Nmap. Provides interactive visualization of scan results and simplified scan configuration.
- **Ndiff:** A tool that compares Nmap scan results, useful for detecting changes in network configuration over time.
- **Ncat:** A networking utility included with Nmap that can read and write data across networks. Useful for debugging and testing.
