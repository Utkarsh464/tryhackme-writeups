# Room: Nmap: The Basics

- **URL:** https://tryhackme.com/room/nmapthebasics
- **Description:** An introductory room covering Nmap, the most widely used network scanning and discovery tool. Learners will use Nmap to discover live hosts, identify open ports and running services, detect operating systems, and leverage the Nmap Scripting Engine (NSE) for advanced reconnaissance. The room emphasizes scan types (SYN scan, connect scan, UDP scan), timing options, output formats, and the ethical use of scanning techniques in penetration testing.
- **Difficulty:** Easy
- **Time:** ~1 hour
- **Tier:** Premium
- **Objectives:**
  - Perform host discovery using ping sweeps
  - Execute TCP SYN and TCP Connect scans to identify open ports
  - Perform UDP scans and understand their limitations
  - Detect operating systems and service versions
  - Use NSE scripts for enumeration and vulnerability detection
  - Output scan results in various formats (normal, XML, grepable)
  - Apply timing and performance options for efficient scanning
- **Tools:** Nmap, NSE
- **Concepts:** Port scanning, SYN scan, service detection, OS fingerprinting, NSE
