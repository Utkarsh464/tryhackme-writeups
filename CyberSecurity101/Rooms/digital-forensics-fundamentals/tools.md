# Digital Forensics Fundamentals - Tools

## FTK Imager
FTK Imager (Forensic Toolkit Imager) by AccessData is a free forensic imaging tool that creates perfect copies of digital evidence. It supports creating forensic images in multiple formats (raw/dd, E01, AFF), previewing disk contents before acquisition, mounting images for read-only exploration, and capturing volatile memory. FTK Imager's wizard-driven interface makes it accessible to beginners while providing advanced features for experienced examiners. It can image local drives, removable media, network shares, and RAM. The tool also provides basic analysis capabilities including file viewing, hex viewing, and keyword searching. FTK Imager runs on Windows and Linux and is widely used in law enforcement and corporate investigations.

## Autopsy and The Sleuth Kit
Autopsy is a graphical digital forensics platform built on The Sleuth Kit (TSK), a collection of command-line forensic analysis tools. Autopsy provides a user-friendly interface for ingesting evidence sources, analyzing file systems, recovering deleted files, extracting registry artifacts, building timelines, and generating reports. The Sleuth Kit command-line tools (fls, icat, mmls, fsstat, istat) provide granular access to file system data structures. Autopsy supports plug-in architecture for extensibility, with modules for email analysis, media analysis, hash set filtering, and geo-location. It is the most widely used open-source digital forensics suite.

## Volatility
Volatility is the leading open-source memory forensics framework, written in Python. It supports analysis of memory dumps from Windows, Linux, macOS, and Android systems. Volatility includes dozens of plugins organized by function: process listing and enumeration, network connection analysis, registry hive extraction, password hash dumping, injected code detection (malfind), kernel object analysis, and timeline generation. Volatility 3 is a complete rewrite that supports multiple memory dump formats (RAW, crash dumps, VMware, Hyper-V, VirtualBox) without requiring profile files. Memory forensics with Volatility can detect advanced malware that operates entirely in memory without touching disk.

## dd / dcfldd
dd is a standard Unix command-line utility for low-level copying of data. In forensics, dd creates bit-for-bit copies of storage devices. dcfldd (Department of Defense Computer Forensics Lab version of dd) extends dd with forensic-specific features: multiple output destinations for simultaneous imaging, integrated hashing (MD5, SHA-256) with progress display, hashing on the fly (verification during imaging), and status output. dcfldd is pre-installed on Kali Linux and other forensic distributions. While dd is universally available, dcfldd is preferred for forensic work due to its integrity verification features.

## Wireshark
Wireshark is the world's most widely used network protocol analyzer. In digital forensics, Wireshark analyzes packet captures (PCAPs) to investigate network-based attacks, data exfiltration, command and control (C2) traffic, and protocol anomalies. Wireshark features include: deep inspection of hundreds of protocols, live capture and offline analysis, three-pane packet browser, powerful display filters, decryption of encrypted protocols (with keys), VoIP analysis, USB traffic analysis, and reconstruction of transferred files. The tshark command-line variant enables automated and scripted analysis. Wireshark is essential for network forensics investigations.
