# SOC Fundamentals - Tasks

## Task 1: Introduction to SOC
- Understand what a Security Operations Center is
- Learn about the purpose and mission of a SOC
- Understand different SOC models (in-house, MSSP, hybrid)

## Task 2: SOC Team Structure
- Learn about Tier 1 Analyst roles (triage and initial assessment)
- Learn about Tier 2 Analyst roles (investigation and response)
- Learn about Tier 3 Analyst roles (advanced analysis and threat hunting)
- Understand SOC Manager and engineering roles
- Understand the career progression path within a SOC

## Task 3: SOC Tools - SIEM
- Understand what SIEM does (log aggregation, correlation, alerting)
- Learn about common SIEM platforms (Splunk, ELK, QRadar)
- Understand how SIEM rules and correlation generate alerts
- Practice interpreting SIEM dashboards and alerts

## Task 4: SOC Tools - EDR and Endpoint Security
- Understand EDR capabilities (process monitoring, file analysis, network connections)
- Learn how EDR detects suspicious behaviors
- Understand the difference between antivirus and EDR
- Explore EDR investigation workflows

## Task 5: SOC Tools - SOAR and Automation
- Understand SOAR capabilities (playbooks, automation, orchestration)
- Learn how SOAR reduces analyst workload
- Explore common SOAR playbook examples
- Understand the role of automation in SOC efficiency

## Task 6: SOC Tools - Threat Intelligence
- Understand threat intelligence sources (OSINT, commercial feeds, ISACs)
- Learn about indicators of compromise (IoCs) and their types
- Understand how threat intelligence informs SOC operations
- Practice using threat intelligence to enrich alerts

## Task 7: Alert Triage and Classification
- Understand the alert triage process
- Classify alerts by type (malware, phishing, unauthorized access, policy violation)
- Prioritize alerts by severity (critical, high, medium, low)
- Determine when to escalate vs close an alert

## Task 8: Incident Escalation
- Understand escalation criteria and procedures
- Learn the difference between events, alerts, and incidents
- Understand escalation paths based on incident type
- Practice escalating sample incidents appropriately

## Task 9: SOC Processes and Procedures
- Understand shift handover procedures
- Learn about communication protocols within SOC
- Understand ticketing and documentation requirements
- Explore SOC reporting and metrics (MTTD, MTTR, alert volume)

## Task 10: SOC Challenges and Best Practices
- Understand alert fatigue and how to mitigate it
- Learn about SOC staffing and retention challenges
- Explore SOC maturity models (Tier 1 through Tier 4)
- Understand strategies for continuous SOC improvement

## Task 11: Practical Triage Exercise
- Review sample security alerts from various sources
- Apply triage methodology to classify and prioritize each alert
- Make escalation decisions based on severity and context
- Document findings in a standard SOC format
