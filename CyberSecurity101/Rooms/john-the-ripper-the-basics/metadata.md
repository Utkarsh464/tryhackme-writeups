# Room: John the Ripper: The Basics

- **URL:** https://tryhackme.com/room/johntheripperbasics
- **Description:** A hands-on introduction to John the Ripper, one of the most popular password cracking tools. This room teaches learners how to identify hash types, crack passwords using dictionary attacks and brute-force modes, apply rules to wordlists with mangling, and crack various hash formats including MD5, SHA, bcrypt, and NTLM. Emphasis is placed on understanding the factors that determine cracking difficulty, the role of password complexity, and the ethical considerations of password cracking in security assessments.
- **Difficulty:** Easy
- **Time:** ~1 hour
- **Tier:** Premium
- **Objectives:**
  - Install John the Ripper and understand its modes
  - Identify hash types using format identifiers
  - Perform dictionary (wordlist) attacks
  - Apply rules to mutate wordlist entries
  - Use incremental (brute-force) mode for simple passwords
  - Crack various hash formats including Unix, Windows NTLM, and web application hashes
  - Understand the role of password cracking in penetration testing
- **Tools:** John the Ripper
- **Concepts:** Dictionary attack, brute-force, rules, wordlist, hash format, incremental mode
