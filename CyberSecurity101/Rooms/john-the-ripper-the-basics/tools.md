# John the Ripper: The Basics — Tools

- **John the Ripper (john):** The primary password cracking tool. Open-source, community-maintained. Supports hundreds of hash formats across Unix, Windows, web applications, and databases.
- **hash-identifier / hashid:** Python tools that identify hash types from their format. Useful for determining which John format to use.
- **unshadow:** A utility distributed with John that combines /etc/passwd and /etc/shadow for cracking Unix password hashes.
- **RockYou wordlist:** The most commonly used password wordlist, located at /usr/share/wordlists/rockyou.txt on Kali Linux. Contains over 14 million passwords.
- **Crunch:** A wordlist generator that can produce custom wordlists based on character sets and patterns.
- **Johnny:** A GUI frontend for John the Ripper, making it more accessible for users who prefer graphical interfaces.
