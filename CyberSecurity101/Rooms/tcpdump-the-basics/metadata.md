# Room: Tcpdump: The Basics

- **URL:** https://tryhackme.com/room/tcpdumpthebasics
- **Description:** A practical introduction to Tcpdump, the command-line packet capture and analysis tool. Unlike Wireshark's graphical interface, Tcpdump is used entirely from the terminal, making it ideal for remote servers, automation, and low-resource environments. Learners will capture live traffic, apply BPF filters, save captures to pcap files, and perform offline analysis. The room emphasizes filter syntax, output interpretation, and the use of flags for controlling verbosity and format.
- **Difficulty:** Easy
- **Time:** ~1 hour
- **Tier:** Premium
- **Objectives:**
  - Capture packets on a specified network interface
  - Apply BPF filters to narrow capture scope
  - Save captured traffic to a pcap file and read it back
  - Control output verbosity using flags (-v, -vv, -vvv, -q)
  - Interpret Tcpdump's packet output format
  - Use Tcpdump for basic network troubleshooting
- **Tools:** Tcpdump
- **Concepts:** BPF, pcap, promiscuous mode, verbosity levels, offline analysis
