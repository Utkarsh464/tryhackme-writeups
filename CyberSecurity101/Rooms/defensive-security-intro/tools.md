# Defensive Security Intro - Tools

## No specific tools are introduced in this room.

Defensive Security Intro is a conceptual overview room that does not introduce specific software tools. Its purpose is to establish the foundational knowledge and terminology that will be applied in subsequent defensive security rooms where tools like SIEM platforms, EDR agents, forensic analysis tools, and log analysis utilities are covered in depth.

## Reference: Defensive Security Tool Categories

While no tools are covered directly in this room, the following categories of defensive tools are introduced conceptually and will be explored in later rooms:

- **SIEM (Security Information and Event Management)**: Aggregates and analyzes log data from across the organization for real-time monitoring and alerting. Examples: Splunk, ELK Stack, IBM QRadar.
- **EDR (Endpoint Detection and Response)**: Monitors endpoints for suspicious behavior and enables rapid investigation and response. Examples: CrowdStrike, SentinelOne, Microsoft Defender for Endpoint.
- **IDS/IPS (Intrusion Detection/Prevention Systems)**: Monitors network traffic for malicious patterns. Examples: Snort, Suricata, Zeek.
- **DLP (Data Loss Prevention)**: Monitors and controls data movement to prevent unauthorized disclosure. Examples: Symantec DLP, Digital Guardian.
- **Vulnerability Scanners**: Identifies vulnerabilities in systems and applications. Examples: Nessus, Qualys, OpenVAS.
- **Firewalls**: Filters network traffic based on rules. Examples: iptables, pfSense, Palo Alto Networks.
- **Antivirus/Antimalware**: Detects and removes malicious software. Examples: ClamAV, Windows Defender, Sophos.
- **Forensic Tools**: Analyzes digital evidence for investigations. Examples: Autopsy, FTK Imager, Volatility.

These tool categories form the foundation of a defensive security stack. Each will be explored in detail in subsequent rooms and modules of the Cyber Security 101 learning path.
