## Description

Defensive Security Intro is the entry point for learners who want to understand the blue team side of cybersecurity. While offensive security focuses on finding and exploiting vulnerabilities, defensive security concentrates on protecting systems, detecting attacks, and responding to incidents. This room explains the core concepts and philosophies that underpin defensive cybersecurity practices. It begins by defining the CIA triad: Confidentiality (ensuring data is accessible only to authorized parties), Integrity (ensuring data has not been tampered with), and Availability (ensuring systems and data are accessible when needed). The room then introduces defense in depth, the strategy of layering multiple security controls so that if one fails, another compensates. Learners explore the different categories of security controls: preventive (firewalls, encryption, access controls), detective (IDS, log monitoring, antivirus), deterrent (warning banners, security cameras), corrective (backups, patching), and compensating (alternative controls when primary controls are not feasible). The room also covers the principle of least privilege, which states that users and systems should have only the minimum permissions needed to perform their functions. The security lifecycle is introduced as a continuous cycle of identifying assets, protecting them, detecting threats, responding to incidents, and recovering from attacks. By the end of this short room, learners will understand why defensive security is equally as important as offensive security and will be prepared for the more detailed defensive modules that follow.

## Objectives
- Understand the CIA triad and its importance in security
- Explain the defense-in-depth strategy
- Identify different categories of security controls
- Understand the principle of least privilege
- Describe the security lifecycle phases
