# Defensive Security Intro - Tasks

## Task 1: Introduction to Defensive Security
- Understand the difference between offensive and defensive security
- Learn about red team vs blue team roles
- Understand why both perspectives are necessary

## Task 2: The CIA Triad
- Define Confidentiality and how it is protected
- Define Integrity and how it is verified
- Define Availability and how it is maintained
- Understand the trade-offs between the three principles

## Task 3: Defense in Depth
- Understand the concept of layered security
- Learn why no single security control is sufficient
- Explore examples of defense-in-depth implementations

## Task 4: Security Controls
- Understand preventive controls (firewalls, encryption, authentication)
- Understand detective controls (monitoring, logging, IDS)
- Understand deterrent controls (warning banners, policies)
- Understand corrective controls (backups, patching, incident response)
- Understand compensating controls (alternative measures)

## Task 5: Principle of Least Privilege
- Define the principle of least privilege
- Understand why excessive permissions create risk
- Learn how to implement least privilege in practice
- Explore examples of least privilege violations

## Task 6: Security Lifecycle
- Understand the identify-protect-detect-respond-recover cycle
- Learn how each phase contributes to security posture
- Understand that security is a continuous process

## Task 7: Summary and Review
- Review all defensive security concepts
- Understand how these concepts apply in real organizations
- Prepare for more advanced defensive security modules
