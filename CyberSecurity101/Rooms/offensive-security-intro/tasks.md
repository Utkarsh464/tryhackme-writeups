# Tasks: Offensive Security Intro

## Task 1: Understanding Offensive Security

**Purpose:** Learn the definition and importance of offensive security in the cybersecurity landscape.

**Skills:** Conceptual understanding of ethical hacking.

**Theory:** Offensive security involves proactively breaking into systems to find vulnerabilities before malicious attackers do. This is also known as ethical hacking or penetration testing. Unlike defensive security, which focuses on building defenses, offensive security takes an attacker's perspective. Ethical hackers operate with proper authorization and follow a structured methodology.

**Commands:** None

---

## Task 2: Hacking a Web Application

**Purpose:** Gain hands-on experience exploiting a vulnerable web application in a safe environment.

**Skills:** Basic web application exploitation, reconnaissance.

**Theory:** Web applications often have vulnerabilities such as weak authentication, injection flaws, and misconfigurations. In this task, students attack a fake web application by trying default credentials, exploring hidden directories, and exploiting common weaknesses. This demonstrates how attackers gain unauthorized access.

**Commands:** Basic Linux terminal commands for navigation.

---

## Task 3: Hacking a Network

**Purpose:** Experience attacking a network and compromising a machine remotely.

**Skills:** Network scanning, service exploitation.

**Theory:** Networks consist of multiple interconnected devices, each running services that can have vulnerabilities. Attackers scan networks to discover live hosts and open ports, then identify and exploit vulnerable services. This task simulates a real-world penetration testing scenario.

**Commands:** Basic Linux commands for file interaction.

---

## Task 4: Conclusion and Career Pathways

**Purpose:** Summarize the offensive security field and explore career opportunities.

**Skills:** Understanding of cybersecurity roles and career paths.

**Theory:** Offensive security professionals can pursue careers as penetration testers, red team members, vulnerability researchers, and exploit developers. Certifications like OSCP, CEH, and GPEN validate these skills. The room emphasizes the importance of ethics and legal authorization.

**Commands:** None
