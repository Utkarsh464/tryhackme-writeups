# Commands: Offensive Security Intro

## Linux Terminal Commands

| Command | Description |
|---------|-------------|
| `ls` | List directory contents |
| `cd` | Change directory |
| `cat` | Display file contents |
| `echo` | Print text to output |
| `whoami` | Display current username |
| `pwd` | Print working directory |
