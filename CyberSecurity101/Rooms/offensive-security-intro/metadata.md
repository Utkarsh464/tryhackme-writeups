# Offensive Security Intro

## Room Information
- **Room URL:** https://tryhackme.com/room/offensivesecurityintro
- **Module:** Start Your Cybersecurity Journey
- **Difficulty:** Easy
- **Estimated Time:** 30 minutes
- **Access:** Free

## Description
This room introduces the concept of offensive security, also known as ethical hacking or penetration testing. Offensive security involves actively breaking into computer systems, networks, and applications to identify vulnerabilities before malicious attackers can exploit them. Unlike defensive security, which focuses on protecting systems, offensive security takes a proactive approach by simulating attacks to find weaknesses. In this room, students get hands-on experience hacking a web application and a fake company's network. They learn about the penetration testing methodology, which includes reconnaissance, scanning, exploitation, and reporting. The room emphasizes ethical and legal boundaries, teaching that offensive security skills must only be used with proper authorization. Students will understand the difference between white-hat (ethical), grey-hat, and black-hat hackers and why ethical hacking is a legitimate and important cybersecurity profession. This room is designed for complete beginners and provides a fun, engaging first experience with real hacking techniques in a safe, legal environment.

## Learning Objectives
- Define offensive security and ethical hacking
- Understand the penetration testing lifecycle
- Perform basic reconnaissance on a target
- Exploit a vulnerable web application
- Recognize the importance of ethical boundaries

## Key Tools and Technologies

- TryHackMe in-browser machine
- Basic Linux command line

## Prerequisites

## Expected Outcomes
Students will understand what offensive security is, how ethical hackers operate, and the value they provide to organizations. They will have hands-on experience with basic exploitation techniques and understand the legal and ethical framework governing penetration testing.
