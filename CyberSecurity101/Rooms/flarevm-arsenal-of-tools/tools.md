# FlareVM: Arsenal of Tools — Tools

## FlareVM Distribution
- **Description:** FlareVM is a Windows-based malware analysis distribution created by Mandiant (Google Cloud). It installs over 200 tools on top of a standard Windows installation, transforming it into a comprehensive reverse engineering and malware analysis workstation. The installation is managed via PowerShell scripts.
- **Repository:** https://github.com/mandiant/flare-vm
- **Key Tools Installed:**

| Category | Tools |
|----------|-------|
| Debuggers | x64dbg, x32dbg, OllyDbg, WinDbg |
| Disassemblers | IDA Free, Ghidra, dnSpy |
| Hex Editors | HxD, 010 Editor, Hex Editor Neo |
| PE Analyzers | Detect It Easy (DIE), PE-bear, PEview, CFF Explorer |
| Process Tools | Process Monitor, Process Explorer, API Monitor |
| Network Tools | Wireshark, tcpdump, Ncat, RawCap |
| Forensics | RegShot, FTK Imager, Autopsy, KAPE |
| Unpackers | UPX, ExeInfoPE, Quick Unpack |
| Utilities | HashMyFiles, Sysinternals Suite, Total Commander |

- **Use Cases:** Malware analysis, reverse engineering, binary triage, dynamic analysis, and forensic investigation on Windows platforms.
