## Description
This room introduces Active Directory (AD), Microsoft's enterprise directory service that is used by the vast majority of large organizations for identity and access management. Active Directory provides centralized authentication and authorization, allowing users to access resources across a network with a single set of credentials. Understanding AD is critical for cybersecurity professionals because it is a frequent target of attacks, including Kerberoasting, AS-REP roasting, pass-the-hash, golden ticket attacks, and DC compromise. This room covers the core components of Active Directory including domains (administrative boundaries), domain controllers (servers that authenticate users), organizational units (OUs for grouping objects), security groups (for assigning permissions), and Group Policy Objects (GPOs for applying configuration settings). Students learn about authentication protocols used by AD, primarily Kerberos (the default) and NTLM (a legacy protocol). The room also explains trust relationships between domains and forests. Hands-on exercises allow students to explore an Active Directory environment, navigate ADUC (Active Directory Users and Computers), and understand how AD objects are organized.

## Learning Objectives
- Explain the purpose and architecture of Active Directory
- Identify key AD components: domains, domain controllers, OUs, GPOs
- Navigate Active Directory Users and Computers (ADUC)
- Understand Kerberos and NTLM authentication
- Manage users, groups, and computers in AD
- Explain Group Policy and its security applications
- Recognize common Active Directory attack vectors

## Key Tools and Technologies

Students will understand the structure and purpose of Active Directory, be able to navigate its management tools, and recognize common attack paths against AD environments. This knowledge is essential for both offensive and defensive security roles in enterprise environments.
