# Room: Networking Secure Protocols

- **URL:** https://tryhackme.com/room/networkingsecureprotocols
- **Description:** This room focuses on the secure versions of common networking protocols and the cryptographic mechanisms that protect data in transit. Learners explore HTTPS, SSH, SFTP, TLS, IPsec, and DNSSEC, understanding how encryption, authentication, and integrity checking are applied at different layers of the network stack. The room explains why insecure protocols like HTTP, FTP, and Telnet are being phased out in favor of their encrypted counterparts.
- **Difficulty:** Easy
- **Time:** ~30 minutes
- **Tier:** Premium
- **Objectives:**
  - Explain the difference between HTTP and HTTPS and the role of TLS
  - Understand how SSH provides secure remote access and file transfer
  - Describe the TLS handshake process and certificate validation
  - Compare IPsec transport mode vs. tunnel mode
  - Understand DNSSEC and how it protects against DNS spoofing
  - Recognize the importance of protocol security in modern networks
- **Tools:** None required
- **Concepts:** TLS, SSL, HTTPS, SSH, IPsec, DNSSEC, SFTP, encryption, authentication, integrity
