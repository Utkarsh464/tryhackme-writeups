# Networking Secure Protocols — Tools

- **OpenSSL:** A command-line toolkit for TLS/SSL operations. Used to generate certificates, test TLS connections, and inspect certificate details.
- **SSH client (ssh):** Connects to remote hosts securely. Supports key-based and password-based authentication.
- **SFTP client (sftp):** Provides interactive secure file transfer over SSH.
- **curl:** A command-line tool for making HTTP/HTTPS requests with configurable TLS settings.
- **dig:** DNS lookup utility with DNSSEC verification support using the +dnssec flag.
- **strongSwan / libreswan:** Open-source IPsec implementations for Linux.
