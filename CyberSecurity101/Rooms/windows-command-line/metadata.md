## Description
This room introduces the Windows Command Prompt (cmd.exe), the traditional command-line interpreter that has been part of Windows since the early days of the operating system. Despite the rise of PowerShell, the Command Prompt remains widely used for system administration, troubleshooting, and automation tasks. It is particularly important for legacy system support, batch scripting, and quick diagnostic operations. The room covers essential commands for navigation and file management including dir, cd, md (mkdir), rd (rmdir), copy, move, del, and ren. Students learn networking commands such as ipconfig for IP configuration, ping for connectivity testing, tracert for route tracing, nslookup for DNS queries, and netstat for network statistics. System information commands including systeminfo, tasklist, and taskkill are covered for system monitoring and management. The room also introduces batch scripting, teaching students how to create .bat files with basic control flow, and covers commands for disk management, user management, and environment variables. Understanding the Command Prompt is a foundational Windows skill for any cybersecurity professional.

## Learning Objectives
- Navigate the Windows filesystem using Command Prompt
- Manage files and directories from the command line
- Use network diagnostic commands
- View and manage running processes
- Create and execute batch scripts
- Configure system settings via command line
- Understand environment variables

## Key Tools and Technologies
- Command Prompt (cmd.exe)
- Batch scripting
- Windows command-line utilities

## Prerequisites
- Basic Windows familiarity

## Expected Outcomes
Students will be comfortable using the Windows Command Prompt for filesystem navigation, file management, network diagnostics, and process management. They will be able to create simple batch scripts and understand the role of the Command Prompt in Windows administration.
