# Tools: Windows Command Line

## Primary Tool

| Tool | Location | Purpose |
|------|----------|---------|
| Command Prompt (cmd.exe) | C:\Windows\System32\cmd.exe | Windows command-line interpreter for executing commands and batch scripts |

## Filesystem Navigation Tools

| Command | Purpose |
|---------|---------|
| `dir` | List directory contents with various format options |
| `cd` or `chdir` | Display or change current directory |
| `tree` | Display directory structure as a tree |
| `md` or `mkdir` | Create new directories |
| `rd` or `rmdir` | Remove directories |

## File Management Tools

| Command | Purpose |
|---------|---------|
| `copy` | Copy one or more files to another location |
| `move` | Move or rename files and directories |
| `del` or `erase` | Delete one or more files |
| `ren` or `rename` | Rename files or directories |
| `xcopy` | Copy files and directory trees (advanced) |
| `robocopy` | Robust file copy with mirroring and retry capabilities |
| `type` | Display contents of text files |
| `more` | Display file contents one screen at a time |
| `find` | Search for a text string in files |
| `findstr` | Search for patterns using regular expressions in files |

## Networking Tools

| Command | Purpose |
|---------|---------|
| `ipconfig` | Display and manage IP configuration |
| `ping` | Test reachability and round-trip time to hosts |
| `tracert` | Trace the route packets take to a destination |
| `pathping` | Combine ping and tracert with latency analysis |
| `nslookup` | Query DNS servers for name resolution |
| `netstat` | Display active connections, listening ports, and routing tables |
| `route` | Display and modify the local IP routing table |
| `arp` | Display and modify the ARP cache |
| `getmac` | Display MAC addresses of network adapters |

## System Administration Tools

| Command | Purpose |
|---------|---------|
| `systeminfo` | Display comprehensive system configuration information |
| `tasklist` | List all running processes with details |
| `taskkill` | Terminate processes by PID or image name |
| `schtasks` | Schedule commands or programs to run periodically |
| `shutdown` | Shut down, restart, or log off local or remote systems |
| `sfc` | System File Checker for verifying protected system files |
| `chkdsk` | Check disk volumes for file system errors |
| `diskpart` | Disk partition management utility |
| `driverquery` | List installed device drivers and properties |
| `net start` | Start a Windows service |
| `net stop` | Stop a Windows service |

## Environment and Session Tools

| Command | Purpose |
|---------|---------|
| `set` | Display, set, or remove environment variables |
| `echo` | Display messages or toggle command echoing |
| `cls` | Clear the command prompt screen |
| `ver` | Display the Windows version number |
| `title` | Set the window title for the command prompt |
| `color` | Change the foreground and background colors |
| `prompt` | Change the command prompt string |
| `help` | Display help for available commands |
| `exit` | Close the command prompt window |
