# Networking Concepts — Commands

This room is primarily conceptual and does not introduce specific command-line tools. However, the following commands may be referenced for illustrative purposes:

| Command | Description |
|---------|-------------|
| `ip addr` | Display IP addresses and network interfaces on Linux |
| `ifconfig` | Legacy command to display network interface configuration |
| `ping` | Test reachability of a host on the network |
| `arp -a` | Display the ARP cache table |
| `ipconfig` | Display IP configuration on Windows |
