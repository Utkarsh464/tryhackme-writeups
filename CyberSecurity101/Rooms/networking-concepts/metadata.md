# Room: Networking Concepts

- **URL:** https://tryhackme.com/room/networkingconcepts
- **Description:** An introductory room covering the fundamental concepts of computer networking. Learners explore the OSI and TCP/IP models, understand how data is encapsulated as it travels through network layers, and learn about IP addressing and subnetting. The room uses interactive content and quizzes to reinforce key ideas, making it ideal for those with no prior networking experience.
- **Difficulty:** Easy
- **Time:** ~30 minutes
- **Tier:** Premium
- **Objectives:**
  - Understand the seven layers of the OSI model and the four layers of the TCP/IP model
  - Explain data encapsulation and de-encapsulation as data moves through layers
  - Differentiate between IPv4 and IPv6 addressing
  - Understand subnet masks and basic subnetting
  - Identify the role of MAC addresses at the data link layer
- **Tools:** None required
- **Concepts:** OSI model, TCP/IP model, encapsulation, IP addressing, subnetting, MAC addresses, data link layer, network layer, transport layer, application layer
