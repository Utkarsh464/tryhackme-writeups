# Networking Concepts — Tools

This room is conceptual and does not introduce specific security tools. Learners may reference standard operating system networking utilities:

- **ip / ifconfig:** Used to view and configure network interfaces on Linux systems.
- **ping:** Sends ICMP echo requests to test connectivity to a remote host.
- **arp:** Displays and modifies the ARP cache table, showing IP-to-MAC address mappings.
- **ipconfig:** The Windows equivalent of ifconfig, used to display TCP/IP configuration.
- **traceroute / tracert:** Traces the path packets take to a destination, showing each hop.
