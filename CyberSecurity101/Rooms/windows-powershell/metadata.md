## Description
This room provides a comprehensive introduction to Windows PowerShell, Microsoft's modern shell and scripting environment. Unlike traditional text-based shells, PowerShell is built on the .NET Framework and works with objects rather than plain text. This object-oriented approach enables powerful data manipulation and automation capabilities that go far beyond what traditional shells can achieve. PowerShell uses a verb-noun naming convention for its commands, called cmdlets (pronounced command-lets), such as Get-ChildItem, Set-ExecutionPolicy, and Invoke-WebRequest. Students learn the PowerShell pipeline, which passes .NET objects between cmdlets, allowing for sophisticated filtering, sorting, and transformation of data. The room covers essential cmdlets for filesystem navigation, file management, process and service management, and system information retrieval. PowerShell scripting is introduced, covering variables, arrays, hash tables, loops, conditionals, error handling, and functions. Students also learn about PowerShell remoting (WinRM) for managing remote systems, execution policies for security, and module management for extending PowerShell functionality.

## Learning Objectives
- Understand PowerShell cmdlets and the verb-noun naming convention
- Use the PowerShell pipeline to process objects
- Navigate the filesystem and registry using PowerShell
- Manage processes, services, and system information
- Write PowerShell scripts with control flow and error handling
- Use PowerShell remoting for remote administration
- Configure PowerShell execution policies
- Import and use PowerShell modules

## Key Tools and Technologies
