# IDS Fundamentals - Tools

## Snort
Snort is the most widely deployed open-source intrusion detection and prevention system. Created by Martin Roesch in 1998 and now maintained by Cisco, Snort performs real-time traffic analysis, packet logging, and protocol analysis. Snort operates in three modes: sniffer mode (simple packet display), packet logger mode (writing packets to disk), and network intrusion detection mode (applying rules to traffic). Snort's architecture includes the packet decoder, preprocessors (for reassembly, normalization, and protocol detection), the detection engine (rule matching), and output modules (alert and log formatting). The detection engine uses a multi-pattern matching algorithm (Aho-Corasick) for efficient content matching across large rule sets. Snort rules are maintained by the Talos Intelligence Group (Cisco) and the open-source community through Emerging Threats (ET) rulesets.

## Suricata
Suricata is a high-performance network IDS, IPS, and Network Security Monitoring (NSM) engine developed by the Open Information Security Foundation (OISF). Suricata is designed to leverage modern multi-core processors with automatic load balancing across CPU cores, enabling it to process traffic at 10 Gbps and above on commodity hardware. Suricata supports GPU acceleration (CUDA) for pattern matching, comprehensive protocol detection for over 200 application-layer protocols, TLS/SSL certificate inspection, file extraction and logging (extracting files transferred over HTTP, SMB, SMTP), and Lua scripting for custom detection logic. Suricata uses the same rule syntax as Snort, making rule sets compatible between the two engines. Suricata outputs JSON-formatted logs (eve.json), which are easily ingested by SIEM platforms like the ELK Stack.

## PulledPork
PulledPork is a rule management tool for Snort that automates downloading, enabling, disabling, and updating Snort rulesets. It supports multiple rule sources: registered Snort subscribers (Talos rules), free Emerging Threats (ET) rulesets, and custom local rules. PulledPork manages rule categories, enables/disables rules based on policy configuration, generates modification files for tuning, and manages the snort.conf include directives. While PulledPork is specific to Snort, Suricata-update is the equivalent tool for Suricata, providing similar functionality for managing Suricata rulesets. Regular rule updates through these tools are essential for maintaining detection coverage against emerging threats.

## Zeek (formerly Bro)
Zeek is a powerful network analysis framework that focuses on network security monitoring rather than traditional signature-based IDS. Unlike Snort and Suricata which primarily match signatures, Zeek creates high-level connection logs that provide comprehensive visibility into network activity. Zeek generates logs for: connections (all TCP/UDP/ICMP sessions), HTTP requests and responses, DNS queries, SSL/TLS certificates, SMTP transactions, SSH authentication attempts, and file transfers. These logs can be analyzed for security events without writing signatures. Zeek also supports a scripting language for custom analysis logic. Many organizations deploy both Suricata (for signature detection) and Zeek (for comprehensive logging and anomaly detection) alongside each other.

## Wireshark
Wireshark is essential for developing and testing IDS rules. When creating a new signature, Wireshark is used to capture sample traffic of the attack, examine the exact byte structure that the IDS needs to match, and verify that the signature fires correctly on the attack traffic. Wireshark's protocol dissection and follow TCP stream features make it easy to understand the application-layer context that IDS rules operate on. When troubleshooting IDS false positives, Wireshark captures the triggering traffic and helps analysts understand whether the alert was legitimate or whether the rule needs tuning.
