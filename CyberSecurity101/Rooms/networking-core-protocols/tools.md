# Networking Core Protocols — Tools

This room is conceptual and does not introduce dedicated security tools, but references standard networking utilities:

- **ping:** Uses ICMP echo requests to verify host reachability and measure round-trip time.
- **traceroute / tracert:** Traces the network path to a destination by sending packets with increasing TTL values.
- **nslookup / dig:** DNS lookup utilities that query nameservers for domain records.
- **curl / wget:** Command-line HTTP clients used to make web requests and inspect headers.
- **netstat / ss:** Display network connections, routing tables, and listening ports.
- **arp:** View and manipulate the ARP cache on a local system.
