# Room: Networking Core Protocols

- **URL:** https://tryhackme.com/room/networkingcoreprotocols
- **Description:** This room provides an in-depth exploration of the core protocols that underpin internet communication. Learners examine TCP and UDP, IP addressing and routing, ICMP for diagnostics, ARP for local resolution, DNS for name resolution, DHCP for automatic configuration, and HTTP for web communication. Each protocol is dissected with its header structure, operational mechanics, and real-world usage.
- **Difficulty:** Easy
- **Time:** ~30 minutes
- **Tier:** Premium
- **Objectives:**
  - Compare TCP (connection-oriented, reliable) with UDP (connectionless, fast)
  - Understand IP packet structure and the role of the IP header fields
  - Explain how ICMP is used for error reporting and network diagnostics
  - Describe the DNS resolution process from query to answer
  - Understand how DHCP automates IP address assignment
  - Explain the HTTP request-response lifecycle
- **Tools:** None required
- **Concepts:** TCP, UDP, IP, ICMP, ARP, DNS, DHCP, HTTP, three-way handshake, port numbers
