# Careers in Cyber — Tasks

## Task 1: Introduction to Cybersecurity Careers
Read about the current state of the cybersecurity job market, the global skills shortage, and the high demand for security professionals. Understand that cybersecurity spans multiple disciplines and that there is no single "right" path into the field.

## Task 2: SOC Analyst — Entry Level
Learn about the Security Operations Center (SOC) environment. Understand the tiered structure: Tier 1 (triage) monitors alerts and determines if they are genuine, Tier 2 (investigation) deep-dives into confirmed incidents, and Tier 3 (hunting) proactively searches for threats. Explore the tools used: SIEM platforms, EDR, and ticketing systems.

## Task 3: Penetration Testing Path
Explore the offensive security career path. Understand the difference between white box, black box, and gray box testing. Learn about the pentest methodology: reconnaissance, scanning, exploitation, post-exploitation, and reporting. Discuss the role of certifications like OSCP, GPEN, and PNPT.

## Task 4: Security Engineering and Architecture
Learn about roles focused on building and maintaining security infrastructure. Security engineers implement firewalls, IDS/IPS, VPNs, and endpoint protection. Security architects design the overall security posture of an organization, including network segmentation, zero trust architecture, and cloud security design.

## Task 5: Incident Response and Forensics
Explore the incident response lifecycle: preparation, detection, containment, eradication, recovery, and lessons learned. Learn about digital forensics as a specialization within IR, including disk forensics, memory forensics, and network forensics. Discuss certifications like GCFE, GCFA, and CHFI.

## Task 6: Threat Intelligence
Learn how threat intelligence analysts research threat actors, their tactics (MITRE ATT&CK), and their targeting. Understand the difference between strategic, operational, tactical, and technical intelligence. Explore tools like MISP, OpenCTI, and threat intelligence platforms.

## Task 7: GRC — Governance, Risk, and Compliance
Explore non-technical roles focused on policy, risk management, and regulatory compliance. GRC professionals conduct risk assessments, develop security policies, manage vendor risk, and ensure compliance with frameworks like PCI DSS, HIPAA, and GDPR. Certifications include CISA, CISM, and CRISC.

## Task 8: Certifications and Education
Map the certification landscape: entry-level (Security+, GSEC), technical (OSCP, GPEN, CISSP, SANS GIAC), and management (CISSP, CISM, CRISC). Discuss degree programs vs. certifications vs. self-study. Understand which certifications employers value for different roles.

## Task 9: Gaining Experience
Explore ways to gain practical experience without a formal job: building a home lab, participating in CTFs and challenges on TryHackMe and Hack The Box, contributing to open-source security tools, reporting bugs through bug bounty programs, and writing technical blog posts.

## Task 10: Building Your Career Plan
Create a personal career plan. Identify your target role, the skills and certifications required, a timeline for achieving them, and resources you will use. Discuss how to network at security conferences (local BSides, DEF CON, etc.) and build an online presence through LinkedIn, Twitter, and GitHub.
