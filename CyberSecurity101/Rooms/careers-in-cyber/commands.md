# Careers in Cyber — Commands

This room focuses on career planning and does not introduce technical command-line tools. However, learners are encouraged to use the following online resources and platforms for career development:

| Resource | URL | Purpose |
|----------|-----|---------|
| LinkedIn | https://www.linkedin.com | Professional networking and job search |
| CyberSeek | https://www.cyberseek.org | Cybersecurity career pathway and job market data |
| TryHackMe | https://tryhackme.com | Hands-on cybersecurity training and CTFs |
| Hack The Box | https://www.hackthebox.com | Penetration testing labs and CTFs |
| OWASP | https://owasp.org | Web application security resources |
| MITRE ATT&CK | https://attack.mitre.org | Adversary tactics and techniques knowledge base |
| National Initiative for Cybersecurity Careers and Studies | https://niccs.cisa.gov | U.S. government cybersecurity career resources |
| CompTIA | https://www.comptia.org | Security+ and other entry-level certifications |
| SANS | https://www.sans.org | Professional cybersecurity training and GIAC certifications |
| (ISC)² | https://www.isc2.org | CISSP and other advanced certifications |
| OffSec | https://www.offsec.com | OSCP, OSED, and other offensive security certifications |
| Bsides | https://www.securitybsides.com | Community-driven security conferences worldwide |
| DEF CON | https://defcon.org | Major annual hacker conference |
| GitHub | https://github.com | Open-source contributions and portfolio building |
