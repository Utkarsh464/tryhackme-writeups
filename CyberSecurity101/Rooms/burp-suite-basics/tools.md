# Burp Suite: The Basics - Tools

## Burp Suite Community Edition
Burp Suite Community Edition is the free version of PortSwigger's web application security testing platform. It includes the essential features needed for manual web application testing: the intercepting proxy, Repeater, Intruder (with rate limiting), and Decoder. The Community Edition has some limitations compared to the Professional Edition, including a slower Intruder (limited to a single thread), no passive scanning, no automated active scanning, no Burp Scanner, and no project file saving. Despite these limitations, the Community Edition is powerful enough for basic penetration testing, bug bounty hunting, and educational purposes. The Java-based application runs on Windows, macOS, and Linux.

## FoxyProxy
FoxyProxy is a browser extension available for Firefox, Chrome, and other Chromium-based browsers that simplifies proxy management. Rather than manually changing proxy settings in the browser's network configuration every time you want to use Burp Suite, FoxyProxy allows you to define multiple proxy profiles and switch between them with a single click. A typical setup includes a profile pointing to 127.0.0.1:8080 for Burp Suite and a disabled profile for direct internet access. FoxyProxy can also be configured to proxy URLs matching specific patterns, automatically enabling the proxy only for in-scope targets.

## Burp Suite Repeater
Repeater is a manual testing tool within Burp Suite that allows users to resend individual HTTP requests with modifications and observe the responses. Unlike the browser, which may re-render or cache results, Repeater shows the raw request and response, giving the tester complete visibility. Each request can be modified independently without affecting the browser session. Repeater supports multiple views: Raw (the raw HTTP message), Params (structured parameter view), Headers (organized header view), and Hex (hexadecimal view for binary content). Repeater is ideal for testing how a server handles different input values, edge cases, and malformed requests.

## Burp Suite Intruder
Intruder is an automated fuzzing tool for performing customizable attacks against web applications. It takes a base request, identifies payload positions, and systematically sends variations with different payload values. The results are displayed in a table sorted by response length, status code, or other criteria, making it easy to identify interesting responses that differ from the baseline. Intruder is commonly used for: brute-forcing login credentials, fuzzing parameter values, enumerating user IDs or file paths, testing for SQL injection and XSS payloads, and discovering hidden content. The Professional Edition offers significantly faster Intruder attacks through multi-threading.

## Burp Suite Decoder
Decoder is a utility tool within Burp Suite for encoding and decoding data. It supports URL encoding, HTML encoding, Base64 encoding, ASCII hex, octal, binary, and standard character encodings (UTF-8, UTF-16, etc.). Users can chain multiple operations to decode nested or layered encoding. The Smart Decode feature attempts to automatically detect the encoding scheme used and apply the appropriate decoding. Decoder also includes a hash function calculator supporting MD5, SHA-1, SHA-256, and other algorithms. This tool is essential when analyzing obfuscated data, session tokens, or encoded payloads encountered during testing.
