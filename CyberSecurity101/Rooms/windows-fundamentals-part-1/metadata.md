## Description
This room introduces the Microsoft Windows operating system, the most widely used desktop operating system in corporate and home environments. Understanding Windows is essential for cybersecurity professionals because a large percentage of cyber attacks target Windows systems. This first part covers the history of Windows, its various editions (Home, Pro, Enterprise, Server), and the core components of the Windows user interface. Students explore the Windows filesystem, learning about drive letters (C:, D:), the directory structure (System32, Program Files, Users), and important system paths. The room covers built-in Windows applications such as Notepad, Calculator, Paint, and Snipping Tool, as well as administrative tools like the Control Panel, Settings app, and Task Manager. Students also learn about system information tools like msinfo32, the System Configuration utility (msconfig), and how to access system properties. Understanding these fundamentals provides the foundation for deeper Windows security and administration knowledge.

## Learning Objectives
- Understand Windows versions, editions, and their differences
- Navigate the Windows desktop and user interface
- Identify the Windows filesystem structure and important directories
- Use built-in Windows applications and tools
- Access and interpret system information
- Use Task Manager to monitor system performance

## Key Tools and Technologies
- Windows 10/11 operating system
- File Explorer
- Task Manager
- Control Panel
- System Information (msinfo32)
- System Configuration (msconfig)

## Prerequisites
- Basic computer literacy

## Expected Outcomes
Students will be familiar with the Windows operating system interface, filesystem structure, and built-in tools. They will know how to access system information, manage running applications, and navigate Windows settings.
