# Tasks: Windows Fundamentals Part 1

## Task 1: Windows Editions and Versions

**Purpose:** Understand the different versions and editions of Windows.

**Skills:** OS version identification.

**Theory:** Windows has multiple editions (Home, Pro, Enterprise, Education, Server) each with different features and use cases. Home is for consumers, Pro adds BitLocker and RDP, Enterprise adds DirectAccess and AppLocker. Windows Server editions provide server roles and Active Directory capabilities.

**Commands:** None

---

## Task 2: Windows Desktop and Interface

**Purpose:** Navigate the Windows desktop interface effectively.

**Skills:** Desktop navigation, UI familiarity.

**Theory:** The Windows desktop includes the taskbar, Start menu, notification area (system tray), desktop icons, and virtual desktops (Task View). Understanding the interface helps administrators locate tools and settings quickly. The Start menu provides access to applications, settings, and power options.

**Commands:** None (GUI navigation)

---

## Task 3: Windows Filesystem

**Purpose:** Understand the Windows directory structure.

**Skills:** Filesystem navigation.

**Theory:** Windows uses drive letters (C:, D:) with a hierarchical folder structure. Key directories include C:\Windows (system files), C:\Program Files (installed applications), C:\Users (user profiles), and C:\ProgramData (application data). System32 contains critical system files and executables.

**Commands:**
- dir - List directory contents
- cd - Change directory
- tree - Display directory structure

---

## Task 4: Built-in Applications

**Purpose:** Learn about essential Windows built-in tools.

**Skills:** Tool identification and usage.

**Theory:** Windows includes many built-in applications: Notepad (text editing), Calculator, Paint, Snipping Tool (screenshots), File Explorer (file management), and the Control Panel and Settings app for configuration. The Run dialog (Win+R) provides quick access to utilities.

**Commands:** None (application usage)

---

## Task 5: System Information Tools

**Purpose:** Access and interpret Windows system information.

**Skills:** System diagnostics.

**Theory:** Windows provides several information tools. System Information (msinfo32) shows comprehensive hardware and software details. System Configuration (msconfig) manages boot options and startup services. Task Manager (Ctrl+Shift+Esc) displays running processes, performance, and startup programs.

**Commands:**
- msinfo32 - System Information
- msconfig - System Configuration
- taskmgr - Task Manager
- winver - Windows version
- dxdiag - DirectX Diagnostic Tool
