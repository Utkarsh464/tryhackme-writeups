# Commands: Windows Fundamentals Part 1

## Command Prompt (cmd.exe) Commands

| Command | Description | Example |
|---------|-------------|---------|
| `dir` | List directory contents | `dir C:\Windows` |
| `cd` | Change directory or display path | `cd C:\Users` |
| `tree` | Display directory structure | `tree C:\Windows` |
| `cls` | Clear the screen | `cls` |
| `ver` | Display Windows version | `ver` |
| `help` | Display command help | `help dir` |
| `exit` | Close Command Prompt | `exit` |

## Run Dialog Commands (Win+R)

| Command | Description | Example |
|---------|-------------|---------|
| `msinfo32` | System Information | Displays hardware and software details |
| `msconfig` | System Configuration | Boot options, startup services |
| `taskmgr` | Task Manager | Processes, performance, startup |
| `winver` | Windows Version | Shows OS version and build |
| `dxdiag` | DirectX Diagnostic | Graphics and sound details |
| `control` | Control Panel | Classic Windows settings |
| `cmd` | Command Prompt | Launches cmd.exe |
| `notepad` | Notepad | Text editor |

## PowerShell Cmdlets (Optional)

| Cmdlet | Description |
|--------|-------------|
| `Get-ChildItem` | List items (like dir) |
| `Set-Location` | Change directory (like cd) |
| `Get-Location` | Display current path (like pwd) |
