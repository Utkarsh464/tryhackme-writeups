# Tools: Windows Fundamentals Part 1

## Built-in Windows Tools

| Tool | How to Access | Purpose |
|------|--------------|---------|
| File Explorer | Win+E or taskbar icon | File and folder management |
| Task Manager | Ctrl+Shift+Esc or taskmgr | Process, performance, and startup management |
| Control Panel | Win+R, control | Classic system settings and configuration |
| Settings App | Win+I | Modern Windows settings interface |
| Notepad | Win+R, notepad | Simple text editor |
| Calculator | Win+R, calc | Basic and scientific calculator |
| Paint | Win+R, mspaint | Image editing and creation |
| Snipping Tool | Win+R, snippingtool | Screen capture and annotation |
| Command Prompt | Win+R, cmd | Text-based command-line interface |
| Run Dialog | Win+R | Quick access to programs and utilities |

## Diagnostic Tools

| Tool | How to Access | Purpose |
|------|--------------|---------|
| System Information | Win+R, msinfo32 | Comprehensive hardware and software details |
| System Configuration | Win+R, msconfig | Boot options, startup services, and tools |
| DirectX Diagnostic | Win+R, dxdiag | DirectX and graphics/sound information |
| Windows Version | Win+R, winver | Display Windows version and build number |
| Resource Monitor | Win+R, resmon | Advanced performance monitoring |
| Performance Monitor | Win+R, perfmon | Detailed performance data collection |

## Navigation Commands (Command Prompt)

| Command | Purpose |
|---------|---------|
| `dir` | List files and directories |
| `cd` | Change directory |
| `tree` | Display directory structure |
| `cls` | Clear command prompt screen |
| `help` | Display command help |
