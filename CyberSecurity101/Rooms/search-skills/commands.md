# Commands: Search Skills

## Google Search Operators

| Operator | Example | Purpose |
|----------|---------|---------|
| `site:` | `site:example.com` | Restrict results to a specific domain |
| `filetype:` | `filetype:pdf` | Find files of a specific type |
| `intitle:` | `intitle:login` | Find pages with keyword in title |
| `inurl:` | `inurl:admin` | Find pages with keyword in URL |
| `intext:` | `intext:password` | Find pages containing specific text |
| `cache:` | `cache:example.com` | View cached version of a page |
| `link:` | `link:example.com` | Find pages linking to a URL |
| `related:` | `related:example.com` | Find similar websites |
| `"exact phrase"` | `"administrator password"` | Search for exact phrase |
| `-` (minus) | `-javascript` | Exclude terms from results |
| `OR` | `linux OR windows` | Search for either term |
| `*` (wildcard) | `how to * in linux` | Match any word |
