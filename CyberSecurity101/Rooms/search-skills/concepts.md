# Concepts: Search Skills

## 1. Google Dorking (Google Hacking)
Using advanced search operators to refine search queries and find specific types of information that may not be easily discoverable through standard searches. Google dorking is used by security professionals to find exposed sensitive information, vulnerable systems, and misconfigured web servers.

## 2. Advanced Search Operators
Special commands added to search queries to narrow results. Common operators include site: (domain restriction), filetype: (file format), intitle: (title keyword), inurl: (URL keyword), intext: (body text), cache: (cached pages), and link: (backlinks). Combining operators creates powerful, targeted searches.

## 3. Common Vulnerabilities and Exposures (CVE)
A publicly available dictionary of standardized identifiers for known vulnerabilities and exposures. Each CVE identifier follows the format CVE-YYYY-NNNN and provides a reference point for vulnerability information across different databases and tools.

## 4. Exploit-DB
A public database maintained by Offensive Security that contains proof-of-concept exploits, shellcode, and security papers. Security professionals use Exploit-DB to find exploit code for testing, understand vulnerability exploitation, and develop signatures for detection systems.

## 5. National Vulnerability Database (NVD)
The U.S. government repository of standards-based vulnerability management data, using CVE identifiers and CVSS (Common Vulnerability Scoring System) scores. NVD provides detailed vulnerability information including affected software, impact metrics, and remediation recommendations.

## 6. VirusTotal
A free online service that analyzes files and URLs using multiple antivirus engines and website scanners. Users upload files or submit URLs to check for malicious content. VirusTotal is used by security analysts to verify suspicious files and URLs quickly.

## 7. Shodan
A search engine that scans the internet and indexes information about connected devices, including servers, routers, webcams, industrial control systems, and IoT devices. Security researchers use Shodan to find exposed systems, identify vulnerable devices, and assess internet-wide security trends.

## 8. OSINT (Open Source Intelligence)
Intelligence gathered from publicly available sources. In cybersecurity, OSINT techniques are used for reconnaissance, threat intelligence gathering, and security research. Effective searching is a core OSINT skill.

## 9. Information Literacy
The ability to identify, locate, evaluate, and effectively use information. In cybersecurity, information literacy means knowing where to look for different types of information, how to evaluate source credibility, and how to apply found information to solve problems.
