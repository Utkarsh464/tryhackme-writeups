# Tasks: Search Skills

## Task 1: Introduction to Search Skills

**Purpose:** Understand why effective searching is critical in cybersecurity.

**Skills:** Research mindset, information literacy.

**Theory:** Cybersecurity professionals spend a significant amount of time researching threats, vulnerabilities, tools, and techniques. Being able to find the right information quickly can mean the difference between stopping an attack and suffering a breach. This task sets the context for the search skills covered in the room.

**Commands:** None

---

## Task 2: Google Dorking

**Purpose:** Learn advanced Google search operators to find specific types of information.

**Skills:** Advanced search techniques, Google hacking.

**Theory:** Google dorking uses advanced search operators like site:, filetype:, intitle:, inurl:, and cache: to narrow search results. For example, site:example.com filetype:pdf finds all PDFs on a specific domain. These techniques help security researchers find exposed sensitive information and vulnerable systems.

**Commands:** None (browser-based search techniques)

---

## Task 3: Exploit-DB and CVE Research

**Purpose:** Learn to use Exploit-DB and CVE databases for vulnerability research.

**Skills:** Vulnerability research, exploit discovery.

**Theory:** Exploit-DB is a public database of exploits and proof-of-concept code. The CVE (Common Vulnerabilities and Exposures) system provides unique identifiers for publicly known vulnerabilities. Security professionals use these resources to understand threats, find exploits for testing, and stay informed about new vulnerabilities.

**Commands:** None (web-based research)

---

## Task 4: VirusTotal and Shodan

**Purpose:** Learn to use VirusTotal for file analysis and Shodan for device discovery.

**Skills:** Malware analysis, internet scanning.

**Theory:** VirusTotal analyzes files and URLs against multiple antivirus engines. Shodan is a search engine for internet-connected devices, allowing researchers to find vulnerable systems, open databases, and exposed industrial control systems. Both tools are valuable for threat intelligence and security assessment.

**Commands:** None (web-based tool usage)

---

## Task 5: Putting It All Together

**Purpose:** Apply search skills in a practical scenario.

**Skills:** Combined research techniques.

**Theory:** This task presents a realistic scenario requiring students to use multiple search techniques together to find specific information, demonstrating how these skills are used in real cybersecurity investigations.

**Commands:** None
