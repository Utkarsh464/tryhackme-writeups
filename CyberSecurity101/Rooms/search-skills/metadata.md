# Search Skills

## Room Information
- **Room URL:** https://tryhackme.com/room/searchskills
- **Module:** Start Your Cybersecurity Journey
- **Difficulty:** Easy
- **Estimated Time:** 30 minutes
- **Access:** Free

## Description
This room teaches the essential skill of finding information effectively using search engines and specialized databases. In cybersecurity, the ability to quickly locate technical documentation, exploit code, vulnerability reports, configuration examples, and threat intelligence is critical. Professionals spend a significant portion of their time researching, and those who can search efficiently have a major advantage. This room covers advanced search operators (often called Google dorking or Google hacking), which allow users to refine search queries to find specific types of information. Students learn how to use site-specific searches, filetype filters, intitle and inurl operators, and other advanced techniques. The room also introduces specialized resources like Exploit-DB for finding proof-of-concept exploits, the National Vulnerability Database (NVD) and CVE database for vulnerability research, VirusTotal for malware analysis, and Shodan for internet-connected device discovery. These research skills are invaluable for both offensive and defensive security professionals who need to stay current with threats, techniques, and technologies.

## Learning Objectives
- Use advanced search operators to refine web searches
- Find exploit code and vulnerability information using Exploit-DB
- Research CVEs using the National Vulnerability Database
- Use VirusTotal to analyze files and URLs
- Understand Shodan and its use in security research
- Locate technical documentation and community resources

## Key Tools and Technologies
- Google search engine
- Exploit-DB
- National Vulnerability Database (NVD)
- MITRE CVE database
- VirusTotal
- Shodan

## Prerequisites
- None

## Expected Outcomes
Students will dramatically improve their ability to find security-related information online. They will be familiar with the key databases and resources used by security professionals for vulnerability research, threat intelligence, and technical problem-solving.
