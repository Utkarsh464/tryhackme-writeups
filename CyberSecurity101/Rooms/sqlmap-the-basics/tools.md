# SQLMap: The Basics - Tools

## SQLMap
SQLMap is the leading open-source tool for automated SQL injection detection and exploitation. Developed by Bernardo Damele A. G. and Miroslav Stampar, SQLMap has been in active development since 2006 and supports all major database management systems: MySQL, Oracle, PostgreSQL, Microsoft SQL Server, SQLite, IBM DB2, Firebird, Sybase, SAP MaxDB, Informix, MariaDB, and others. SQLMap's extensive feature set includes: automatic detection of SQL injection points in GET, POST, Cookie, and User-Agent parameters; support for all injection techniques (boolean, error, UNION, time, stacked, inline); database and table enumeration; data extraction with filtering and limiting; file system access (read/write); OS command execution; WAF bypass through tamper scripts; proxy support for traffic routing; and multiple output formats. SQLMap is written in Python and runs on any platform with Python 2.7 or Python 3.x. It is pre-installed on Kali Linux and available via GitHub, PyPI, and package managers.

## Burp Suite (Request Capture)
Burp Suite's proxy is used to capture HTTP requests that are then saved to files and fed to SQLMap with the -r flag. The workflow involves: configuring the browser to route through Burp Suite's proxy, navigating to the target application and performing actions that include the parameter to be tested, finding the relevant request in Burp's HTTP history, right-clicking and selecting "Copy to file", and passing the saved file to SQLMap. Using request files is more accurate than manually specifying URL parameters because it preserves the exact headers, cookies, and parameter encoding that the browser would send, ensuring SQLMap tests the application exactly as a real user would.

## Tamper Scripts
SQLMap includes a comprehensive collection of tamper scripts in its `tamper/` directory. Each script is a Python module that transforms payloads to evade WAF detection. Popular tamper scripts include: space2comment (replaces spaces with comments), between (replaces > with BETWEEN), apostrophemask (encodes apostrophes), apostrophenullnull (replaces apostrophes with null bytes), bluecoat (bypass Blue Coat WAF), charencode (full URL encoding), charunicodeencode (Unicode URL encoding), equaltolike (replaces = with LIKE), halfversionedmorekeywords (shrouded MySQL injection), modsecurityversioned (bypass ModSecurity), randomcase (randomizes letter case), and symboliclogic (AND/OR to &&/||). Multiple tamper scripts can be combined with comma separation. The --list-tampers flag shows all available scripts with descriptions.

## SecLists (Wordlists)
SecLists provides wordlists used for SQL injection testing, including common SQL injection payloads, usernames for database accounts, and table/column name dictionaries. While SQLMap includes its own payload libraries, custom wordlists can be used with SQLMap's `--file-read` targets and for brute-forcing database object names. The SecLists/Fuzzing/SQLi/ directory contains specialized SQL injection payload collections that can supplement SQLMap's internal testing when manual verification is needed.

## Network Scanning Tools (Nmap)
Nmap can be used in conjunction with SQLMap for comprehensive database security assessment. The Nmap scripting engine (NSE) includes scripts for database service discovery, version detection, and initial vulnerability scanning. For example, `nmap -sV --script=mysql-audit,mysql-enum` identifies MySQL servers and checks basic security configurations. Nmap results guide SQLMap targeting by identifying database services and potentially non-standard ports. SQLMap's `--dbms` and `--port` flags can be configured based on Nmap discovery results.

## Alternative SQL Injection Tools
While SQLMap is the most comprehensive automated SQL injection tool, alternatives exist for specific scenarios. jSQL Injection provides a graphical interface for SQL injection testing. NoSQLMap specializes in NoSQL database injection (MongoDB, CouchDB). BBQSQL is a blind SQL injection framework optimized for speed. Each tool has strengths in specific use cases, but SQLMap remains the standard due to its breadth of features, regular updates, and widespread adoption in the penetration testing community.
