# Introduction to SIEM - Tools

## Splunk
Splunk is the leading SIEM platform, known for its powerful Search Processing Language (SPL), scalability, and extensive ecosystem of apps and add-ons. Splunk operates on a data-indexing model where logs are parsed, indexed, and made searchable. The Splunk Search app provides the primary interface for querying data. Splunk Enterprise Security (ES) is a premium app that adds predefined correlation rules, risk-based alerting, asset and identity management, and threat intelligence integration. Splunk uses a distributed architecture with forwarders (data collection), indexers (data storage and search), search heads (query coordination and user interface), and deployment servers (configuration management). Splunk is proprietary but offers a free license limited to 500 MB of daily data ingestion.

## ELK Stack (Elasticsearch, Logstash, Kibana)
The ELK Stack is the leading open-source SIEM alternative. Elasticsearch is a distributed search and analytics engine based on Apache Lucene, providing scalable storage and fast search. Logstash is the data processing pipeline that ingests, parses, normalizes, and enriches log data before sending it to Elasticsearch. Kibana provides the visualization layer with dashboards, charts, maps, and alerting. Elastic Security extends the ELK Stack with SIEM capabilities including detection rules (based on the Elastic Common Schema), endpoint security integration, and case management. The Elastic Stack is free and open-source, with commercial features available under the Elastic License.

## IBM QRadar
IBM QRadar is an enterprise SIEM platform known for its strong correlation engine and offense management. QRadar uses a flow-based approach where network flows (conversation metadata) are analyzed alongside log data for comprehensive visibility. QRadar's offense management framework automatically groups related alerts into offenses based on common attributes (source IP, destination IP, time proximity). Each offense is assigned a magnitude score based on relevance, severity, and credibility. QRadar supports a wide range of log source integrations through its DSM (Device Support Module) library and includes built-in compliance reports for PCI DSS, HIPAA, and other regulations.

## Microsoft Sentinel
Microsoft Sentinel is a cloud-native SIEM and SOAR solution built on top of Azure. Unlike traditional SIEMs that require significant infrastructure to deploy and maintain, Sentinel is fully managed in the cloud with pay-as-you-go pricing. Sentinel integrates deeply with the Microsoft security ecosystem including Microsoft 365 Defender, Azure Active Directory, and Microsoft Defender for Cloud. It uses Kusto Query Language (KQL) for searching and analyzing data. Sentinel includes built-in analytics rules based on Microsoft threat intelligence and the MITRE ATT&CK framework, and its SOAR capabilities use Logic Apps for automated response playbooks.

## Wazuh (Open-Source Alternative)
Wazuh is an open-source security platform that provides SIEM and XDR (Extended Detection and Response) capabilities. It is built on the Elastic Stack and the OSSEC HIDS (Host-based Intrusion Detection System). Wazuh provides log analysis, file integrity monitoring, vulnerability detection, configuration assessment, and incident response capabilities. Its agent-based architecture supports Windows, Linux, macOS, and Solaris endpoints. Wazuh is a popular choice for organizations that need SIEM capabilities but have limited budgets, as it is completely free and open-source.
