# Security Principles — Tasks

## Task 1: The CIA Triad
Learn the definition of confidentiality, integrity, and availability. For each pillar, identify a real-world scenario where it is threatened. For example, an unencrypted database leak threatens confidentiality, a man-in-the-middle attack threatens integrity, and a DDoS attack threatens availability.

## Task 2: Confidentiality in Practice
Explore mechanisms that enforce confidentiality: encryption (at rest and in transit), access control lists, multi-factor authentication, and data classification. Given a scenario, recommend the appropriate confidentiality controls.

## Task 3: Integrity in Practice
Understand how integrity is maintained through hashing, digital signatures, checksums, version control, and audit logs. Given a scenario involving file tampering or data corruption, identify which integrity controls were bypassed.

## Task 4: Availability in Practice
Study the threats to availability: denial of service attacks, hardware failures, natural disasters, and ransomware. Learn about redundancy, failover, backup strategies, load balancing, and SLA management as availability controls.

## Task 5: Authentication, Authorization, and Accounting
Differentiate the three As: authentication (who are you?), authorization (what can you do?), and accounting (what did you do?). Explore methods for each: passwords, biometrics, tokens for authentication; RBAC, ABAC for authorization; logging and SIEM for accounting.

## Task 6: Defense in Depth
Understand the layered security model where multiple controls protect assets. Explore layers such as perimeter firewalls, network segmentation, endpoint protection, application security, data encryption, and user training. Apply the model to a scenario and identify gaps.

## Task 7: Least Privilege and Separation of Duties
Learn why users and services should have only the minimum permissions needed to perform their functions. Explore separation of duties as a fraud prevention measure. Apply both principles to a role-based access control scenario.

## Task 8: Risk Management Fundamentals
Define risk as threat x vulnerability x impact. Learn the risk management steps: identify assets, assess threats and vulnerabilities, evaluate risk, implement controls, and monitor. Practice calculating risk levels using qualitative and quantitative methods.

## Task 9: Security Frameworks and Standards
Explore the NIST Cybersecurity Framework (Identify, Protect, Detect, Respond, Recover) and ISO 27001. Understand how these frameworks guide security program development and how compliance differs from security.

## Task 10: Compliance and Regulations
Learn about major compliance frameworks: GDPR (data privacy), HIPAA (healthcare), PCI DSS (payment card industry). Understand what triggers compliance obligations, what the key requirements are, and how non-compliance is penalized. Discuss the shared responsibility model in cloud environments.
