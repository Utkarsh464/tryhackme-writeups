# Networking Essentials — Tasks

## Task 1: Network Devices
- **Purpose:** Learn the roles of routers, switches, hubs, bridges, and repeaters in a network infrastructure.
- **Skills:** Device identification, function matching.
- **Commands:** None.
- **Theory:** Routers operate at Layer 3 and forward packets between networks. Switches operate at Layer 2 and forward frames within a network. Hubs are simple repeaters that broadcast all traffic to all ports. Bridges connect two network segments.

## Task 2: Network Types and Topologies
- **Purpose:** Understand classifications of networks by size (LAN, WAN, MAN, PAN) and physical/logical layout (star, bus, ring, mesh, tree, hybrid).
- **Skills:** Topology recognition, classification by geographic scope.
- **Commands:** None.
- **Theory:** LAN covers a small geographic area like a home or office. WAN spans large geographic distances. Topologies describe how devices are connected: star uses a central switch, bus uses a single backbone cable, and mesh provides full redundancy.

## Task 3: Network Cables and Media
- **Purpose:** Identify common physical media used to connect network devices.
- **Skills:** Cable type identification, use-case matching.
- **Commands:** None.
- **Theory:** Copper cables (Ethernet/Cat5e/Cat6) use electrical signals and are limited to ~100 meters. Fiber optic cables use light and support much longer distances and higher speeds. Wireless uses radio waves for mobility.

## Task 4: Network Segmentation and VLANs
- **Purpose:** Understand how VLANs segment a network logically, improving performance and security.
- **Skills:** VLAN concept understanding, collision vs. broadcast domain differentiation.
- **Commands:** None.
- **Theory:** A VLAN creates logically separate networks on the same physical switch. Broadcast traffic is contained within the VLAN, reducing unnecessary load and improving security by isolating sensitive systems.
