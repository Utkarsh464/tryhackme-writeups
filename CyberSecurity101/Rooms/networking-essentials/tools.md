# Networking Essentials — Tools

This room does not introduce dedicated security tools. Understanding these hardware concepts is a prerequisite for working with network analysis and security tools introduced in later rooms:

- **Ethernet cables (Cat5e, Cat6, Cat6a):** Twisted-pair copper cables used for wired network connections.
- **Fiber optic cables:** Use light pulses for high-speed, long-distance data transmission.
- **Wi-Fi (IEEE 802.11):** Wireless networking standard for local area connectivity.
- **Managed switches:** Allow configuration of VLANs, port mirroring, and other advanced features.
- **Router CLI (Cisco IOS, etc.):** Command-line interface for configuring routing, NAT, and ACLs.
