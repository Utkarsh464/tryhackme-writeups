# Networking Essentials — Commands

This room focuses on hardware and architectural concepts rather than command-line tools. The following commands may be referenced for context:

| Command | Description |
|---------|-------------|
| `ip link` | View and manage network interfaces on Linux |
| `brctl show` | Display bridge information on Linux |
| `vconfig` | Manage VLAN interfaces on Linux (legacy) |
| `ip link add link <interface> name <vlan> type vlan id <id>` | Create a VLAN interface |
| `ethtool <interface>` | Query network interface hardware capabilities |
