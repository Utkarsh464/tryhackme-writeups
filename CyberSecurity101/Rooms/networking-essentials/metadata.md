# Room: Networking Essentials

- **URL:** https://tryhackme.com/room/networkingessentials
- **Description:** This room covers the essential hardware and architectural components that make up modern networks. Learners explore routers, switches, hubs, bridges, repeaters, access points, and the various types of network cables and topologies. Understanding these physical and logical building blocks is critical for designing, troubleshooting, and securing networks.
- **Difficulty:** Easy
- **Time:** ~30 minutes
- **Tier:** Premium
- **Objectives:**
  - Describe the function of routers, switches, and hubs in a network
  - Differentiate between LAN, WAN, MAN, and PAN
  - Identify common network topologies (star, bus, ring, mesh, hybrid)
  - Understand the purpose of network cables (copper, fiber) and wireless communication
  - Explain how network segmentation improves security and performance
- **Tools:** None required
- **Concepts:** Router, switch, hub, LAN, WAN, topology, VLAN, collision domain, broadcast domain
