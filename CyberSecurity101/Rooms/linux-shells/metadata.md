## Description
This room focuses on Linux shells, primarily the Bash (Bourne Again SHell) shell, which is the default command-line interpreter on most Linux distributions. The shell is the primary interface for interacting with Linux systems, and mastery of the shell is essential for cybersecurity professionals who work with Linux-based tools, servers, and security distributions. This room covers shell fundamentals including command syntax, command types (built-in vs. external), environment variables, and the PATH variable. Students learn about shell configuration files such as .bashrc, .bash_profile, and .bash_logout, and how to customize the shell environment. Input-output redirection is covered in depth, including standard input (stdin), standard output (stdout), standard error (stderr), and the redirection operators (>, >>, <, 2>, &>). The pipe operator (|) is introduced for chaining commands together. Job control is covered including background execution (&), foreground and background process management (bg, fg), and job monitoring (jobs). Shell scripting is a major focus, teaching students how to write scripts with variables, command substitution, arithmetic expansion, conditional statements (if, case), loops (for, while, until), functions, and error handling.

## Learning Objectives
- Understand the Bash shell environment and configuration
- Use environment variables and customize the shell
- Implement input-output redirection and piping
- Manage background and foreground jobs
- Write Bash scripts with variables, conditionals, and loops
- Create and use functions in scripts
- Handle errors and debug scripts
- Automate tasks with shell scripts

## Key Tools and Technologies

- Shell scripting
- Unix/Linux command-line utilities
- Redirection and pipe operators
