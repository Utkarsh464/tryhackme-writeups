# Room: OWASP Top 10 - 2025

## URL
https://tryhackme.com/room/owasptop102025

## Description
The OWASP Top 10 is the definitive industry standard for web application security risks, published by the Open Web Application Security Project (OWASP). The 2025 edition updates the list to reflect the evolving threat landscape, introducing new categories that address modern attack vectors such as AI-driven threats, API-specific vulnerabilities, and supply chain risks. This capstone room guides learners through each of the ten categories in depth, combining theoretical understanding with hands-on exploitation and remediation exercises. Learners will explore and exploit vulnerabilities including Broken Access Control (the most common and dangerous class), Cryptographic Failures, Injection (SQL, NoSQL, OS command, and template injection), Insecure Design, Security Misconfiguration, Vulnerable and Outdated Components, Identification and Authentication Failures, Software and Data Integrity Failures, Security Logging and Monitoring Failures, and Server-Side Request Forgery (SSRF). The 2025 edition also introduces new considerations such as AI/ML model manipulation, API abuse, and software supply chain attacks. Each category is presented with real-world examples, exploitation techniques using tools like Burp Suite and SQLMap, and detailed remediation guidance. As the final assessment for the Cyber Security 101 path, this room expects learners to draw on knowledge from prior modules including networking, web hacking, cryptography, and defensive security to solve challenges and answer questions.

## Objectives
- Explain all ten categories of the OWASP Top 10 2025
- Exploit common web vulnerabilities including SQL injection, XSS, and SSRF in a lab environment
- Identify cryptographic failures and apply proper encryption and hashing techniques
- Understand API-specific vulnerabilities and how they differ from traditional web attacks
- Recognize supply chain and integrity failure risks
- Apply appropriate remediation strategies for each vulnerability category
- Demonstrate cumulative knowledge from all prior Cyber Security 101 modules
