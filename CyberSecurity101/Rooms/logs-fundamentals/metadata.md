## Description

Logs Fundamentals teaches the essential skill of reading, interpreting, and analyzing log data for security monitoring and incident investigation. Logs are the written record of everything that happens on a computer system, and they are the primary source of evidence when investigating security incidents. This room covers the major types of logs generated by different systems, the structure and format of log entries, and the tools and techniques used to collect, parse, and analyze logs at scale. The room begins with Windows Event Logs, which are the primary logging mechanism in Windows operating systems. Learners explore the three main Windows logs: Application (events from applications and services), System (events from the operating system and drivers), and Security (events related to authentication, authorization, and auditing). Key Windows Event IDs are covered: 4624 (successful logon), 4625 (failed logon), 4634 (logoff), 4688 (process creation), 4720 (user account creation), 4732 (user added to group), and 7045 (service installation). Linux system logs are then explored, focusing on the /var/log directory structure: syslog (general system messages), auth.log (authentication events), kern.log (kernel messages), dmesg (kernel ring buffer), apache2/access.log and error.log (web server logs), and dpkg.log (package management). The room covers log formats including syslog (RFC 5424), Common Log Format (CLF) for web servers, Windows EVTX format, and JSON-structured logs from modern applications. Log collection and centralization are covered: Syslog for Linux log forwarding, Windows Event Forwarding (WEF) for Windows logs, and agents for collecting logs into SIEM platforms. Log parsing and analysis techniques include using grep, awk, sed, and cut for command-line analysis, using Logstash for parsing and normalization, and using jq for JSON log analysis. Practical exercises involve reading real log files to identify failed login attempts, brute-force attacks, privilege escalation, web application attacks, and data exfiltration.

## Objectives
- Understand Windows Event Log structure and key Event IDs
- Navigate Linux system logs and their locations
- Parse logs using command-line tools (grep, awk, sed)
- Identify security events from log data
- Understand log collection and centralization methods
- Recognize log anomalies indicative of attacks

## Tools
- grep, awk, sed, cut (command-line log analysis)
- journalctl (systemd journal viewer)
- wevtutil (Windows Event Log command-line tool)
- Windows Event Viewer
- Syslog and log collectors

## Concepts
- Windows Event Logs (Application, System, Security)
- Linux system logs (/var/log/)
- Web server logs (Apache, Nginx)
- Syslog format and protocol
- Log levels and severity
- Log rotation and retention
- Timestamps and time zones
- Log correlation and normalization
