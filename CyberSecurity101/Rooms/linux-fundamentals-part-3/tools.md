# Tools: Linux Fundamentals Part 3

## Networking Tools

| Tool | Category | Purpose |
|------|----------|---------|
| `ip` | Networking | Show and manipulate routing, devices, policy routing and tunnels |
| `ifconfig` | Networking | Configure network interface parameters (legacy, may need net-tools) |
| `ping` | Networking | Test network connectivity to a remote host |
| `ss` | Networking | Socket statistics utility (modern replacement for netstat) |
| `netstat` | Networking | Display network connections, routing tables, and interface statistics |
| `ssh` | Remote Access | Secure Shell client for encrypted remote connections |
| `scp` | File Transfer | Securely copy files between hosts using SSH |
| `rsync` | File Transfer | Fast, versatile file copying and synchronization tool |
| `curl` | Data Transfer | Transfer data to or from a server using various protocols |
| `wget` | Download | Download files from the web non-interactively |

| Tool | Category | Purpose |
