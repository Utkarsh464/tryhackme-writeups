## Description
This room concludes the Linux Fundamentals series by covering advanced topics essential for cybersecurity professionals. The primary focus is on Bash shell scripting, which allows users to automate repetitive tasks, process data, and create powerful tools. Students learn to write scripts using variables, command substitution, conditional statements (if-else), loops (for, while), and functions. The room also covers input and output redirection using pipes and redirect operators, enabling students to chain commands together for complex data processing. Networking commands are introduced, including ip and ifconfig for interface configuration, ping for connectivity testing, ss and netstat for socket statistics, and ssh for secure remote access. File transfer methods such as scp and rsync are covered for moving data between systems. Package management is another key topic, teaching students how to install, update, and remove software using apt (Debian-based) and yum (RHEL-based) package managers. Finally, task scheduling with cron and system automation concepts round out the module.

## Learning Objectives
- Write and execute Bash shell scripts
- Use variables, conditionals, and loops in scripts
- Implement input-output redirection and command piping
- Configure network interfaces and test connectivity
- Transfer files securely between systems
- Manage software packages using apt and yum
- Schedule tasks using cron and crontab

## Key Tools and Technologies
- Bash shell scripting
- ip, ifconfig, ping, ss, netstat
- ssh, scp, rsync
- apt, yum, dpkg
- cron, crontab
- grep, awk, sed (introduction)

## Prerequisites
- Linux Fundamentals Part 2

## Expected Outcomes
Students will be able to write Bash scripts to automate tasks, configure basic networking, transfer files between systems, manage software packages, and schedule automated tasks. These skills are directly applicable to real-world cybersecurity operations and system administration.
