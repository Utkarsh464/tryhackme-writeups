# Public Key Cryptography Basics — Tools

- **OpenSSL:** The primary tool for working with public key cryptography on the command line. Supports key generation, CSR creation, certificate management, and TLS connections.
- **certtool (GnuTLS):** An alternative to OpenSSL for certificate and key management.
- **GnuPG (GPG):** Implements the OpenPGP standard for public key encryption and signing, which uses a web-of-trust model rather than a hierarchical PKI.
- **KeyStore Explorer:** A GUI tool for managing Java keystores and certificates.
- **Online tools (SSL Labs, certificate decoder):** Web-based utilities for analyzing and debugging TLS certificates.
