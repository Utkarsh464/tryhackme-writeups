## Description

JavaScript Essentials provides a comprehensive introduction to the programming language that powers interactivity on the modern web. As the most widely used client-side scripting language, JavaScript is a critical skill for web security professionals because many vulnerabilities, including Cross-Site Scripting (XSS), arise from improper JavaScript handling. This room starts with the absolute basics of JavaScript syntax, data types, and control flow, making it accessible even to learners with no prior programming experience. It then progresses through variables (var, let, const), functions, objects, arrays, and type coercion. The room explores the Document Object Model (DOM), showing how JavaScript interacts with HTML elements to create dynamic user experiences. Event handling is covered in depth, including event listeners, event propagation, and preventing default behaviors. Asynchronous programming is introduced through callbacks, Promises, and the async/await syntax, which are essential for understanding modern web APIs. The Fetch API is explained as the modern way to make HTTP requests from the browser. Security-focused sections cover the Same-Origin Policy, Content Security Policy (CSP), and how to identify and prevent DOM-based XSS vulnerabilities. By the end of this room, learners will be able to read, write, and analyze JavaScript code, understand how it executes in the browser, and recognize common security pitfalls.

## Objectives

- Manipulate the DOM to read and modify web page content
- Handle events and asynchronous operations
- Make HTTP requests using the Fetch API
