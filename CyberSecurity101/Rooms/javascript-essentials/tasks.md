# JavaScript Essentials - Tasks

## Task 1: Introduction to JavaScript
- Understand the role of JavaScript in web applications
- Differentiate between client-side and server-side JavaScript
- Learn how to execute JavaScript in the browser console

## Task 2: Variables and Data Types
- Declare variables using var, let, and const
- Understand the differences between var, let, and const
- Work with strings, numbers, booleans, null, undefined, and symbols
- Practice type coercion and type checking with typeof

## Task 3: Control Flow
- Use conditional statements: if, else if, else, switch
- Understand truthy and falsy values
- Write loops: for, while, do-while
- Iterate over arrays with forEach and for-of

## Task 4: Functions
- Declare functions using function declarations and expressions
- Use arrow functions (=>) for concise syntax
- Understand function parameters, default parameters, and rest parameters
- Learn about scope (global, function, block) and closures

## Task 5: Objects and Arrays
- Create and manipulate JavaScript objects
- Access properties using dot notation and bracket notation
- Use array methods: push, pop, map, filter, reduce
- Understand JSON as a data interchange format

## Task 6: DOM Manipulation
- Select HTML elements using document.getElementById, querySelector
- Modify element content with innerHTML and textContent
- Change CSS styles dynamically
- Create and remove elements from the DOM

## Task 7: Events
- Add event listeners using addEventListener
- Understand event objects and their properties
- Learn about event propagation: capturing and bubbling
- Prevent default behaviors with preventDefault

## Task 8: Asynchronous JavaScript
- Understand synchronous vs asynchronous execution
- Use callbacks for async operations
- Create and consume Promises
- Use async/await for cleaner async code
- Handle errors with try/catch blocks

## Task 9: Fetch API and HTTP Requests
- Make GET requests using fetch
- Send POST requests with JSON data
- Handle response status codes and errors
- Understand CORS and same-origin restrictions

## Task 10: Security Considerations
- Understand the Same-Origin Policy and its purpose
- Learn about Content Security Policy (CSP) headers
- Identify DOM-based XSS vulnerabilities
- Practice safe coding practices to prevent XSS

## Task 11: Conclusion and Review
- Review all JavaScript concepts covered
- Understand how JavaScript relates to web security
- Prepare for advanced web exploitation topics
