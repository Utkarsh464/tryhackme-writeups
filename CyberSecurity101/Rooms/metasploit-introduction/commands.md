# Metasploit: Introduction — Commands

| Command | Description |
|---------|-------------|
| `msfconsole` | Launch the Metasploit Framework console |
| `msfconsole -q` | Launch without the banner |
| `help` | Display help for available commands |
| `use <module_path>` | Select a module to use |
| `show exploits` | List all exploit modules |
| `show payloads` | List all payload modules |
| `show auxiliary` | List all auxiliary modules |
| `show post` | List all post-exploitation modules |
| `show options` | Display the current module's options |
| `show targets` | Display compatible targets for the module |
| `show advanced` | Display advanced options for the module |
| `set <option> <value>` | Set a module option |
| `setg <option> <value>` | Set a global option (persists across modules) |
| `unset <option>` | Unset an option |
| `search <query>` | Search for modules |
| `info` | Display detailed information about the current module |
| `back` | Leave the current module context |
| `exit` | Exit msfconsole |
