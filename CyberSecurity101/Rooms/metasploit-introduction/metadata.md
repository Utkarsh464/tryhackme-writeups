# Room: Metasploit: Introduction

- **URL:** https://tryhackme.com/room/metasploitintro
- **Description:** A guided introduction to the Metasploit Framework, the most widely used exploitation framework in penetration testing. This room covers the Metasploit interface (msfconsole), module types (exploit, auxiliary, payload, encoder, post, nop), navigating the module database, and basic workflows for searching and configuring modules. Learners gain familiarity with the core architecture that makes Metasploit a powerful platform for developing and executing exploit code against remote targets.
- **Difficulty:** Easy
- **Time:** ~1 hour
- **Tier:** Free
- **Objectives:**
  - Launch and navigate the msfconsole interface
  - Understand the Metasploit module hierarchy and types
  - Search for modules using keywords and CVE identifiers
  - Display and interpret module information and options
  - Set global and module-specific variables
  - Understand the difference between active and auxiliary modules
- **Tools:** Metasploit Framework (msfconsole)
- **Concepts:** Exploit, payload, auxiliary, encoder, post module, nop, msfconsole, RHOSTS, LHOST
