# Metasploit: Introduction — Tools

- **Metasploit Framework (msfconsole):** The primary tool. Open-source and maintained by Rapid7. Available by default on Kali Linux. Contains thousands of modules across all categories.
- **msfvenom:** A standalone payload generator and encoder. Can create payloads in many formats (exe, elf, python, powershell, etc.) without launching msfconsole.
- **Metasploit Database (msfdb):** A PostgreSQL-backed database that stores scan results, sessions, and loot. Enables workspace management and session tracking.
- **Armitage:** A graphical front-end for Metasploit. Provides point-and-click exploitation, visualization of targets, and team collaboration features.
- **Resource Scripts:** Metasploit automation scripts (.rc files) that execute a sequence of commands automatically. Useful for reproducible workflows.
