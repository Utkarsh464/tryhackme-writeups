# Tools: Linux Fundamentals Part 1

## Primary Tools (Commands)

| Tool | Category | Purpose |
|------|----------|---------|
| Bash Shell | Shell | Command-line interpreter for executing commands |
| Terminal Emulator | Interface | Application providing terminal access (GNOME Terminal, Konsole, xterm) |

## File Navigation Commands

| Command | Purpose |
|---------|---------|
| `ls` | List files and directories with optional format options |
| `cd` | Change the current working directory |
| `pwd` | Print the absolute path of the current directory |
| `tree` | Display directory structure as a tree |

## File Manipulation Commands

| Command | Purpose |
|---------|---------|
| `touch` | Create empty files or update file timestamps |
| `mkdir` | Create new directories |
| `cp` | Copy files and directories |
| `mv` | Move or rename files and directories |
| `rm` | Delete files and directories |
| `cat` | Display and concatenate file contents |
| `less` | View file contents with pagination and search |
| `more` | View file contents with basic pagination |
| `head` | Display the first lines of a file |
| `tail` | Display the last lines of a file |
| `file` | Determine the type of a file |
| `echo` | Print text to standard output |

## Documentation Commands

| Command | Purpose |
|---------|---------|
| `man` | Display the manual page for a command |
| `whatis` | Display a one-line description of a command |
| `apropos` | Search manual page names and descriptions |
| `help` | Display help for shell built-in commands |
