## Description
This room introduces the Linux operating system from the ground up, assuming no prior experience. Linux is an open-source, Unix-like operating system that powers the majority of servers, cloud infrastructure, embedded devices, and security tools worldwide. In cybersecurity, Linux is the preferred platform for penetration testing distributions like Kali Linux and Parrot OS, as well as for security appliances, web servers, and database servers. This first part covers what Linux is, why it is important in cybersecurity, and how to access a Linux terminal either through a local installation, virtual machine, or TryHackMe's in-browser environment. Students learn the most fundamental Linux commands for navigating the filesystem and manipulating files. Topics include the directory hierarchy, absolute and relative paths, and core commands such as ls, cd, pwd, cat, echo, touch, mkdir, cp, mv, rm, and file. The room also teaches students how to get help using the man command and how to use the terminal effectively.

## Learning Objectives
- Understand what Linux is and its role in cybersecurity
- Access a Linux terminal
- Navigate the Linux filesystem using command-line commands
- Create, copy, move, and delete files and directories
- Read file contents using various commands
- Use the manual pages to learn about commands
- Understand the Linux filesystem hierarchy

## Key Tools and Technologies
- Bash shell
- Linux terminal
- GNU Core Utilities

## Prerequisites
- None

## Expected Outcomes
Students will be able to log into a Linux system, navigate the filesystem, and perform basic file operations using the command line. They will understand the Linux directory structure and know how to get help with commands.
