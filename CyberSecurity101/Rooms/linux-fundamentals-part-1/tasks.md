# Tasks: Linux Fundamentals Part 1

## Task 1: Introduction to Linux

**Purpose:** Understand what Linux is and why it matters in cybersecurity.

**Skills:** Conceptual understanding of Linux.

**Theory:** Linux is an open-source, Unix-like operating system widely used in servers, cloud computing, embedded devices, and cybersecurity tools. Distributions like Ubuntu, Debian, CentOS, and Kali Linux serve different purposes. Most cybersecurity tools are developed for Linux first, making it essential knowledge.

**Commands:** None

---

## Task 2: Running Your First Commands

**Purpose:** Access a Linux terminal and run basic commands.

**Skills:** Terminal access, command execution.

**Theory:** The terminal provides a text-based interface to the operating system. Commands are programs that perform specific actions. The first commands users learn are typically echo (print text), whoami (show current user), and date (show current date and time).

**Commands:**
- echo - Display a line of text
- whoami - Print current username
- date - Display system date and time

---

## Task 3: Filesystem Navigation

**Purpose:** Navigate the Linux directory hierarchy.

**Skills:** Path navigation, directory listing.

**Theory:** Linux uses a hierarchical filesystem with a single root directory (/). Directories branch from the root, including /home (user files), /etc (configuration files), /var (variable data), /tmp (temporary files), and /bin (essential binaries). Paths can be absolute (starting from /) or relative (starting from current location).

**Commands:**
- pwd - Print working directory
- ls - List directory contents
- cd - Change directory

---

## Task 4: Working with Files

**Purpose:** Create, view, copy, move, and delete files.

**Skills:** File manipulation.

**Theory:** Files are the fundamental unit of storage in Linux. Different commands are used for creating files (touch), viewing contents (cat, less, head, tail), copying (cp), moving or renaming (mv), and deleting (rm). Each command has options that modify its behavior.

**Commands:**
- touch - Create empty file or update timestamp
- cat - Concatenate and display files
- less - View file with pagination
- head - Display first lines of file
- tail - Display last lines of file
- cp - Copy files and directories
- mv - Move or rename files
- rm - Remove files
- file - Determine file type
- mkdir - Create directory

---

## Task 5: Getting Help

**Purpose:** Learn to use built-in help resources.

**Skills:** Self-learning, documentation navigation.

**Theory:** Linux provides extensive built-in help. The man command displays manual pages for commands. The --help flag provides a quick usage summary. The whatis command shows brief command descriptions. Learning to read documentation is essential for independent problem-solving.

**Commands:**
- man - Display manual pages
- whatis - Show brief command descriptions
- apropos - Search manual page descriptions
