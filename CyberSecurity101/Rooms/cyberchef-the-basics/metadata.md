# Room: CyberChef: The Basics

## URL
https://tryhackme.com/room/cyberchefthebasics

## Description
CyberChef is a web-based application developed by GCHQ that acts as a "Cyber Swiss Army Knife" for data transformation. This room introduces learners to the CyberChef interface, its drag-and-drop recipe system, and its vast library of operations. Learners will practice encoding and decoding data in formats such as Base64, hexadecimal, binary, and URL encoding. They will also explore hashing operations (MD5, SHA1, SHA256), encryption and decryption using symmetric ciphers (AES, DES), compression and decompression, data extraction using regular expressions, and conditional logic within recipes. The room emphasizes practical workflows such as decoding obfuscated strings found in malware, extracting indicators of compromise from log data, and converting between data formats commonly encountered in forensic investigations. By the end of the room, learners will be comfortable building multi-step recipes, chaining operations, and using CyberChef's built-in magic wand feature to automatically detect and decode unknown data.

## Objectives
- Navigate the CyberChef interface including the recipe pane, input pane, output pane, and operation list
- Encode and decode data using Base64, hexadecimal, binary, and URL encoding operations
- Apply hashing algorithms (MD5, SHA1, SHA256, SHA512) to data
- Encrypt and decrypt data using AES and DES in various modes (ECB, CBC)
- Use conditional operations and regular expressions for data extraction
- Build multi-step recipes by chaining operations in the correct order
- Use the Magic wand to automatically detect encoding and decoding

## Tools
- CyberChef (https://gchq.github.io/CyberChef/)

## Concepts
- Data encoding vs. encryption
- Base64 encoding and its common use in malware and web applications
- Hexadecimal and binary representation of data
- Symmetric encryption (AES, DES) modes (ECB, CBC)
- Cryptographic hash functions and their properties
- Regular expressions for pattern matching and extraction
- Recipe-based data transformation pipelines
