## Description
This room builds on the foundational skills from Linux Fundamentals Part 1 and introduces essential system administration concepts. Linux is a multi-user operating system, meaning multiple users can access the same system simultaneously. Managing users, groups, and permissions is a core responsibility of any Linux administrator and is critical for security. This room covers user and group management commands including useradd, usermod, userdel, groupadd, and passwd. Students learn about Linux file permissions and ownership using chmod, chown, and chgrp, understanding the read-write-execute model for the owner, group, and others. The room also introduces process management, teaching students how to view running processes with ps and top, how to manage processes with kill, and how to run jobs in the background and foreground. Additionally, students learn about system services managed by systemd, using systemctl to start, stop, enable, and disable services. Logging with journalctl is also covered. Text editors like nano and vim are introduced for editing configuration files directly from the terminal.

## Learning Objectives
- Create and manage Linux user accounts and groups
- Set and modify file permissions and ownership
- Monitor and manage system processes
- Start, stop, and enable system services
- View and search system logs
- Edit text files using terminal-based editors

## Key Tools and Technologies
- useradd, usermod, userdel, passwd
- chmod, chown, chgrp
- ps, top, kill, bg, fg
- systemctl, journalctl
- nano, vim
