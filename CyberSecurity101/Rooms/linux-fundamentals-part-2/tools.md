# Tools: Linux Fundamentals Part 2

## User Account Management Tools

| Tool | Category | Purpose |
|------|----------|---------|
| `useradd` | User Management | Create new user accounts |
| `usermod` | User Management | Modify existing user account properties |
| `userdel` | User Management | Delete user accounts |
| `passwd` | User Management | Set or change user passwords |
| `groupadd` | Group Management | Create new groups |
| `groupdel` | Group Management | Delete groups |
| `groups` | Information | Display user group membership |
| `id` | Information | Display user and group ID numbers |
| `who` | Information | Show who is logged into the system |
| `last` | Information | Show last login history |

## File Permission Tools

| Tool | Category | Purpose |
|------|----------|---------|
| `chmod` | Permissions | Change file and directory permissions |
| `chown` | Permissions | Change file and directory ownership |
| `chgrp` | Permissions | Change group ownership of files |
| `umask` | Permissions | Set default permission mask for new files |

## Process Management Tools

| Tool | Category | Purpose |
|------|----------|---------|
| `ps` | Process Management | Display currently running processes |
| `top` | Process Management | Interactive process viewer with real-time updates |
| `htop` | Process Management | Enhanced interactive process viewer (may need installation) |
| `kill` | Process Management | Send signals to terminate or control processes |
| `killall` | Process Management | Kill processes by name |
| `pkill` | Process Management | Kill processes by pattern |
| `nice` | Scheduling | Run a program with modified scheduling priority |
| `renice` | Scheduling | Alter priority of running processes |

## Service Management Tools

| Tool | Category | Purpose |
|------|----------|---------|
| `systemctl` | Service Management | Control systemd services and system states |
| `journalctl` | Log Management | Query and view systemd journal logs |

## Text Editors

| Tool | Category | Purpose |
|------|----------|---------|
| `nano` | Text Editor | Simple, beginner-friendly terminal text editor |
| `vim` | Text Editor | Powerful modal text editor with extensive features |
