## Description

The OWASP Top 10 - 2021 room provides a comprehensive deep-dive into the ten most critical web application security risks as defined by the Open Web Application Security Project (OWASP). The OWASP Top 10 is widely regarded as the definitive standard for web application security awareness, and it is regularly updated to reflect the evolving threat landscape. This room is the cornerstone of the Web Hacking module, synthesizing concepts from all previous rooms into a practical understanding of real-world web vulnerabilities. The 2021 edition introduced significant changes from the 2017 edition, including a new category for Insecure Design, the merging of several categories, and a renewed focus on software and data integrity. Each vulnerability category is explored through explanations of how the vulnerability works, real-world examples of breaches and attacks, hands-on exercises for exploitation, and detailed guidance on prevention and mitigation. The room covers A01 Broken Access Control, A02 Cryptographic Failures, A03 Injection, A04 Insecure Design, A05 Security Misconfiguration, A06 Vulnerable and Outdated Components, A07 Identification and Authentication Failures, A08 Software and Data Integrity Failures, A09 Security Logging and Monitoring Failures, and A10 Server-Side Request Forgery (SSRF). Learners practice exploiting each vulnerability in controlled environments, understanding not just the technical exploitation but also the business impact and remediation strategies. By the end of this room, learners will be able to identify, exploit, and mitigate all ten categories of web application vulnerabilities, providing a solid foundation for professional penetration testing and bug bounty hunting.

## Objectives
- Understand all ten categories of the OWASP Top 10 - 2021
- Identify vulnerabilities in web applications through manual testing
- Exploit common web vulnerabilities in controlled environments
- Implement effective mitigation and remediation strategies
- Apply security best practices to web application development

## Concepts
- Broken Access Control (IDOR, privilege escalation)
- Cryptographic failures (weak encryption, exposed data)
- Injection attacks (SQL, NoSQL, OS command)
- Insecure design and architecture flaws
- Security misconfiguration and default settings
- Supply chain and dependency risks
- Authentication and session management flaws
- Software integrity and update security
- Logging, monitoring, and incident response
- Server-Side Request Forgery (SSRF)
