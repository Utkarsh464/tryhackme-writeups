# Training Impact on Teams — Tools

## GoPhish
- **Description:** Open-source phishing simulation framework that allows organizations to create and manage realistic phishing campaigns. Supports multiple sending profiles, landing pages, email templates, and user management. Provides detailed reporting on campaign results including clicks, credential submissions, and reported emails.
- **Website:** https://getgophish.com/
- **Key Features:** Web-based admin interface, REST API, SMTP integration, landing page cloning, user groups, campaign scheduling, and detailed click tracking.

## Atomic Red Team
- **Description:** An open-source library of tests mapped to the MITRE ATT&CK framework that allows blue teams to validate their detection and response capabilities. Each test is a simple, executable procedure that simulates a specific adversary technique.
- **Repository:** https://github.com/redcanaryco/atomic-red-team
- **Key Features:** Tests for all MITRE ATT&CK techniques, cross-platform support (Windows, Linux, macOS), automated execution via PowerShell or shell scripts, and integration with SIEM and EDR platforms.

## Caldera
- **Description:** An automated adversary emulation platform developed by MITRE. It allows red and purple teams to design and execute adversarial campaigns using ATT&CK techniques, providing realistic attack scenarios for testing detection and response.
- **Repository:** https://github.com/mitre/caldera
- **Key Features:** Plugin-based architecture, REST API, ability to run agents on multiple platforms, pre-built adversarial profiles, and integration with sandbox environments.

## Moodle / Canvas
- **Description:** Learning management systems (LMS) used to host, deliver, and track training content. Moodle is open-source, while Canvas is a commercial platform popular in academic and corporate settings. Both support quizzes, assignments, forums, and grade tracking.
- **Use Cases:** Delivering security awareness modules, hosting technical training materials, tracking completion rates, and administering knowledge assessments.

## KnowBe4
- **Description:** A commercial security awareness training and phishing simulation platform. Offers a large library of training content, automated phishing campaigns, and compliance reporting. Widely used in enterprise environments.
- **Key Features:** Pre-built training modules, automated campaign scheduling, risk scoring, compliance tracking, and integrations with Active Directory and SIEM platforms.
