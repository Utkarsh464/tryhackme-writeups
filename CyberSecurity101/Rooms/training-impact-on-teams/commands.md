# Training Impact on Teams — Commands

This room focuses on training program design and does not introduce traditional command-line tools. The following software platforms and commands are referenced:

| Command / Tool | Description |
|----------------|-------------|
| `GoPhish` | Open-source phishing simulation framework |
| `gophish --config config.json` | Launch GoPhish server with specific configuration |
| `setoolkit` | Social Engineering Toolkit used in red team exercises |
| `modlishka` | Reverse proxy phishing framework for credential harvesting |
| `apache2-utils / htpasswd` | Create password files for simulation login pages |
| `python3 -m smtpd -n -c DebuggingServer` | SMTP debugging server for test phishing campaigns |
| `openssl req -x509 -newkey rsa:4096 -keyout key.pem -out cert.pem -days 365` | Generate TLS certificate for phishing simulation server |
| MISP | Malware Information Sharing Platform for threat intelligence sharing |
| Moodle / Canvas | Learning management systems for hosting training content |
| CyberSeek | Online tool for skills gap analysis (no command line) |

Additional platforms for exercises:

| Tool | Purpose |
|------|---------|

| Caldera | Automated adversary emulation platform for red/blue team exercises |
| Purple Knight | Active Directory security assessment tool for purple teaming |
