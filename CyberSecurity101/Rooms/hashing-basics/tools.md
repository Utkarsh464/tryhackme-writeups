# Hashing Basics — Tools

- **sha256sum / md5sum / sha1sum:** Standard Linux command-line tools for computing file hashes. Part of the GNU Core Utilities.
- **openssl dgst:** OpenSSL's digest command for computing hashes with many algorithms including MD5, SHA-1, SHA-256, SHA-512, and BLAKE2.
- **shasum:** Perl-based hash utility available on macOS and Linux.
- **hash-identifier:** A tool (often used in CTFs) that attempts to identify the type of hash based on its format and length.
- **Python hashlib:** Python's standard library module for computing hashes programmatically. Useful for scripting custom hash operations.
- **Online hash databases (CrackStation, Hashes.com):** Lookup services for reversing unsalted hashes against known wordlists.
