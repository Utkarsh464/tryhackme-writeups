# Room: Hashing Basics

- **URL:** https://tryhackme.com/room/hashingbasics
- **Description:** This room explores cryptographic hash functions, one-way mathematical algorithms that produce fixed-size digests from arbitrary input data. Learners will understand the properties that make hash functions useful for integrity checking, password storage, and digital signatures. The room covers common algorithms (MD5, SHA-1, SHA-256, SHA-3), the importance of salting passwords, and the difference between hashing and encryption. Practical exercises involve computing hashes, verifying file integrity, and understanding collision vulnerabilities.
- **Difficulty:** Easy
- **Time:** ~1 hour
- **Tier:** Premium
- **Objectives:**
  - Define the properties of a cryptographic hash function
  - Distinguish between hashing, encryption, and encoding
  - Compute hashes using common algorithms (MD5, SHA-1, SHA-256)
  - Explain the importance of salting passwords
  - Understand collision resistance and preimage resistance
  - Recognize why MD5 and SHA-1 are considered broken
  - Verify file integrity using hash comparisons
- **Tools:** OpenSSL, sha256sum, md5sum
- **Concepts:** Hash function, digest, collision, avalanche effect, salt, preimage resistance, SHA, MD5
