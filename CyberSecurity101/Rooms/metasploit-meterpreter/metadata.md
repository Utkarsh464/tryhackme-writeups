# Room: Metasploit: Meterpreter

- **URL:** https://tryhackme.com/room/meterpreter
- **Description:** This room focuses on the Meterpreter payload, the most advanced interactive shell available in Metasploit. Meterpreter operates entirely in memory, never touching the disk, making it highly stealthy. Learners will explore Meterpreter's extensive post-exploitation capabilities including privilege escalation, file system manipulation, process migration, keylogging, screen capture, credential dumping, and pivoting through compromised networks. The room emphasizes practical post-exploitation techniques used in real penetration tests.
- **Difficulty:** Medium
- **Time:** ~1 hour
- **Tier:** Premium
- **Objectives:**
  - Understand how Meterpreter differs from traditional shell payloads
  - Perform privilege escalation using Meterpreter modules
  - Navigate and manipulate the target file system
  - Capture keystrokes and screenshots
  - Dump password hashes and credentials
  - Migrate to stable processes for persistence
  - Set up pivoting through compromised hosts
- **Tools:** Metasploit Framework, Meterpreter
- **Concepts:** Meterpreter, post-exploitation, privilege escalation, pivoting, credential dumping, process migration
