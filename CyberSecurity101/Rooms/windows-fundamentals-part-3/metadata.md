# Windows Fundamentals Part 3

## Room Information

- **Difficulty:** Easy
- **Estimated Time:** 1 hour
- **Access:** Premium

## Description
This room completes the Windows Fundamentals series by covering advanced security features and enterprise management tools. Students explore Windows Defender Antivirus, Microsoft's built-in antivirus solution, learning how to configure real-time protection, scan options, and exclusions. The Windows Firewall with Advanced Security is covered in depth, including inbound and outbound rules, connection security rules, and monitoring. BitLocker Drive Encryption is introduced as a method for protecting data at rest through full disk encryption. The Event Viewer application is explored in detail, teaching students how to navigate Windows logs, create custom views, and filter events for security analysis. The Microsoft Management Console (MMC) is introduced as a framework for hosting administrative snap-ins. PowerShell is presented as a powerful command-line shell and scripting language for automation. Windows Update and patch management concepts are covered to explain how Microsoft keeps Windows systems secure through regular updates.

## Learning Objectives
- Configure Windows Defender Antivirus settings
- Create and manage Windows Firewall rules
- Understand BitLocker drive encryption
- Use Event Viewer to analyze Windows logs
- Work with Microsoft Management Console (MMC)
- Perform basic PowerShell commands
- Manage Windows Update and patching

## Key Tools and Technologies
- Windows Defender Antivirus
- Windows Firewall with Advanced Security (wf.msc)
- BitLocker Drive Encryption
- Event Viewer (eventvwr.msc)
- Microsoft Management Console (mmc)
- PowerShell
- Windows Update

## Prerequisites
- Windows Fundamentals Part 2

## Expected Outcomes
Students will be able to configure Windows security features including antivirus, firewall, encryption, and logging. They will understand the role of PowerShell in Windows administration and know how to keep Windows systems updated and secure.
