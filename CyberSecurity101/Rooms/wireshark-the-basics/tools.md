# Wireshark: The Basics — Tools

- **Wireshark:** The industry-standard GUI-based network protocol analyzer. Supports hundreds of protocol dissectors, advanced filtering, statistics, and visualization.
- **tshark:** The command-line interface to Wireshark's capture engine. Useful for scripting automated analysis, processing large captures on remote servers, and integrating with other tools.
- **mergecap:** Part of the Wireshark suite; merges multiple pcap files into a single file.
- **editcap:** Modifies and manipulates pcap files. Can split files, remove duplicate packets, and truncate captures.
- **capinfos:** Prints statistics and information about capture files.
