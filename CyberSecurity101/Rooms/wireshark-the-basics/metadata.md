# Room: Wireshark: The Basics

- **URL:** https://tryhackme.com/room/wiresharkthebasics
- **Description:** A hands-on introduction to Wireshark, the most widely used network protocol analyzer. This room teaches learners how to capture live network traffic, navigate the Wireshark interface, apply display and capture filters, follow TCP streams, and inspect packets at each layer of the protocol stack. Practical exercises involve analyzing real traffic captures to identify protocols, flag suspicious activity, and understand normal network behavior.
- **Difficulty:** Easy
- **Time:** ~1 hour
- **Tier:** Premium
- **Objectives:**
  - Install and launch Wireshark and understand its interface components
  - Capture live traffic on a network interface
  - Apply capture filters using BPF syntax
  - Use display filters to isolate specific traffic
  - Follow TCP and UDP streams to reconstruct conversations
  - Inspect packet headers across all OSI layers
  - Export objects and statistics from captures
- **Tools:** Wireshark
- **Concepts:** Packet capture, BPF, display filters, TCP stream following, protocol dissection
