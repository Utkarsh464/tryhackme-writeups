# Web Application Basics - Tasks

## Task 1: Introduction to Web Applications
- Understand what constitutes a web application
- Differentiate between static and dynamic websites
- Identify the components of a web application stack (client, server, database)

## Task 2: The HTTP Protocol
- Learn the structure of HTTP requests and responses
- Understand the request line format: METHOD path VERSION
- Examine response status lines and their meaning

## Task 3: HTTP Methods
- Explore GET requests for retrieving resources
- Learn POST requests for submitting data
- Understand PUT for updating resources and DELETE for removal
- Practice sending different request types

## Task 4: HTTP Status Codes
- Memorize common status codes: 200 OK, 301 Moved Permanently, 403 Forbidden, 404 Not Found, 500 Internal Server Error
- Identify the class of a status code from its first digit
- Interpret server responses during testing

## Task 5: HTTP Headers
- Examine common request headers: Host, User-Agent, Accept, Cookie, Authorization
- Examine common response headers: Set-Cookie, Content-Type, Location, Server
- Understand how headers control caching, security, and content negotiation

## Task 6: Cookies and Sessions
- Learn how cookies maintain state in a stateless protocol
- Understand session identifiers and their security implications
- Practice reading and manipulating cookies in browser tools

## Task 7: HTTPS and Encryption
- Understand the role of TLS/SSL in web security
- Learn how certificates validate server identity
- Recognize the difference between HTTP and HTTPS traffic

## Task 8: Using Developer Tools
- Open and navigate browser developer tools
- Use the Network tab to inspect HTTP traffic
- View request and response details in real-time

## Task 9: Practical Application
- Intercept a login form submission
- Analyze the request structure
- Modify parameters and observe server behavior
- Identify security misconfigurations from response headers

## Task 10: Conclusion and Summary
- Review all concepts covered
- Understand the attack surface of web applications
- Prepare for advanced web hacking modules
