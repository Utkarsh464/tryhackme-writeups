# Web Application Basics

## Room Information
- **URL**: https://tryhackme.com/room/webapplicationbasics
- **Difficulty**: Easy
- **Subscription**: Free
- **Estimated Time**: ~1 hour

## Description

Web Application Basics is the starting point for understanding how web applications function and how they can be attacked. This room demystifies the HTTP protocol, the foundation of all web communication, by breaking down requests, responses, methods, status codes, and headers. Learners explore the client-server architecture and how browsers communicate with web servers to deliver dynamic content. The room covers essential topics including Uniform Resource Locators (URLs), HTTP methods (GET, POST, PUT, DELETE, PATCH), status code classes (1xx informational, 2xx success, 3xx redirection, 4xx client error, 5xx server error), request and response headers, cookies for session management, and the HTTPS encryption layer. Practical exercises involve using browser developer tools to inspect network traffic, modifying and resending requests, and understanding how form data is submitted. This room also introduces the concept of statelessness in HTTP and how sessions are maintained using cookies and tokens. By the end of this room, learners will be able to manually craft HTTP requests, interpret server responses, and understand the basic attack surface of any web application.

## Objectives
- Understand the HTTP/HTTPS protocol and request-response cycle
- Identify and interpret HTTP status codes and headers
- Use browser developer tools to inspect web traffic
- Understand cookies, sessions, and authentication mechanisms
- Recognize common web application attack surfaces
