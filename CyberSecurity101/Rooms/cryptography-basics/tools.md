# Cryptography Basics — Tools

- **OpenSSL:** A comprehensive command-line toolkit for TLS/SSL and cryptographic operations. Supports encryption, decryption, key generation, certificate management, and hashing.
- **GnuPG (GPG):** An open-source implementation of the OpenPGP standard for encrypting and signing data. Supports both symmetric and asymmetric encryption.
- **HashCalc / HashMyFiles:** GUI tools for calculating file hashes using various algorithms.
- **CyberChef:** A web-based tool (often used in TryHackMe) for performing various data transformations including encryption, encoding, compression, and analysis.
- **VeraCrypt / LUKS:** Disk encryption tools that apply cryptographic concepts at the storage layer.
