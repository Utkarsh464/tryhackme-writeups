## Description
This room dives deeper into Windows system administration and security features. Students learn about User Account Control (UAC), which is Windows' primary mechanism for preventing unauthorized system changes by prompting for administrator approval. The room covers managing local users and groups through the Local Users and Groups Manager (lusrmgr.msc), including creating, modifying, and deleting user accounts. Windows security policies, configurable through secpol.msc, are explored along with account policies, audit policies, and user rights assignments. The Windows Registry, a hierarchical database that stores operating system and application configuration settings, is introduced with guidance on its structure and safe navigation. Networking features including TCP/IP configuration, file sharing, and Remote Desktop Protocol (RDP) are covered. Students learn how to configure network settings, set up file shares, and connect to remote systems. The room also covers the Windows Firewall basics for controlling inbound and outbound network traffic.

## Learning Objectives
- Understand User Account Control (UAC) and its security role
- Manage local user accounts and groups
- Configure Windows security policies
- Navigate the Windows Registry safely
- Configure Windows networking and file sharing
- Use Remote Desktop Protocol (RDP) for remote access
- Understand Windows Firewall fundamentals

## Key Tools and Technologies
- Local Users and Groups Manager (lusrmgr.msc)
- Local Security Policy (secpol.msc)
- Windows Registry Editor (regedit)
- Windows Firewall
- Remote Desktop Connection
- Network and Sharing Center

## Expected Outcomes
Students will be able to manage local users and groups, configure security policies, understand the Windows Registry, set up basic networking and file sharing, and use RDP for remote administration. These skills are essential for Windows system administration and security.
