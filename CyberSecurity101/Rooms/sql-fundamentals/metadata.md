## Description

SQL Fundamentals teaches the Structured Query Language (SQL), the standard language for managing and querying relational databases. SQL is one of the most important technologies in computing, powering everything from small websites to enterprise applications. Understanding SQL is essential for web security because SQL injection attacks, which exploit improperly sanitized user input in SQL queries, remain one of the most common and dangerous web vulnerabilities. This room begins with the basics of relational databases: tables, rows, columns, primary keys, and foreign keys. Learners then progress through SELECT queries with WHERE clauses for filtering results, ORDER BY for sorting, and LIMIT for pagination. Aggregate functions (COUNT, SUM, AVG, MIN, MAX) are introduced for data analysis. The room covers JOIN operations (INNER JOIN, LEFT JOIN, RIGHT JOIN) for combining data from multiple tables, a critical skill for understanding complex database schemas during penetration testing. Subqueries and nested queries are explored for advanced data retrieval. The room also covers database manipulation with INSERT, UPDATE, and DELETE statements. Database relationships (one-to-one, one-to-many, many-to-many) and normalization principles are explained. Security-focused content includes understanding how SQL queries are constructed dynamically and how unsanitized input can alter query logic. By the end, learners can write complex SQL queries and identify potential injection points.

## Objectives
- Understand relational database structure and design
- Write SELECT queries to retrieve data from databases
- Use WHERE, ORDER BY, LIMIT, and aggregate functions
- Combine data from multiple tables using JOIN operations
- Perform data manipulation with INSERT, UPDATE, DELETE
- Recognize SQL injection vulnerabilities in query construction
