# Module 10: Defensive Security

## Overview

Defensive Security represents the critical shift from identifying vulnerabilities to protecting systems, detecting threats, and responding to incidents. While offensive security focuses on finding and exploiting weaknesses, defensive security is about building resilient systems, monitoring for malicious activity, and minimizing damage when attacks occur. This module provides a comprehensive introduction to the core disciplines of defensive cybersecurity: the roles and structure of Security Operations Centers (SOCs), the principles and practices of digital forensics, the systematic process of incident response, and the foundational skill of log analysis.

The module begins with Defensive Security Intro, which sets the stage by explaining the fundamental differences between offensive and defensive security. This room covers defense-in-depth strategies, the CIA triad (Confidentiality, Integrity, Availability), and the concept of preventing, detecting, and responding to threats. Learners understand why defensive security is equally as important as offensive security and how the two disciplines complement each other in a mature security program.

SOC Fundamentals dives into the operational heart of defensive security: the Security Operations Center. This room covers SOC team structures, roles (Tier 1 Analyst, Tier 2 Analyst, Tier 3 Analyst, SOC Manager), and the tools and processes used to monitor, triage, and escalate security incidents. Learners explore how SOCs use SIEM (Security Information and Event Management) platforms, endpoint detection and response (EDR) tools, and threat intelligence feeds to identify and respond to threats in real-time.

Digital Forensics Fundamentals introduces the scientific discipline of investigating digital evidence. This room covers forensic principles (locard's exchange principle, chain of custody), acquisition methods (disk imaging, memory capture), analysis techniques (file system forensics, registry analysis, timeline creation), and legal considerations. Learners understand how digital forensics supports incident response, criminal investigations, and internal inquiries.

Incident Response Fundamentals teaches the structured approach to handling security incidents. The room covers the NIST incident response lifecycle: Preparation, Detection and Analysis, Containment Eradication and Recovery, and Post-Incident Activity. Each phase is explained with practical examples and best practices. Learners understand how to create incident response plans, assemble response teams, and conduct post-incident reviews.

The module concludes with Logs Fundamentals, which covers the generation, collection, storage, and analysis of log data from various sources. Logs are the raw material of defensive security, and understanding how to read, interpret, and correlate log entries is essential for detecting and investigating security incidents. This room covers Windows Event Logs, Linux syslogs, web server access logs, firewall logs, and application-specific logging.

By the end of this module, learners will understand the defensive security landscape, the roles and processes involved in protecting organizations, and the foundational skills needed for a career in cybersecurity defense.

## Prerequisites

- Basic understanding of networking (Module 05)
- Familiarity with operating systems (Modules 02-03)
- No prior security operations experience required

## Learning Objectives

- Distinguish between offensive and defensive security roles
- Understand SOC operations and analyst responsibilities
- Apply digital forensics principles to evidence handling
- Follow structured incident response processes
- Analyze logs from various sources for security events
- Understand the cybersecurity defense lifecycle
