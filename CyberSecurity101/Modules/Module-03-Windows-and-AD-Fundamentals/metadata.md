# Module 03: Windows and Active Directory Fundamentals

## Module Name
Windows and AD Fundamentals

## Description
This module provides a thorough introduction to the Microsoft Windows operating system and Active Directory, the dominant enterprise directory service used by organizations worldwide. Windows powers the majority of desktop computers, many servers, and critical infrastructure in corporate environments. Active Directory (AD) is the backbone of identity and access management in Windows networks, controlling authentication, authorization, policy enforcement, and resource access for millions of users globally. Understanding Windows and Active Directory is essential for cybersecurity professionals because a significant portion of cyber attacks target Windows environments. Offensive security specialists need to understand AD attack paths, while defensive teams must know how to secure Windows networks and detect malicious activity. This module is divided into four rooms covering Windows fundamentals in three progressive parts and an introduction to Active Directory basics. Students will learn about the Windows filesystem, user accounts, permissions, security features, group policy, and the core components of Active Directory including domains, domain controllers, organizational units, group policy objects, and authentication protocols. This knowledge is critical for roles such as penetration testing, SOC analysis, incident response, and security architecture.

## Learning Objectives
- Navigate the Windows operating system interface and filesystem
- Understand Windows user accounts, groups, and permissions
- Configure Windows security settings and built-in protections
- Explain the architecture and components of Active Directory
- Manage users, groups, and organizational units in AD
- Understand Group Policy and its security implications
- Identify common Windows and AD attack vectors
- Recognize the importance of Windows in enterprise environments

## Expected Outcomes
Students completing this module will have a solid understanding of the Windows operating system from both a user and administrative perspective. They will be able to manage local users and groups, configure security settings, navigate Windows networking features, and understand the core components of Active Directory. Students will recognize common attack paths against Windows and AD environments and understand the defensive measures available to protect them. This knowledge is essential for advanced topics in exploitation, privilege escalation, and enterprise security assessment.
