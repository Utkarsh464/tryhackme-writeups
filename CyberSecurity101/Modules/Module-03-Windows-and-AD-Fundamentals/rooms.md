# Rooms: Windows and AD Fundamentals

## Room 1: Windows Fundamentals Part 1

**Room URL:** https://tryhackme.com/room/windowsfundamentalspart1

**Description:** This room introduces the Microsoft Windows operating system, covering its history, editions, and core user interface components. Students learn about the Windows filesystem structure, including drive letters, system folders, and user profile directories. The room also covers built-in Windows applications, the Control Panel, Settings app, Task Manager, and basic system information tools.

**Key Topics:**
- Windows versions and editions
- Windows desktop and interface
- Filesystem structure (NTFS, directories, paths)
- Built-in applications and tools
- Control Panel and Settings
- Task Manager
- System Information (msinfo32)

---

## Room 2: Windows Fundamentals Part 2

**Room URL:** https://tryhackme.com/room/windowsfundamentalspart2

**Description:** Building on Part 1, this room explores Windows system administration in greater depth. Topics include user account control (UAC), the Local Users and Groups manager, Windows security policies, the Windows Registry, and system configuration tools. Students also learn about Windows networking, shares, and remote access technologies like Remote Desktop Protocol (RDP).

**Key Topics:**
- User Account Control (UAC)
- Local users and groups management
- Windows Security policies
- Windows Registry overview
- System Configuration (msconfig)
- Windows networking and file sharing
- Remote Desktop Protocol (RDP)

---

## Room 3: Windows Fundamentals Part 3

**Room URL:** https://tryhackme.com/room/windowsfundamentalspart3

**Description:** The final Windows fundamentals room covers advanced security features and management tools. Students explore Windows Defender antivirus, the Windows Firewall with Advanced Security, BitLocker encryption, Event Viewer for logging, and the Microsoft Management Console (MMC). The room also introduces PowerShell as an administrative tool and covers Windows Update and patch management.

**Key Topics:**
- Windows Defender Antivirus
- Windows Firewall with Advanced Security
- BitLocker drive encryption
- Event Viewer and Windows logging
- Microsoft Management Console (MMC)
- PowerShell administration
- Windows Update and patching

---

## Room 4: Active Directory Basics

**Room URL:** https://tryhackme.com/room/activedirectorybasics

**Description:** This room introduces Active Directory, Microsoft's directory service used in enterprise Windows networks. Students learn about AD components including domains, domain controllers, organizational units (OUs), security groups, and Group Policy Objects (GPOs). The room covers authentication protocols like Kerberos and NTLM, and explains how AD enables centralized management of users, computers, and resources across a network.

**Key Topics:**
- What is Active Directory
- Domains and domain controllers
- Organizational Units (OUs)
- Security groups and users
- Group Policy Objects (GPOs)
- Kerberos and NTLM authentication
- AD security best practices
