## Module Summary
Module 14 serves as the final assessment for the Cyber Security 101 learning path, challenging learners to synthesize and apply everything they have learned across Modules 1 through 13. The module consists of a single comprehensive room focused on the OWASP Top 10 2025, which represents the most critical web application security risks identified by the security community. This edition introduces updated categories reflecting modern attack vectors including AI-driven threats, API-specific vulnerabilities, and supply chain risks. Learners will demonstrate their proficiency in identifying, exploiting, and remediating each vulnerability category in a hands-on lab environment. Successful completion validates readiness for entry-level cybersecurity roles and intermediate certifications. The room is medium difficulty and takes approximately two hours to complete. Learners should ensure they have completed all prior modules and are comfortable with web technologies, HTTP, and common vulnerability classes before attempting this capstone assessment.
