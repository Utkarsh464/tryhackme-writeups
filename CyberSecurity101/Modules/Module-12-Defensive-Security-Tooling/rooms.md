# Module 12: Defensive Security Tooling — Rooms

## 1. CyberChef: The Basics
- **Room:** CyberChef: The Basics
- **URL:** https://tryhackme.com/room/cyberchefthebasics
- **Difficulty:** Easy
- **Time:** ~1 hour
- **Tier:** Premium
- **Description:** Introduces CyberChef, the "Cyber Swiss Army Knife" for data transformation. Learn to use its drag-and-drop recipe interface to perform encoding, decoding, encryption, decryption, hashing, compression, and data extraction tasks essential for any security analyst.

## 2. CAPA: The Basics
- **Room:** CAPA: The Basics
- **URL:** https://tryhackme.com/room/capathebasics
- **Difficulty:** Easy
- **Time:** ~1 hour
- **Tier:** Premium
- **Description:** Covers the fundamentals of CAPA, Mandiant's static analysis tool for identifying malware capabilities. Learn to analyze PE files, interpret CAPA rule matches, and understand how capability detection aids in malware classification and triage.

## 3. REMnux: Getting Started
- **Room:** REMnux: Getting Started
- **URL:** https://tryhackme.com/room/remnuxgettingstarted
- **Difficulty:** Easy
- **Time:** ~1 hour
- **Tier:** Premium
- **Description:** Walks through the REMnux Linux distribution for malware analysis. Explore its preinstalled toolset for static and dynamic analysis, examine suspicious documents, decode malicious macros, and analyze network captures in a purpose-built environment.

## 4. FlareVM: Arsenal of Tools
- **Room:** FlareVM: Arsenal of Tools
- **URL:** https://tryhackme.com/room/flarevmarsenaloftools
- **Difficulty:** Easy
- **Time:** ~1 hour
- **Tier:** Premium
- **Description:** Demonstrates how to deploy and use FlareVM, Mandiant's Windows-based malware analysis distribution. Learn to install the environment, navigate its extensive tool collection, and perform common analysis tasks with debuggers, disassemblers, and process monitors.
