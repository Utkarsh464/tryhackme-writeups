# Module 06: Cryptography

## Name
Cryptography

## Description
This module introduces the fundamental concepts of cryptography, the science of secure communication. Learners will explore symmetric and asymmetric encryption, the role of public and private keys, digital signatures, and certificate authorities. The module also covers hashing algorithms and their use in data integrity and password storage, culminating in hands-on password cracking with John the Ripper. Understanding cryptography is essential for any cybersecurity professional, as encryption protects data at rest and in transit, ensures authenticity, and underpins secure protocols such as TLS, SSH, and IPsec. The module balances theoretical foundations with practical application using real-world tools.

## Objectives
- Differentiate between symmetric and asymmetric encryption and describe their use cases
- Explain how public key cryptography enables secure key exchange and digital signatures
- Understand the role of certificate authorities and the PKI trust model
- Describe common hashing algorithms and their properties (MD5, SHA-1, SHA-256, etc.)
- Use John the Ripper to crack password hashes using various attack modes
- Recognize the importance of cryptographic hygiene in system design

## Skills
- Distinguishing encryption types and algorithms
- Cryptographic key management concepts
- Hash analysis and verification
- Password hash cracking with wordlists and rules
- Understanding digital certificates and chains of trust

## Technologies
- Symmetric encryption (AES, DES)
- Asymmetric encryption (RSA, ECC)
- Public Key Infrastructure (PKI)
- X.509 certificates
- Hashing algorithms (MD5, SHA-1, SHA-2, SHA-3)
- Cryptographic attack modes

## Tools
- John the Ripper
- OpenSSL (conceptual)

## Prerequisites
- Basic command-line proficiency
- Completion of Modules 01 and 02 recommended
- No advanced mathematics required

## Outcomes
Learners will understand the core principles of encryption, hashing, and public key infrastructure. They will be able to identify cryptographic primitives used in common protocols, verify file integrity using hashes, and use John the Ripper to crack password hashes in a controlled environment. This knowledge is critical for securing systems, analyzing malware, and understanding authentication mechanisms.
