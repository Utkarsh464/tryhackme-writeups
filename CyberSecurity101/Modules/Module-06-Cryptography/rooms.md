# Module 06: Cryptography — Rooms

## 1. Cryptography Basics
- **Room:** Cryptography Basics
- **URL:** https://tryhackme.com/room/cryptographybasics
- **Difficulty:** Easy
- **Time:** ~1 hour
- **Tier:** Free
- **Description:** Introduces the fundamental concepts of cryptography including symmetric and asymmetric encryption, historical ciphers, and modern encryption algorithms. Learners will understand how encryption protects data and how keys are managed.

## 2. Public Key Cryptography Basics
- **Room:** Public Key Cryptography Basics
- **URL:** https://tryhackme.com/room/publickeycryptographybasics
- **Difficulty:** Easy
- **Time:** ~1 hour
- **Tier:** Premium
- **Description:** Explores asymmetric encryption in depth, covering RSA, Diffie-Hellman key exchange, digital signatures, and the web of trust. Explains how public and private keys work together to enable secure communication without shared secrets.

## 3. Hashing Basics
- **Room:** Hashing Basics
- **URL:** https://tryhackme.com/room/hashingbasics
- **Difficulty:** Easy
- **Time:** ~1 hour
- **Tier:** Premium
- **Description:** Covers cryptographic hash functions, their properties (deterministic, fast, preimage resistance), and common algorithms. Topics include password hashing, salting, and the difference between hashing and encryption.

## 4. John the Ripper: The Basics
- **Room:** John the Ripper: The Basics
- **URL:** https://tryhackme.com/room/johntheripperbasics
- **Difficulty:** Easy
- **Time:** ~1 hour
- **Tier:** Premium
- **Description:** Hands-on introduction to John the Ripper, a powerful password cracking tool. Covers dictionary attacks, brute-force modes, rule-based attacks, and cracking various hash types (MD5, SHA, bcrypt, NTLM).
