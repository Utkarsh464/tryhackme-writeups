# Module 04: Command Line

## Module Name
Command Line

## Description
This module focuses on developing proficiency with command-line interfaces (CLIs) across both Windows and Linux operating systems. The command line is the primary interface used by cybersecurity professionals for system administration, automation, security testing, and data analysis. Mastering the command line is essential because it provides greater speed, power, and flexibility compared to graphical user interfaces, and many security tools are only available through terminal environments. This module covers three distinct but complementary command-line environments: the traditional Windows Command Prompt (cmd.exe), Windows PowerShell (a powerful object-oriented scripting shell), and Linux shells (primarily Bash). Each environment has its own syntax, capabilities, and use cases in the cybersecurity field. Windows Command Prompt is important for legacy system administration and batch scripting. PowerShell is the modern Windows administration standard with deep integration into the Windows ecosystem, Active Directory, and enterprise management. Linux shells are ubiquitous in server environments, cloud infrastructure, and security distributions like Kali Linux. By completing this module, students will be able to navigate, automate, and manage systems using command-line interfaces on both major operating systems, a skill that is fundamental to nearly every cybersecurity role.

## Learning Objectives
- Navigate the Windows filesystem using Command Prompt
- Execute administrative tasks with Windows Command Prompt
- Understand PowerShell cmdlets, pipelines, and object manipulation
- Write PowerShell scripts for automation
- Navigate and manage Linux systems using Bash shell
- Write Bash scripts for task automation
- Compare and contrast Windows and Linux command-line environments
- Apply command-line skills to security-related tasks

## Skills
- Windows Command Prompt proficiency
- PowerShell scripting and automation
- Linux Bash shell proficiency
- Command-line file and process management
- Text processing and data extraction
- System administration via CLI
- Cross-platform command-line literacy

- Windows Command Prompt (cmd.exe)

- cmd.exe (Command Prompt)
- PowerShell (powershell.exe, pwsh)

- find, findstr (Windows text search)

- PowerShell cmdlets (Get-ChildItem, Get-Process, etc.)
- Task Scheduler (schtasks)
- Cron (Linux scheduling)

## Prerequisites
- Completion of Modules 01-03 recommended
- Basic understanding of files and processes
- Familiarity with either Windows or Linux as a user

## Expected Outcomes
Students will gain practical, hands-on experience with three major command-line environments. They will be able to navigate filesystems, manage files and processes, configure networking, and write automation scripts in both Windows and Linux environments. This cross-platform command-line fluency is a prerequisite for advanced cybersecurity topics including penetration testing, digital forensics, incident response, and security tool development. Students will understand when to use each shell environment and how to translate concepts between them.
