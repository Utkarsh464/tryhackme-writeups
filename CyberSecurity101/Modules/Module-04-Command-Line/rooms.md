# Rooms: Command Line

## Room 1: Windows Command Line

**Room URL:** https://tryhackme.com/room/windowscommandline

**Description:** This room introduces the Windows Command Prompt (cmd.exe), the traditional command-line interpreter for Windows. Students learn how to navigate the Windows filesystem using commands like dir, cd, and tree. The room covers file management commands (copy, move, del, ren), network diagnostics (ipconfig, ping, tracert, netstat), system information tools, and batch scripting basics. Understanding the Command Prompt is important for legacy system support and quick administrative tasks.

**Key Topics:**
- Navigating the Windows filesystem
- File and directory management
- Network configuration and diagnostics
- System information commands
- Batch file scripting basics
- Task management (tasklist, taskkill)

## Room 2: Windows PowerShell

**Room URL:** https://tryhackme.com/room/windowspowershell

**Description:** This room provides an introduction to Windows PowerShell, Microsoft's modern shell and scripting language built on the .NET framework. Unlike traditional text-based shells, PowerShell works with objects, enabling powerful data manipulation and automation. Students learn about cmdlets (pronounced command-lets), the pipeline, object filtering, and script construction. The room covers common administrative tasks such as file management, process control, service management, and Active Directory interaction.

**Key Topics:**
- PowerShell cmdlets and aliases
- The PowerShell pipeline
- Working with objects (properties and methods)
- Filtering and selecting data (Where-Object, Select-Object)
- File system and registry navigation
- Process and service management
- PowerShell scripting fundamentals
- Remoting with PowerShell

## Room 3: Linux Shells

**Room URL:** https://tryhackme.com/room/linuxshells

**Description:** This room covers Linux shells, primarily focusing on the Bash (Bourne Again SHell) shell, which is the default on most Linux distributions. Students learn shell fundamentals including command syntax, environment variables, input-output redirection, pipes, and job control. The room also covers shell scripting with variables, conditionals, loops, functions, and error handling. Understanding Linux shells is critical for cybersecurity work as most security tools are run from the command line.

**Key Topics:**
- Bash shell fundamentals
- Environment variables and PATH
- Input-output redirection (>, >>, <, |)
- Command piping and chaining
- Job control (background, foreground)
- Shell scripting (variables, conditionals, loops)
- Functions and error handling
- Shell customization (.bashrc, .bash_profile)
