# Module 02: Linux Fundamentals

## Module Name
Linux Fundamentals

## Description
This module provides a comprehensive introduction to the Linux operating system, which is the backbone of modern cybersecurity infrastructure. Linux powers the majority of servers, cloud environments, containers, and security tools used by professionals worldwide. Understanding Linux is essential for anyone pursuing a career in cybersecurity, as most penetration testing distributions (such as Kali Linux), security appliances, and enterprise servers run on Linux-based operating systems. The module is divided into three parts, progressively building from basic command-line navigation and file management to advanced topics like service management, process control, user administration, and shell scripting. Students will gain hands-on experience with the Linux terminal, learning to navigate the filesystem, manipulate files and directories, manage users and permissions, control processes, configure networking, and write simple scripts. This module assumes no prior Linux experience and starts from the very beginning.

## Learning Objectives
- Navigate the Linux filesystem using command-line interfaces
- Manage files and directories with common Linux commands
- Understand Linux file permissions and ownership
- Create and manage user accounts and groups
- Control and monitor system processes
- Configure basic networking settings
- Write and execute simple shell scripts
- Use text editors in the terminal
- Install and manage software packages
- Understand system services and daemons

## Skills
- Linux command-line proficiency
- File system navigation and management
- User and permission administration
- Process and service management
- Basic shell scripting
- Package management
- Network configuration
- System monitoring and logging

## Technologies

- Bash shell

## Tools

- ls, cd, pwd, cp, mv, rm, mkdir, touch

- cat, less, more, head, tail, echo

## Prerequisites
- Basic computer literacy
- Completion of Module 01 recommended
- No prior Linux experience required

## Expected Outcomes
Upon completing this module, students will be comfortable working in a Linux terminal environment. They will be able to perform everyday administrative tasks such as creating users, setting permissions, managing files, monitoring processes, and installing software. Students will also understand the Linux directory hierarchy and be able to navigate it efficiently. These skills are directly applicable to real-world cybersecurity roles where Linux is the primary operating system for both attack and defense.
