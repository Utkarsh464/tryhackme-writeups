# Rooms: Linux Fundamentals

## Room 1: Linux Fundamentals Part 1

**Room URL:** https://tryhackme.com/room/linuxfundamentalspart1

**Description:** The first part of the Linux Fundamentals series introduces the absolute basics of the Linux operating system. Students learn what Linux is, how to access a Linux terminal, and the most fundamental commands for navigating the filesystem and working with files. Topics include the ls, cd, pwd, cat, echo, touch, mkdir, cp, mv, rm, and file commands. This room also covers the concept of the Linux filesystem hierarchy and how to get help using the man command.

**Key Topics:**
- What is Linux and why it matters in cybersecurity
- Accessing the Linux terminal
- Basic filesystem navigation (ls, cd, pwd)
- File operations (touch, mkdir, cp, mv, rm)
- Reading files (cat, less, more, head, tail)
- Using the manual pages (man command)

## Room 2: Linux Fundamentals Part 2

**Room URL:** https://tryhackme.com/room/linuxfundamentalspart2

**Description:** Building on Part 1, this room dives deeper into Linux administration. Students learn about user and group management, file permissions and ownership, process management, and system monitoring. The room covers essential commands such as useradd, usermod, passwd, chmod, chown, ps, top, kill, and systemctl. Understanding these concepts is critical for maintaining secure Linux systems.

**Key Topics:**
- User and group management
- File permissions (chmod, chown)
- Process management (ps, top, kill)
- System services and daemons (systemctl)
- System monitoring and logging (journalctl)
- Text editors (nano, vim)

## Room 3: Linux Fundamentals Part 3

**Room URL:** https://tryhackme.com/room/linuxfundamentalspart3

**Description:** The final part of the Linux Fundamentals series covers advanced Linux topics including shell scripting, networking commands, package management, and automation. Students learn to write Bash scripts using variables, conditionals, loops, and functions. The room also covers network configuration tools, remote access with SSH, file transfer with scp, and software installation via package managers like apt and yum.

**Key Topics:**
- Bash shell scripting basics
- Variables, conditionals, and loops
- Networking commands (ip, ifconfig, netstat, ss)
- Remote access with SSH
- File transfer with scp and rsync
- Package management (apt, yum, dpkg)
- Scheduling tasks with cron
