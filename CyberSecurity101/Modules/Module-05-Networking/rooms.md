# Module 05: Networking — Rooms

## 1. Networking Concepts
- **Room:** Networking Concepts
- **URL:** https://tryhackme.com/room/networkingconcepts
- **Difficulty:** Easy
- **Time:** ~30 minutes
- **Tier:** Premium
- **Description:** Introduces fundamental networking concepts including the OSI model, TCP/IP model, IP addressing, subnetting, and how data is encapsulated and transmitted across networks. A perfect starting point for absolute beginners.

## 2. Networking Essentials
- **Room:** Networking Essentials
- **URL:** https://tryhackme.com/room/networkingessentials
- **Difficulty:** Easy
- **Time:** ~30 minutes
- **Tier:** Premium
- **Description:** Builds on basic concepts to cover essential networking components such as routers, switches, hubs, cables, and topologies. Learners will understand how local and wide-area networks are physically and logically structured.

## 3. Networking Core Protocols
- **Room:** Networking Core Protocols
- **URL:** https://tryhackme.com/room/networkingcoreprotocols
- **Difficulty:** Easy
- **Time:** ~30 minutes
- **Tier:** Premium
- **Description:** Dives into the core protocols that power the internet: TCP, UDP, IP, ICMP, ARP, DNS, DHCP, and HTTP. Each protocol is explained with its purpose, packet structure, and role in communication.

## 4. Networking Secure Protocols
- **Room:** Networking Secure Protocols
- **URL:** https://tryhackme.com/room/networkingsecureprotocols
- **Difficulty:** Easy
- **Time:** ~30 minutes
- **Tier:** Premium
- **Description:** Covers secure alternatives to common protocols, including HTTPS, SSH, SFTP, TLS, and IPsec. Explains why security matters at the protocol level and how encryption and authentication protect data in transit.

## 5. Wireshark: The Basics
- **Room:** Wireshark: The Basics
- **URL:** https://tryhackme.com/room/wiresharkthebasics
- **Difficulty:** Easy
- **Time:** ~1 hour
- **Tier:** Premium
- **Description:** Hands-on introduction to Wireshark, the industry-standard packet analyzer. Learn to capture live traffic, apply display and capture filters, follow TCP streams, and inspect packet details across multiple protocol layers.

## 6. Tcpdump: The Basics
- **Room:** Tcpdump: The Basics
- **URL:** https://tryhackme.com/room/tcpdumpthebasics
- **Difficulty:** Easy
- **Time:** ~1 hour
- **Tier:** Premium
- **Description:** Introduces Tcpdump, the command-line packet capture tool. Covers capturing traffic on specific interfaces, using BPF filters, saving captures to files, and reading pcap files for offline analysis.

## 7. Nmap: The Basics
- **Room:** Nmap: The Basics
- **URL:** https://tryhackme.com/room/nmapthebasics
- **Difficulty:** Easy
- **Time:** ~1 hour
- **Tier:** Premium
- **Description:** Covers the fundamentals of Nmap for network discovery and security auditing. Topics include TCP SYN scans, service version detection, OS fingerprinting, NSE scripts, and output formats.
