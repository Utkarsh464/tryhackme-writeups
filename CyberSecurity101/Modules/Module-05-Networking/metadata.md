# Module 05: Networking

## Name
Networking

## Description
This module provides a foundational understanding of computer networking concepts, protocols, and tools essential for any cybersecurity professional. From the OSI and TCP/IP models to packet analysis with Wireshark and Tcpdump, and network scanning with Nmap, learners will gain both theoretical knowledge and hands-on practical skills. The module covers how data travels across networks, how devices communicate, what core and secure protocols enable modern internet communication, and how to capture, filter, and analyze network traffic. This knowledge is critical for identifying vulnerabilities, understanding attack surfaces, and performing network-based security assessments.

## Objectives
- Understand the OSI and TCP/IP models and how they map to real-world networking
- Describe the purpose and function of common networking protocols such as TCP, UDP, IP, DHCP, DNS, HTTP, and ARP
- Differentiate between secure and insecure protocols and understand when each should be used
- Capture and analyze network traffic using Wireshark and Tcpdump
- Perform network reconnaissance and port scanning using Nmap
- Interpret packet-level data to identify normal and malicious network activity
- Apply networking knowledge to troubleshoot and secure networked systems

## Skills
- Packet capture and analysis
- Network traffic filtering
- Port scanning and service discovery
- Protocol identification and analysis
- Network troubleshooting
- Secure protocol selection and implementation

## Technologies
- TCP/IP stack
- OSI model layers
- Ethernet, Wi-Fi
- IPv4, IPv6
- DNS, DHCP, HTTP/HTTPS
- TLS/SSL
- ARP, ICMP

## Tools
- Wireshark
- Tcpdump
- Nmap

## Prerequisites
- Basic familiarity with using a computer and command-line interfaces
- Completion of Module 01 (Start Your Cybersecurity Journey) recommended
- No prior networking experience required

## Outcomes
Upon completing this module, learners will be able to describe how data flows through a network, identify and explain the purpose of major networking protocols, use Wireshark and Tcpdump to capture and filter packets, and use Nmap to discover hosts and services on a network. These skills form the foundation for more advanced topics in network security, web hacking, and penetration testing.
