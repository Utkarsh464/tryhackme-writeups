# Rooms: Start Your Cybersecurity Journey

## Room 1: Offensive Security Intro

**Room URL:** https://tryhackme.com/room/offensivesecurityintro

**Description:** This room introduces the offensive security discipline, commonly known as ethical hacking or penetration testing. Students learn about the hacker mindset, the penetration testing methodology, and get hands-on experience exploiting a vulnerable machine. The room covers key concepts such as reconnaissance, enumeration, exploitation, and post-exploitation. It provides a realistic but safe environment to understand how attackers think and operate.

**Key Topics:**
- What is offensive security
- Penetration testing methodology
- Ethical hacking principles
- Basic exploitation techniques
- Legal and ethical boundaries

---

## Room 2: Defensive Security Intro

**Room URL:** https://tryhackme.com/room/defensivesecurityintro

**Description:** This room focuses on the defensive side of cybersecurity, introducing the blue team's role in protecting organizations from cyber threats. Students learn about security operations centers (SOCs), incident detection and response, digital forensics, and security monitoring. The room covers tools and techniques used by defenders to identify, analyze, and mitigate security incidents in real time.

**Key Topics:**
- What is defensive security
- Security Operations Center (SOC) roles
- Incident detection and analysis
- Digital forensics fundamentals
- Threat intelligence and monitoring

---

## Room 3: Search Skills

**Room URL:** https://tryhackme.com/room/searchskills

**Description:** This room teaches the critical skill of finding information efficiently and effectively. Cybersecurity professionals must be able to search for documentation, exploits, configuration guides, vulnerability reports, and threat intelligence quickly. The room covers advanced search operators, specialized search engines, exploit databases, CVE lookups, and best practices for technical research. These skills are essential for both offensive and defensive roles.

**Key Topics:**
- Advanced search operators (Google dorking)
- Using exploit databases (Exploit-DB)
- CVE and vulnerability research
- Technical documentation lookup
- Security community resources
