# Module 01: Start Your Cybersecurity Journey

## Module Name
Start Your Cybersecurity Journey

## Description
This module serves as the entry point for anyone beginning their cybersecurity education. It introduces the fundamental concepts that underpin the entire field of information security, providing a strong foundation for future learning. Students will explore the two primary disciplines within cybersecurity: offensive security (ethical hacking and penetration testing) and defensive security (blue team operations, monitoring, and incident response). The module also covers essential research and search skills necessary for any cybersecurity professional to locate documentation, exploits, threat intelligence, and community knowledge effectively. By the end of this module, learners will understand the cybersecurity landscape, the roles and responsibilities of different security professionals, and how to leverage the internet as a learning and research tool. This module is designed for absolute beginners with no prior security experience and requires only a willingness to learn and explore.

## Learning Objectives
- Understand the difference between offensive and defensive security
- Identify the key responsibilities of red team and blue team professionals
- Recognize common attack types and defense mechanisms
- Develop effective search and research skills for cybersecurity
- Navigate TryHackMe rooms and learning paths confidently
- Apply basic research techniques to find technical documentation and threat data
- Understand the ethical and legal boundaries of security testing

## Prerequisites
- Basic computer literacy
- Ability to browse the web
- No prior cybersecurity experience required

## Expected Outcomes
After completing this module, students will be able to differentiate between offensive and defensive security roles and methodologies. They will have hands-on experience with basic penetration testing concepts and defensive monitoring techniques. Students will also be proficient at using search engines and specialized databases to find security information, exploits, patches, and threat reports. This foundational knowledge prepares learners for deeper technical modules in Linux, Windows, networking, and web security.
