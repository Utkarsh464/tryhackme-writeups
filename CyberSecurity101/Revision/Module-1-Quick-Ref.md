# Module 1: Start Your Cybersecurity Journey - Quick Reference

## Key Concepts
- **Cybersecurity** - Practice of protecting systems, networks, and programs from digital attacks
- **CIA Triad** - Confidentiality (secrecy), Integrity (accuracy), Availability (accessibility)
- **Risk** = Threat × Vulnerability × Impact
- **Defense in Depth** - Multiple layers of security controls

## Security Controls
- **Preventive** - Firewalls, encryption, access controls
- **Detective** - IDS, SIEM, log monitoring
- **Corrective** - Backups, patches, incident response
- **Deterrent** - Warning banners, guards

## Common Terminology
- **Threat Actor** - Entity that causes harm (nation-state, cybercriminal, hacktivist, insider)
- **APT** - Advanced Persistent Threat (long-term targeted attack)
- **Zero-Day** - Unknown vulnerability without patch
- **Exploit** - Code that takes advantage of a vulnerability
- **Payload** - Malicious code delivered by exploit
- **IoC** - Indicator of Compromise (evidence of breach)

## Attack Types
- **Phishing** - Deceptive emails to steal credentials
- **Malware** - Malicious software (virus, worm, trojan, ransomware)
- **DoS/DDoS** - Denial of Service / Distributed DoS
- **MITM** - Man-in-the-Middle (intercepting communication)
- **SQL Injection** - Injecting SQL queries via input
- **XSS** - Cross-Site Scripting (injecting scripts into web pages)

## Career Paths
- **Red Team** - Offensive security (penetration testing, exploitation)
- **Blue Team** - Defensive security (SOC, incident response, forensics)
- **Purple Team** - Combined offensive and defensive collaboration
- **GRC** - Governance, Risk, and Compliance
- **Security Architecture** - Designing secure systems
- **Security Engineering** - Building security tools and controls
- **SOC Analyst** - Monitor and respond to security incidents (tiers 1-3)

## Methodologies & Frameworks
- **Cyber Kill Chain** (Lockheed Martin) - Recon → Weaponization → Delivery → Exploitation → Installation → C2 → Actions on Objectives
- **MITRE ATT&CK** - Knowledge base of adversary TTPs (Tactics, Techniques, Procedures)
- **NIST CSF** - Identify, Protect, Detect, Respond, Recover
- **OWASP Top 10** - Most critical web app vulnerabilities
- **ISO 27001** - Information Security Management System standard

## Certifications (Entry Level)
- **CompTIA Security+** - Foundational security certification
- **CEH** - Certified Ethical Hacker
- **OSCP** - Offensive Security Certified Professional (advanced)
- **CISSP** - Certified Information Systems Security Professional (experienced)
- **SANS GIAC** - Various specialized certifications

## Tools Mentioned
- **Nmap** - Network scanning and discovery
- **Burp Suite** - Web application testing proxy
- **Metasploit** - Exploitation framework
- **Wireshark** - Packet analysis
- **Nessus/OpenVAS** - Vulnerability scanners
- **Splunk/ELK** - SIEM and log analysis

## Key Laws & Regulations
- **GDPR** - EU data protection (fines up to 4% revenue)
- **HIPAA** - US healthcare data protection
- **PCI DSS** - Payment card industry security
- **SOX** - Sarbanes-Oxley (financial reporting)

## Ethics & Legal
- Stay within scope of authorization
- Report findings responsibly
- Follow disclosure guidelines
- Obtain written permission before testing
- Respect privacy and data protection laws
